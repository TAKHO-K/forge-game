## 3. 방식(LOOK3에서 바꾼 것)

1. **몸통 곡면 위 2D 도안 투영**: 몸통을 단면 함수(초타원 · 높이별 폭/깊이)로 정의하고, 판 · 테두리 · 문장 · 리벳을 2D 다각형으로 그린 뒤 곡면에 붙여 두께를 준다. 판이 몸을 따라 휘고, 테가 판 가장자리를 실제로 감싼다(LOOK3 = 상자 · 고리 조합).
2. **매끈 음영 + 각도 기준 날카로운 모서리**(smooth by angle 42°). LOOK3 = 평면 음영.
3. **팔레트 1장 + UV 명암**: 색마다 세로 띠(어두움 → 기본 → 밝은 빛 색)를 그린 팔레트 1장. UV u = 색 칸, v = 굽힌 명암(반 램버트 빛 + 위쪽 빛 + 광선 AO 24방향 + 볼록 모서리 하이라이트). 세트 · 등급 바꾸기 = 팔레트 칸만 교체(메시 · UV 그대로). LOOK3 = 등급마다 1024 색 지도(1벌 텍스처 최대 7.9MB 주의 항목) → A안 = 256² 1장.
4. 안 보이는 면 삭제(판 바닥 · 테 바닥 · 흉갑 안쪽 겹) + 열린 조각은 몸 바깥 방향으로 법선 맞춤 → 같은 삼각형으로 더 많은 장식.
5. 판 윗면을 한 점 부채꼴이 아니라 "긴 축 가운데 선"으로 줄어드는 고리로 채움(첫 시도에서 부채꼴 → 길쭉한 삼각형 → 명암 톱니가 생겼다).

## 5. 스스로 평가

### 참고 그림과 다른 점 3가지
1. **판 색이 초록이 아니라 주황.** 그림은 판 = 초록 + 금 테인데, 규칙(3-1절 "등급색 = 판 에나멜", 3절 "세트 부착물 ≤ 25%")을 따르면 전설 = 주황 판이 된다. 초록은 문장 · 어깨 띠로만 남았다. 그림처럼 하려면 "세트 색이 판을 덮는" 쪽으로 규칙 판단이 필요하다.
2. **장식 밀도 · 손그림 질감이 낮다.** 그림의 판 위 금 문양(나뭇잎 · 소용돌이) · 긁힌 붓 질감 · 가슴 육각 가죽 패턴이 없다. 스크립트로 넣을 수는 있지만(도안 투영 재사용) 삼각형 예산 안에서는 문양 1 ~ 2개가 한계. 멀리서 보면 "깨끗한 장난감" 느낌.
3. **어깨 실루엣이 둥근 돔.** 그림의 어깨는 각진 판 3장이 계단처럼 위로 솟고 바깥 끝이 뾰족하다. A안은 큰 돔 + 아래 겹판 2장이라 덜 공격적이다. 가슴 방패도 그림은 세로로 긴 육각형에 금 나뭇잎 문양인데, A안은 규칙의 "돌 방패 + 균열"로 바꿨다.

### LOOK3 대비 나아진 점(`renders/pilotA_compare_look3.png`)
- 판이 몸을 따라 휜 하나의 덩어리로 읽힌다(LOOK3는 상자 판 + 고리가 따로 떠 보임). 가슴 · 배 · 등 판 구분이 분명하다.
- 매끈 음영 + 구운 AO · 하이라이트로 입체감이 Studio 조명에서도 남는다(정면 Studio 캡처에서 판 경계 그늘이 보임).
- 어깨가 팔 상자 모서리를 완전히 덮는다(LOOK3 = 겹판 반지름이 팔 모서리 0.707보다 작아 남색이 비침 - 이번에도 첫 시도에서 같은 문제가 나와 반지름으로 해결).
- 텍스처 256² 1장(LOOK3 1024² 색 지도 + 발광 지도) → 1벌 텍스처 메모리 큰 폭 감소 · 세트 교체 = 팔레트만.
- 대신 삼각형은 LOOK3 몸통(3,276)보다 많다(5,911 · 예산 6,000 안).

## 6. 남은 문제 · 범위 밖
- 발광(EmissiveMask) 없음 - 호박 보석은 팔레트 밝은 칸으로만.
- 문장을 메시에 합쳤다(게임의 "세트 문장 = 따로 붙는 파트" 구조와 다름). 실제 적용 시 문장만 별도 오브젝트로 떼면 된다.
- 팔을 크게 들면 어깨판 안으로 팔이 들어감(UpperTorso 부착 · LOOK3 판정 2와 같은 허용).
- Studio 확인은 Edit 모드 정지 자세(앵커)만. 달리기 · 공격 · 활강 파고듦 검사는 하지 않았다(시범 범위).
- `upload.py`가 규칙대로 `roblox/art/asset-ids.json` · `roblox/src/shared/data/ArtAssetIds.lua`에 2줄씩 **추가**했다(기존 줄 변경 0). 게임 코드는 이 키를 읽지 않는다.
