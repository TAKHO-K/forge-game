- 스크린샷: 서버 `ServerStorage.DevCommandHook:Invoke(player, "/gg …")` + 로그 `SHOT|이름` → `shots.ps1`(PowerShell 도구 백그라운드 · 이름 목록을 쓰면 끝나므로 장면마다 새로).
