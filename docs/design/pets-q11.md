# 펫 최소판 (QUEUE-10h Q11 · 2026-09-29)

> 코드: `shared/data/PetData.lua` · `shared/Pet.lua`(순수 규칙) · `server/PetService.lua`(Remote PetRequest · PetSync) · `client/PetView.client.lua`(모습) · 알 창 `client/panels/EggInfo.lua`. 저장 SAVE v52 `pets`.

## 1. 흐름
1. 알 = 무료 획득만(둥지 - 개인 쿨다운 · 뺏기 없음(M1-3 NestServer 그대로) · 퀘스트 보상 · 출석(Q12)). 유료 랜덤 없음.
2. 알 창 [부화] → 대기열(기본 1 · 캐릭터 Lv 300 = +1) · 시간 = 보통 60초 · 좋은 180초 · 희귀 600초.
3. [받기] → 종 = 알 후보 2종 50:50 · 등급 = `Pet.hatchTable(알 등급, 부화 레벨)` · 첫 펫은 바로 동행.
4. 부화 레벨 = 누적 부화 수(0 · 3 · 10 · 25 · 50회 → Lv 1 ~ 5) · 일반 몫 0 · 3 · 6 · 9 · 12%p를 고급 60% · 희귀 30% · 영웅 10%로.
5. 동행 펫 = Player Attribute(PetSpecies · PetBody · PetZone · PetGrade) → 모든 클라가 그린다(서버 위치 전송 없음).
6. 자동 줍기(캐릭터 Lv 200 + 동행) = `ItemDropServer` 줍기 반경만 14 stud(높이 8)로 넓힌다. 칸 확인 · 바닥 제거 · 가득이면 바닥에 둠 · 소유자 한 명 = 기존 `tryPickup` 한 곳(복사 경로 없음).

## 4. 결정 필요
1. 해금 "레벨" = 캐릭터 레벨로 가정(펫 레벨 없음) - 환생하면 레벨이 내려가 자동 줍기가 꺼진다. 대안 = 계정 최고 레벨(peakLevel - 내려가지 않음). 추천 = peakLevel.
2. 종 24 → 몸 틀 3(강아지 · 고양이 · 새끼 용) 배정(`PetData.bodyOf`) - 이름(돌 거북 · 구름 양 등)과 몸이 안 맞는 종이 있다. 종별 몸은 아트 단계.
3. 부화장 NPC(커뮤니티센터) = H1 배치 금지라 자리 데이터만(`PetData.hatchery`) · 부화는 알 창에서.
4. 펫 등급의 효과 = 지금 없음(모습 · 영웅 빛만). 탑승 · 기능 차등은 뒤.
