# 초월(超越) 등급 + 보스 도파민 (C5-7 · 2026-09-28)

## 1. 등급

- 8번째 등급 `transcendent`(`ArmorData.gradeOrder` 마지막). 색 = 흑금(검은 본체 + 옅은 금빛 균열 + 미세 무지개 - 보스 경고색 330 ~ 50°와 구분). 등급 색표 · 이름표 · 아이콘 자리. `SAVE_VERSION`↑(등급 문자열 · 각인 · 원장).
- 위력: 딜 부위(장갑 · 신발) 초월 = 고대 × 1.5(`TranscendentData.dpsStepOverPrimordial`) · 갑옷 = 태초 × 1.5. 보유자 도달 시간 비 ≤ 1.5(EconSim).

## 2. 공급(바닥 드랍 자체 확률 - `DropTableData`)

| 출처 | 초월 확률 |
|---|---|
| 보스 첫 클리어 | 0.001% |
| 토벌 | 0.0002% |
| 반짝이 | 0.0005% |
| 일반 몹 | 0.00001% × tier 3구간(×0.7 / ×1 / ×1.4) |

- 동접 1,000 기준 합계 1 ~ 2개/일 · 보스 계열 ≥ 60%(EconSim으로 확정). 끝자리 맞추기 · 합 100 검사 유지. 환생 무기 · 분해 · 합성 · 운영 지급 제외.
- 태초 · 고대 보정: 총 공급 유지 · 보스 계열 비중 ≥ 60% · 일반 몹은 로또.

## 3. 처리

분해 불가(버튼 비활성 + 문구) · 계승 가능(옵션 + 특수 옵션 이동) · 각성 무료 · 무제한 · 기본 잠금 · 판매 불가. S1 발급 원장에 별도 기록 · 격리 규칙 동일 · 자동 격리 1순위. 태초 리더보드에 초월 열. 확률표에 초월 확률 공개(P4b 단일 소스).

## 4. 아슬아슬 회피(폐기 - C5-7b 사용자 결정 2026-09-28)

전조 종료 전 위험 범위 표본 → 적중 순간 밖 + 피해 0 판정(`registerDanger`)은 **폐기**했다. 강탈(파편 저장 · 변환 · 매핑표) · 역전(HP 조건 기절 · 보스 +15% · Q 강화판)도 같이 삭제 - 코드 · 데이터 · 검증 블록 · `/gg c5 dodge|fragment|dodgefire` 없음.

## 5. 특수 옵션(부위별 1개 고정 · 리롤 불가 · 계승 시 이동 · 본인만 - C5-7b 교체)

수치 = `TranscendentData.phantom · frenzy · soar` · 판정 = `TranscendentService`(서버). 부위 고정이라 `item.special`(v47 옛 값 plunder · reversal 포함)은 읽지 않고 `specialByPart` 표가 정한다 - **저장 구조 변경 없음(SAVE_VERSION 47 그대로)**. 툴팁 = 부위 한 줄(`TextData transcendent.special.*`).

| 부위 | 이름 | 효과 |
|---|---|---|
| 장갑 | 환영(幻影) | 흑금 무기 + 팔의 환영이 등 뒤에 떠 있다(클라 `PrimordialFx` - 임시 파트 · 판정 없음 · 타인에게도 보임). 기본 공격이 대상에 들어가면 **25%(서버 굴림)** 로 환영이 같은 대상에 추가타 1회 = 기본 공격 피해 1회분(한 타 배율 · 딜링모드 · 치명 굴림 · 힐러 버프 포함, 3타 배율 제외). 환영 추가타 **3번째마다 강공격**(3타 배율 · 강공격 불꽃 · 무기가 길게 찌름). 공격 요청 1회당 최대 1번 · 보스 포함 · 근접 즉시 판정(원거리 직업은 화살 도달 순간 첫 대상). 흡혈 · 태초 번개 · 비상 초기화는 걸지 않는다 |
| 갑옷 | 광폭(狂暴) | 전투 중(최근 5초 안에 공격했거나 맞음 - `PlayerState.lastCombatActionAt`) 이동 속도 +10% · 공격 속도 +10% · 대시 · 돌진형 스킬(`shape = "dash"`) 쿨 −20%. 이속 · 공속은 신발 % 합에 더한다 → 이속 상한 ×1.5 · 공속 상한 ×2.5 · 최소 간격 0.33초(넘는 몫 = 한 타 피해 환산) 규칙 그대로(신발 +150% 이상이면 공속 이득 0). 발동 중 흑금 오라가 짙어진다(Attribute `FrenzyActive`) |
| 신발 | 비상 | 공중에서 스킬을 써도 착지 판정 · 공중 행동 소모 없음(SkillServer는 원래 공중 상태를 쓰지 않는다 - 유지). **초기화 조건 = 공중 강공격(3타)이 적에게 적중**(근접 · 원거리 도달 모두) → 공중 행동(공중 점프 · 대시 · 공격) 초기화(쿨 4초). 최고 높이 상한(24.38) 유지 - 세션 정점은 안 건드린다 · 둥지 도달성 "보유자 예외" |

## 6. 보스 연결 · 알림

- 보스전 공식 제외 · 보스 HP = 대표 60초분 유지. 검증: 대표 장비 전멸률 설계값 유지 · 태초 1부위 클리어 시간 −20 ~ 30% · 초월 1부위 −35 ~ 50%. 착용 시 보스전 흑금 오라(타인에게 보임).
- 태초 = 출처(일반 몹 · 반짝이 · 보스 첫 클리어 · 토벌 · 세대 변이) 상관없이 **같은 서버 알림(배너 + 채팅 줄 · 빛기둥) + 본인 큰 연출만**. 전 서버 알림 · 배너 · 폭죽 · 명예의 전당 · 칭호는 초월부터(QUEUE-10h Q0-6 - 태초 명예의 전당 기록 · "태초의 선택" 새 지급 제거 · 이미 가진 칭호는 유지). 문서 · EconSim의 합계 수치는 "전체 서버 합계 ○○ 발생/일(통계, 알림 아님)"으로 적는다. 초월 = 획득 슬로우 + 흑금 섬광 + 빛기둥 최상단 → 전 서버 채팅 "★ ○○님이 세계 N번째 초월 [부위]를 획득했습니다!"(MessagingService · 원본 DataStore) + 배너 + 서버 폭죽 + 명예의 전당 별도 칸 + 칭호 "초월자"(흑금 그라데이션) + 세계 번호 · 최초 획득자 · 출처 각인.
