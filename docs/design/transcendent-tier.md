# 초월(超越) 등급 + 보스 도파민 (C5-7 · 2026-09-28)

## 1. 등급

- 8번째 등급 `transcendent`(`ArmorData.gradeOrder` 마지막). 색 = 흑금(검은 본체 + 옅은 금빛 균열 + 미세 무지개 - 보스 경고색 330 ~ 50°와 구분). 등급 색표 · 이름표 · 아이콘 자리. `SAVE_VERSION`↑(등급 문자열 · 각인 · 원장).
- 위력: 딜 부위(장갑 · 신발) 초월 = 고대 × 1.5(`ArmorData.dpsTranscendentStep`) · 갑옷 = 태초 × 1.5. 보유자 도달 시간 비 ≤ 1.5(EconSim).

## 2. 공급(바닥 드랍 자체 확률 - `DropTableData`)

| 출처 | 초월 확률 |
|---|---|
| 보스 첫 클리어 | 0.001% |
| 토벌 | 0.0002% |
| 반짝이 | 0.0005% |
| 일반 몹 | 0.00001% × tier 3구간(×0.7 / ×1 / ×1.4) |

- 동접 1,000 기준 합계 1 ~ 2개/일 · 보스 계열 ≥ 60%(EconSim으로 확정). 끝자리 맞추기 · 합 100 검사 유지. 환생 무기 · 분해 · 합성 · 운영 지급 제외.
- 태초 · 고대 보정: 총 공급 유지 · 보스 계열 비중 ≥ 60% · 일반 몹은 로또.

## 3. 처리

분해 불가(버튼 비활성 + 문구) · 계승 가능(옵션 + 특수 옵션 이동) · 각성 무료 · 무제한 · 기본 잠금 · 판매 불가. S1 발급 원장에 별도 기록 · 격리 규칙 동일 · 자동 격리 1순위. 태초 리더보드에 초월 열. 확률표에 초월 확률 공개(P4b 단일 소스).

## 4. 아슬아슬 회피(서버 공통 판정)

보스의 전조 있는 공격에서 **전조 종료 0.4초(`BossCurveData.closeDodge.windowSeconds`) 전까지 위험 범위 안**에 있다가 **적중 순간 밖 + 피해 0** → 회피 이벤트(`CloseDodge`). 지연 0.25 오판정 비율(회피했는데 미인정 / 맞았는데 인정) 각 ≤ 5%.

## 5. 특수 옵션(부위별 1개 고정 · 리롤 불가 · 계승 시 이동 · 본인만)

| 부위 | 이름 | 효과 |
|---|---|---|
| 장갑 | 강탈 | 아슬아슬 회피 시 그 패턴의 파편 1개 저장(1개만 · 새 회피 시 교체 · 보스전 종료 30초 뒤 소멸). 다음 강공격(3타) 또는 Q가 파편으로 변환 - 매핑표(`TranscendentData.fragments`): 지진파 → 소형 파동 / 돌진 → 돌진 베기 / 눈덩이 → 작은 눈덩이 / 낙뢰 → 낙뢰 1발 / 회오리 → 소형 회오리(잡몹 띄움) / 독침 → 3연 투사체 / 레이저 → 짧은 레이저 / 판 뒤집기 → 앞 원형 넉백. 피해 = 플레이어 스킬 계수(보스 수치 아님) · 잡몹에도 사용. 스킬바 옆 파편 아이콘(보스 얼굴) · 흑금 잔상. 투사체형 파편은 반사 태세 보스에 반사 |
| 갑옷 | 역전 | HP ≤ 50% → 강공격이 잡몹 짧은 기절 + 보스 피해 +15%(잔상 굵어짐) / HP ≤ 20% → Q 강화판(범위 · 계수 ×1.5 · 쿨 −50% · 연출 변경). 받는 피해 감소 · 회복 없음 · 전멸기 · 낙사 예외 없음 |
| 신발 | 비상 | 공중에서 스킬을 써도 착지 판정 · 공중 행동 소모 없음. 아슬아슬 회피 또는 공중 강공격 적중 시 공중 행동(공중 점프 · 대시 · 공격) 초기화(쿨 4초). 최고 높이 상한(24.38) 유지 - 수평 · 공중 공격 · 낮은 재점프만 복구. 서버 판정 이벤트에만 연결(치트 검사 합법 등록) · 둥지 도달성 "보유자 예외" |

## 6. 보스 연결 · 알림

- 보스전 공식 제외 · 보스 HP = 대표 60초분 유지. 검증: 대표 장비 전멸률 설계값 유지 · 태초 1부위 클리어 시간 −20 ~ 30% · 초월 1부위 −35 ~ 50%. 착용 시 보스전 흑금 오라(타인에게 보임).
- 태초 = 같은 서버 알림 + 본인 큰 연출(전 서버 배너 제거). 초월 = 획득 슬로우 + 흑금 섬광 + 빛기둥 최상단 → 전 서버 채팅 "★ ○○님이 세계 N번째 초월 [부위]를 획득했습니다!"(MessagingService · 원본 DataStore) + 배너 + 서버 폭죽 + 명예의 전당 별도 칸 + 칭호 "초월자"(흑금 그라데이션) + 세계 번호 · 최초 획득자 · 출처 각인.
