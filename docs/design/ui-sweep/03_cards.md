# Claude Design 요청 카드 (FINAL-1 1단계)

카드 한 장 = 화면 하나. 시안(HTML)은 만들지 않았다 — 디자인은 Claude Design 담당. 기준 = `claude-design-handoff\00_design-system`(최신 v6) + 각 화면 최신 vN + 이미 구현된 UiKit · 토큰 · 배치 데이터(`shared/data/UiTokens` · `UiLayoutData` · `UiIconData`).

**캡처 주의**: Studio 창 높이 상한(뷰포트 최대 592) 때문에 실제 1920×1080 · 1366×768 뷰포트는 만들 수 없다. PC = **16:9 축소 1052×592**(두 해상도 모두 16:9라 v2 화면은 같은 비율로 줄어듦 — 해상도별 px 차이는 `02_causes.md` 계산표), 폰 = **844×390**(Studio `ForceTouchLayout` · 800×360과 비율 거의 같음). 캡처 파일 = `docs/design/ui-sweep/cap/`(pc169_* · ph_*). Studio 폰 캡처는 스킬 줄이 PC 배치로 찍힌다(스킬 줄은 `TouchEnabled`만 보는데 Studio는 false — 실제 폰에선 오른쪽 아래 배치).

**공통 제약(모든 카드)**
- 기준 좌표 PC 1920×1080 · 폰 800×360(UiRoot UIScale) · 폰 = 엄지 영역(왼쪽 아래 = 이동 조이스틱 · 오른쪽 아래 = 공격/스킬/점프) 비워 두기.
- 로블록스 기본 UI 자리: 위 상단 바 58px(채팅 · 메뉴 버튼 - `GetGuiInset`) · 폰 점프 버튼(짧은 변 ≤ 500 → 지름 70 · 오른쪽 95 · 아래 90 / 큰 화면 120 · 170 · 210) · 노치(SafeArea).
- 압박 UI 금지(카운트다운 · 빨간 강요 · "놓치면 손해" 금지) · 로벅스로 힘 사기 없음.
- 글자 크기 설정(보통 1.0 · 크게 1.15 · 아주 크게 1.3)은 글자에만 곱해진다 → 칸이 커진 글자를 견디게.
- 아이콘 크기 기준(제안 · 이 조사 결론): 폰 기준 상태 아이콘 28 ~ 32px · 누르는 영역은 44px 이상 · PC 1366×768에서 메뉴 아이콘이 40px 아래로 내려가지 않게(지금 하한 없음 — 02 원인 표).
