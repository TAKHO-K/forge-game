# 카드용 데이터 표 — 꼭 보여야 할 값(필드 · 최대 길이 · 범위 · 상태)

경로 = `roblox/src` 기준 · 글자 수 = 한국어 최장 문구(TextData). 계산값은 "(계산)".

**요구와 코드가 다른 점(디자인 전에 확인)**
1. 도감 직업 탭 = **4직업 × 7등급(0 일반 ~ 6 태초)** — 사용자 요구 "무기 4종 × 8등급"(초월 g8 포함) ↔ 코드 7등급. 초월은 칸이 아니라 "초월 완성" 테두리 → **결정 필요**(8칸으로 늘릴지).
2. 지속 피해형 상태이상(화상 · 독 · 출혈 · 둔화 · 침묵) = **코드에 없음** → 상태 아이콘 줄의 상태이상(빨강)은 기절 · 잡힘류뿐.
3. HUD 배치 저장 필드 = **없음**(창 위치 `windowPositions`만).
4. BREAK 게이지 · 기여도 = 서버에만 있음(기여도는 클라로 안 옴 · BREAK는 게이지 없이 기믹 성공 뒤 "기절 + 받는 피해 ×1.3 4초 창"만).
5. 성장 별 1 ~ 3(도감) = 코드에 없음(새 데이터).

## 5. HUD 배치 저장

- 지금 필드 없음. 선례 = `windowPositions`(kind positions · `"id:x,y;…"` · ≤ 800자 · id ≤ 40자 · 좌표 ±10000 · SettingsService:49-63).
- 설정 저장 = `profile.settings[키]` · 없는 키 = 기본값 → **새 키는 SAVE 버전 안 올림**(SaveConfig.saveVersion = 75).
- 제안 이름(구현 때 확정): `hudLayout`(positions) · `hudLayoutPhone`(positions) · `hudLayoutVersion`(stamp).
