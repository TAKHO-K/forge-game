> 단일 소스: 첫 클리어 = `DropTableData.bossGrades.firstClear` · 토벌(재도전) = `DropTableData.raidWeights`(정수 · 합 검사) → `DropTable.bossFirstClearGradeTable` · `bossRetryGradeTable`(서버 굴림 `Loot.rollBossFirstClearDrop` · `rollBossRetryDrop` · 보스 선택 창 보상 띠 · 확률 공개가 같은 함수). 골드 · 경험치 = `BossData` 공통 배율(×20) · 강화석 = 보스 보상 단위(`rewardKillUnits` 또는 `hpMultiplier`).

## 2. 점검

| 정수 가중치 + 합 검사 | 잡몹 3구간 · 토벌 = 정수 ÷ 10⁷ · 합 틀리면 서버가 시작 안 함(assert) · 첫 클리어 = 소수(합 1 - QueueVerify 합 검사 O) | 첫 클리어도 정수 가중치로 옮기는 건 Q5에서 세트와 같이(기록) |
