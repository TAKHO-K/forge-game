### 6-3. 지진파 동작(사용자: "첫 지진파 뒤 점프만 해서 어색함" → 추가 "지팡이로 내려찍는 것이 더 나을 듯")

- 원인: 폭풍 세트에 `hopSlam`이 없어 파동마다 공통 맨손 점프 클립(팔 번쩍 → 착지)이 덮었고, 서버가 파동마다 몸을 4 stud 들었다.
- 고침: 폼별 찍기 클립 `forms.*.hop`(BossMotion · 애니메이터가 폼 값을 먼저 씀 - 다른 보스는 그대로 `hopSlam`) + 새 몸 노브 `v3.hopHeight = { thunderRing = 0, discharge = 0 }`(몸을 들지 않음 · 판정 · 파동 시각 · 피해 그대로 · 옛 몸 불변).
  - 1폼 `s_hop`: 지팡이를 두 손으로 쥠 → 머리 위로 크게 들어 올림(발끝) → 두 손으로 땅에 내리꽂음(멈춤 0.1초) → 회복. Studio: 몸 위치 변화 0 · 발 1 stud 안팎 · 보주 38 stud → 2.6 ~ 4.3 stud.
  - 2폼 `f_hop`: 쭈그려 주먹을 거두며 밀기 → 떠올라 두 주먹을 머리 위로 → 내려와 두 주먹으로 땅 찍기(무릎 꿇기). Studio: 주먹 13 → 26 → 착지 중심 3.1 ~ 3.2 stud(아래 끝 ≈ 지면) · 발이 지면 아래로 빠지던 것(−3.3) 고침.
  - 파동 간격 1.6초라 착지 직후 다음 찍기가 이어진다(찍기 ↔ 들기 반복 - 데이터 그대로).
- `discharge`(방전 고리 1파동)의 들기 0은 같은 장치라 하네스로만 확인(Studio 촬영은 천둥 고리로).

캡처: `s11a/b/c_quake1_*`(1폼 들어 올림 · 머리 위 · 내리찍기) · `s14a/b/c_quake2_*`(2폼 떠오름 · 내려와 찍기) · `s12_quake_cracks_top.jpg` · `s12b_quake_cracks_with_rings.jpg` · `s13_sword_wave_scorch.jpg`.
