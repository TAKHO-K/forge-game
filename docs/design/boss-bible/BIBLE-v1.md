# 보스 설계 바이블 v1 (10-05 · 설계 담당 · 사용자 결정 반영)

> 원본: BOSS-DUMP.md(c6d38fa3) · ART-REF2 ref-parts(537574f5) · 프로젝트 문서 boss-bible-v0 / boss-3d-spec.

## 0. 사용자 결정 (10-05)
- **6마리 모두 출시 전**, 몸 구조 · 파츠 · 리깅 · 모션 · 스킬 판정까지 고품질. 출시일 늦어져도 됨.
- 보스별 몸 구조 = v0 추천안 전부(수호자 너클 보행 골렘 · 수정 나비 여왕 · 심해 나가 · 전갈 구조 유지 · 폭풍 기사→비행 변신 · 서리 빙하 매머드).
- 품질에 필요하면 파츠 수를 늘림. 단 렉이 많이 걸리지 않게(아래 예산).
- Meshy 크레딧: 이번 달 약 4,100 사용 목표.

## 1. 공통 규칙
### 1-1. 바꾸지 않는 것(게임 데이터)
- 스킬표(BossData)의 전조 모양 · 크기 · 전조 시간 · 피해 · 쿨 · 조건 · 우선순위 · 페이즈 · 기믹 · 환경 · 서버 이동(가장 가까운 사람에게 걷기 · 속도) · 스테이지 곡선 · BossSim 목표(처치 45~90초 · 받는 피해 80~150% · 전멸 30~50%).
- 예외: 새 몸 때문에 전조가 몸 모양과 어긋나 읽기 어려운 경우만 설계 담당 승인 후 조정 → BossSim 재실행. 출시 전에만(출시 후 확률 · 판정 변경 금지 원칙).
### 1-2. 판정(스킬 판정 고품질 기준)
- 판정 = 지금처럼 바닥 전조 영역 기준(공정 · 가독성). 대신 **몸이 정확히 그 영역을 친다**: 접촉 키프레임 = 서버 피해 시각(BossActHit) · 때리는 부위가 전조 영역 안에 들어간 모습 · 전조 모양 = 그 부위 궤적.
- 스킬마다 "때리는 부위"를 번쩍임(flash)으로 표시(지금은 강화 평타 하나뿐 → 전 스킬). 번쩍 = 위험색 아닌 흰 테 0.15초(빨강/진한 주황 빛 금지).
- 피격 판정 사본(_Query): 보스마다 Body · Head(+ 큰 몸이면 Tail/Abdomen 1개 추가 가능) · 부피 = 지금 ±20% · BodyRadius 재계산 · 사본은 관절 부위에 붙어 자세를 따라감.
- 근접 플레이어가 보스 몸에 파묻히지 않게 보이는 몸 ↔ 판정 사본 차이 ≤ 1 stud.
### 1-3. 모션 고품질 기준
- 보스마다 전용 클립 표(BossMotionData): 대기 · 걷기 · (변신 전/후 각각) · 등장 · 처치 · 환경 · 50% 변신 · 스킬 전부(예비 동작 → 타격 → 마무리). 스킬 → 클립 대응 빠짐 0(지금 심해 삼지창 던지기처럼 기본값으로 떨어지는 것 금지).
- 예비 동작(전조와 같은 길이) · 타격 정지 프레임 0.05~0.08초 · 마무리 · 무게감(큰 보스 = 느린 예비 · 긴 마무리).
- 2차 움직임(절차형 스프링): 꼬리 · 날개 · 망토 · 코 · 깃발 · 수정 · 털 → 관절 사슬에 지연 · 흔들림.
- 이동 연출: 서버는 걷기만 → 클라가 보행 주기(너클 · 네 발 · 뱀 S자 · 떠 있음 흔들림 · 여섯 다리)를 이동 속도에 맞춰 재생 · 발 미끄러짐 최소.
- 50% 변신: 지금 "겉모습 격노(≤50%)" 순간에 변신 클립 1회 + 클립 세트 교체(서버 무변경).
- 보스별 소리 자리: 포효 · 걷기 · 스킬별 큐 자리를 데이터로 추가(음원은 로블록스 공식 라이선스 오디오 예외 규칙 · SFX 후보표에서).
### 1-4. 파츠 · 렉 예산(보스 1마리 · 아레나 = 보스 1 + 최대 4인)
| 항목 | 상한 | 지금(참고) |
|---|---|---|
| Motor6D 관절 | ≤ 60 | 28~51 |
| 보이는 MeshPart(외곽선 · Neon 포함) | ≤ 90 | 61~74 |
| 외곽선 껍데기 | ≤ 12(감량본) | 0~10 |
| Neon 조각 | ≤ 10 · 색 = 가장 낮은 채널 ≤90 | 2~9 |
| 삼각형(외곽선 제외) | ≤ 30,000 · 부위 1개 ≤ 5,000 | 측정 필요 |
| 외곽선 삼각형 | ≤ 8,000 | 측정 필요 |
| 텍스처 | 1024 아틀라스 ≤ 3장 | — |
- 낮은 그래픽 · 폰: 세밀 장식 · 작은 Neon · 작은 부위 외곽선 숨김(지금 "세밀" 표시 방식) · 2차 움직임 사슬 절반 갱신.
- 합격: 아레나 4인 PC 60fps · 폰 저사양 ≥30fps · 보스 애니메이션 클라 비용(ms/프레임) ≤ 지금 × 1.5 · 서버 Heartbeat 변화 없음.

## 2. 보스별 설계

### 2-1. 구간 수호자 → 너클 보행 수정 골렘 (stage 5 · 석조 평원 / 아레나 공허의 제단)
- 정체성 유지: 보라 수정 + 어두운 보라 돌(지금 실전 색) + 윗면 이끼 조금. 귀여움 50 / 위엄 50 · "말 없는 문지기 고릴라".
- 몸(뼈대 = 지금 이족 17 그대로 + 추가): 어깨 갑옷 L/R · 가슴 룬 · 허리 갑옷 앞/뒤 · 등 수정 5(Crystal1~5 · 흔들림 · 50%에 터짐) · 머리 수정 왕관 · 눈썹 바위(Brow) · 턱. 깃발 3마디 ×2 → 등 수정으로 대체(네 발 자세에서 깃발이 땅에 끌림). 약 30관절.
- 이동: 변신 전 = 주먹 짚고 네 발(팔이 앞다리 · 어깨 낮음 · 루트 높이 −20%) · 변신 후 = 두 발 직립.
- 50% 변신(지반 붕괴와 함께): 일어서며 가슴 치기 → 등 수정 폭발 → 직립 세트.
| 스킬 | 몸 · 동작 |
|---|---|
| 강공격 heavy(원 r14) | 뒷다리로 일어서 두 주먹 머리 위 → 내려찍기 · 두 주먹 번쩍 |
| 진동파 shockwave(고리) | 가슴 치기 2번 → 두 주먹 땅 내리치기 · 점프 찍기(hop) |
| 낙석 meteor | 한 손으로 바위를 뜯어 던짐(원마다 바위 조각) |
| 돌진 charge | 변신 전 = 네 발 질주(고릴라 돌진) · 변신 후 = 어깨 들이받기 · 헤롱 = 엉덩방아 + 별 |
| 십자 화염 cross | 두 주먹 X자로 땅 찍기 → 4방향 수정 줄기 · 둘째 볼리 = 몸 45° 돌려 다시 |
| 강화 평타 swipe | 오른팔 손등 휘두르기(Hand_R 번쩍) |
| 움켜쥐기 grab | 손 뻗어 쥐기 → 머리 위로 들기 → 던지기 |
| 방패 거울 mirror | 웅크리고 등 수정이 돔처럼 빛남 |
| 원 안 내려찍기 innerSmash | 발치에 두 주먹 해머 |
| 쌍권 연타 fists | 좌우 번갈아 땅 치기 · 수정 주먹이 떨어짐 |
| 추적 광구 orbs | 등 수정 2개가 떨어져 날아감 |
| 대지 가르기 earthSplit | 한 손을 땅에 대고 반원 긁기 |

### 2-2. 수정 여왕 → 수정 나비 여왕 (stage 10 · 수정 동굴)
- 정체성: 우아함 · 노래(오르골) · 빛. 라벤더 + 청록 수정 · 연분홍은 작게(흰+자홍 금지). 왕관 빛 색 = 블룸 규칙으로 교체.
- 몸: 상체 이족 + 드레스 4방향 ×2 · 왕관 · 홀 · 홀 보석 · **날개 4장(앞 · 뒤 L/R) × 2마디 = 8** · 더듬이 L/R · 가슴 보석. 다리는 드레스 안(보이지 않음). 약 40관절.
- 이동: 땅에서 1.5~2.5 stud 떠서 위아래 흔들림(루트 높이 오프셋 · 판정 무변경) · 날갯짓 주기.
- 50% 수정 부수기: 날개가 수정 껍질로 감싸져 보호막(지금 기믹 그대로).
| 스킬 | 몸 · 동작 |
|---|---|
| 파편 폭발 burst(안 → 밖) | 날개를 접었다(안쪽 펄스) 활짝 폄(바깥 펄스) |
| 수정 낙하 drop | 홀을 위로 · 하늘에서 수정 낙하 |
| 에네르기파 energyBeam | 더 높이 떠서 가슴 보석 빔 · 날개 최대로 펼침 |
| 수정 오르골 orgel | 홀로 지휘 · 날개가 박자에 맞춰 떨림 |
| 강화 평타 swipe | 홀 휘두르기 + 날개 튕김(Scepter 번쩍) |
| 수정 손 grab | 앞날개로 감싸 잡기 → 밀어 던지기 |
| 프리즘 반사막 mirror | 날개 4장으로 몸을 감쌈(프리즘) |
| 수정 가시 spikes | 홀을 땅에 꽂음 → 가시 연쇄 |
| 수정 파편탄 shards | 날개 비늘 수정이 떨어져 유도탄 |
| 분신 돌격 mirrorDash | 날개 가루 잔상 분신 3개 |

### 2-3. 심해 군주 → 나가(바다뱀 군주) (stage 15 · 수몰 사원)
- 정체성: 바다 왕 · 꼬리 · 물 · 삼지창. 청록 + 진주 + 깊은 남청.
- 몸(새 뼈대): 상체(Body · Neck · Head · Jaw · Eyes · 어깨 · 팔꿈치 · 손목 L/R · 지느러미 L/R · 등 볏 · 지느러미 머리카락 3) + **뱀 하체 꼬리 12마디(Tail1~12) + 꼬리 끝 지느러미** + 삼지창 · 창날. 약 38관절.
- 이동: 꼬리 S자 파동(절차형) · 상체 꼿꼿.
- 50% 판 털기: 꼬리로 돌단 가장자리를 감아 들어 올림.
| 스킬 | 몸 · 동작 |
|---|---|
| 꼬리 휩쓸기 sweep(도넛) | 몸을 감고 꼬리로 한 바퀴 휩쓸기(몸 쪽 안전 = 그대로 보임) |
| 해일 tide | 꼬리로 서서 수면을 두 번 내리침(두 겹 고리) |
| 물기둥 spout | 삼지창 겨누기 · 물기둥 |
| 색 맞추기 colors | 삼지창 들어 올림 · 머리 위 표시 |
| 강화 평타 swipe | 삼지창 베기(Trident 번쩍) |
| 꼬리 감기 grab | 꼬리로 감아 들고 던짐 |
| 물의 장막 mirror | 두 팔로 물 장막 소용돌이 |
| 꼬리 반원 tailSweep | 180° 돌아 꼬리 반원(점프) |
| 소용돌이 vortex | 꼬리로 나선을 그리며 회전 |
| 거품탄 bubbles | 입으로 거품 |
| 삼지창 던지기 tridentThrow | 전용 던지기 클립(지금 기본 돌진 클립 → 고침) · 삼지창이 돌아와 잡음 |

### 2-4. 전갈 여왕 → 몸 구조 유지 · 고품질 외형 (stage 20 · 모래 유적)
- 정체성: 땅속 · 빠름 · 꼬리 3개(진짜 꼬리 빛). 모래 + 크림 배 + 금 장식 + 왕관 · 큰 눈 · 킹크랩 집게.
- 몸: 지금 51관절 유지(다리 3쌍 · 집게 팔 · 꼬리 3 × 8) + 외곽선 껍데기 추가(지금 0 → 몸 · 집게 · 머리 ≤ 8).
- 이동: 여섯 다리 보행 주기(교차 삼각 보행) · 파고들기 · 솟구치기.
| 스킬 | 몸 · 동작 |
|---|---|
| 집게 강타 claw · 집게 휘두르기 clawSweep | 두 집게 · 번쩍 = 해당 집게 |
| 독침 낙하 sting · 3연 찌르기 stingJab | 꼬리 3개가 차례로 · 번쩍 = 찌르는 꼬리 끝 |
| 잠행 찌르기 stab · 모래 잠복 ambush · 진짜 찾기 sandSearch | 파고들기(모래 튐) · 꼬리 끝만 · 솟구치기 |
| 아르마딜로 태세 armadillo | 다리 · 꼬리 웅크림 · 등 가시 |
| 강화 평타 swipe | 오른 집게(Pincer_R) |
| 집게 낚아채기 grab | 집게로 잡아 꼬리로 던짐 |

### 2-5. 폭풍 군주 → 폭풍 기사 · 50%에 비행 변신 (stage 25 · 폭풍 첨탑 · 썸네일 주인공)
- 정체성: 번개 · 바람 · 피뢰침. 남청 판금 + 노랑 번개(검정+금 금지 → 검정 대신 짙은 남색).
- 몸: 이족 17 + 어깨 번개 칼날 L/R · 투구 깃 · **망토 사슬 L ×4 · R ×4(변신 때 날개 뼈로 펼침)** · 로브 앞/뒤 ×2 · 지팡이 · 보주. 약 37관절.
- 이동: 변신 전 = 망토 휘날리며 걷기 · 변신 후 = 떠서 이동(2.5~3.5 stud) · 날개 번개 깜빡.
- 50% 돌풍: 지팡이 수평 → 망토가 번개 날개로 펼쳐지며 떠오름(썸네일 포즈).

|---|---|
| 방전 고리 discharge · 천둥 고리 thunderRing | 지팡이로 땅 찍기(변신 후 = 공중에서 지팡이 내리꽂기) |
| 회오리 whirl | 망토/날개 펼치고 회전 |
| 낙뢰 strike | 지팡이 하늘로 · 번개 |
| 번개 조준경 rods | 지팡이로 표적 지목 · 피뢰침 충전 |
| 강화 평타 swipe | 지팡이 휘두르기(Staff 번쩍) |
| 바람 손 grab | 지팡이 바람으로 끌어올림 |
| 번개 결계 mirror | 망토로 몸 감싸며 번개 결계 |

### 2-6. 서리 거인 → 빙하 매머드 거인 (stage 30 · 빙하 동굴)
- 정체성: 느림 · 무거움 · 엄폐물(얼음 기둥) · 포효. 얼음 청 + 흰 털 + 회청 피부 + 상아.
- 몸(새 뼈대 · 네 발): Root · Hips · Body(척추 2) · Neck · Head · Jaw · Eyes · 귀 L/R · **코 6마디** · 상아 L/R · 앞다리 L/R(어깨 · 팔꿈치 · 손목 · 발) · 뒷다리 L/R(엉덩이 · 무릎 · 발목 · 발) · 꼬리 3 · 등 털 망토 3 · 등 얼음 결정 3. 약 45관절. 배율 S 4.455 유지(가장 큼) · 카메라 줌 38 → 42 검토.
- 판정 사본: Body(몸통 길쭉) · Head · 부피 ±20%.
- 50% 빙하 균열: 앞발 두 개로 들어 올려 내리찍음.
| 스킬 | 몸 · 동작 |
|---|---|
| 빙결 강타 slam(원 r18) | 뒷다리로 일어서 앞발 내리찍기 |
| 낙빙 icefall | 몸을 털어 등 얼음 조각이 날아가 떨어짐 |
