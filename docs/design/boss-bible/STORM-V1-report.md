## 7. 미검증 · 결정 필요

1. **2폼 삼각형 예산 초과**(2절 · 46,585 > 30,000): 2폼 부품(어깨 · 건틀릿 · 왕관 · 코어)이 Meshy 원본의 수백 조각 구조 때문에 감량이 목표(800 ~ 1,500)까지 안 된다(개당 3,700 ~ 5,700). 1폼은 28,440으로 예산 안. 복셀 리메시는 얇은 부품(왕관 번개 · 날개 결정)에서 감량이 막혀 몸에만 썼다. → **Meshy 리메시본(부품별 목표 삼각형)을 받으면 해결** - 매머드에서 리메시본 호환 확인됨.
2. **모션 비용 × 2.0**(4-1) · **아는 보스 난이도**(4절) - 결정 필요.
3. 부품 방향 · 크기 눈 확인 필요: 건틀릿(주먹 방향 · 손목 회전) · 2폼 어깨(오른쪽 원본 · 왼쪽 반전) · 가슴 코어(판 앞뒤) · 날개 위치 · 구름 깃 → 왕관 교체 자리.
4. 후광: 머리 뒤 2 / 6.5 stud · 반지름 5.5 / 7.0으로 옮긴 뒤 다시 보지 않음(첫 위치는 날개에 가렸다).
5. 2폼 떠 있기(높이 약 3 stud)가 캡처에서 잘 안 드러남 - 눈 확인.
6. "낙뢰 = 구름 보주가 대상 위로 날아가 번개" · "번개 조준경 = 지팡이 보주가 표적 위로"는 안 함(보주는 공전만 - 바이블 §10 활약 연출 미구현).
7. 날개 불꽃 부스러기: 작은 조각 143개 삭제(가장 큰 조각의 1% 미만) - 남은 부스러기 눈 확인.
8. 변신 중 부품 날아오기(0.8초) · 망토 → 날개 전환 장면은 정지 캡처로 못 잡음(영상 금지).

## 8. Studio에서 직접 확인하는 순서

준비: Edit에서 `game:GetService("ReplicatedStorage"):SetAttribute("TestSkipMainMenuUntil", os.time() + 6 * 3600)`(**2시간짜리로 하면 밤샘 중 만료돼 캐릭터가 안 생긴다**) → Play → `[ArtAssetLoader] 메시 캐시` 줄까지.

2. 1폼 스킬: `discharge` · `thunderRing` · `whirl` · `strike` · `rods` · `tornado` · `boltSpear` · `mirror` · `innerSmash` · `grab`.
3. 변신: `/gg boss pattern off` → `/gg bossdmg 0.55` → 지팡이 수평 → 떠오름 → 2폼 부품이 날아와 붙음 · 후광 · 2.8초 동안 공격이 안 들어가는지(피해 숫자 0).
4. 2폼 스킬(같은 id로 다시 `/gg boss pattern storm_lord <id>` - 새 스폰이라 1폼부터 → 다시 `/gg bossdmg 0.55`).
