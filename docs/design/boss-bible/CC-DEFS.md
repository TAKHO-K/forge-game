# 상태이상(CC) 정의표 — 확정본 (BOSS-NIGHT-3 2단계 · 2026-10-10)

기준 = handoff `31_bosses/CC-DEFS-draft.md` 10-10 저녁판 + addendum(VERIFY-2 정정 3 ~ 6) + addendum-2 19. 값의 한 곳 = `BossData.mechanics.cc` · `BossData.mechanics.stun` · 서버 = `server/PlayerCC.lua`(경직 · 넉백/띄움 면역 · 둔화 · 수정 표식) · `server/PlayerStun.lua`(기절) · 아이콘 = `shared/data/StatusIconData.lua`.

## 공통 규칙
- 강도: 경직 < 넉백 < 띄움 < 기절(잡기 · 덫은 특수). **면역은 강도별로 따로** — 경직 면역은 기절을 막지 않고, 기절 면역은 경직을 막지 않는다. 띄움 면역은 넉백까지 막는다(같은 `launch` 계열에서 강한 쪽이 약한 쪽을 덮음).
- 대시는 무적이 아님: 보호 창 = 받는 피해 × 0.5 + 수정 미사일 통과(정본 표). 기절 중 · 띄워진 직후 0.3초 = 대시 거절.
- 상태 Attribute(플레이어) = `Status<이름>Until`(서버 시계 `workspace:GetServerTimeNow()` 끝 시각) — UI 줄은 UI 구현 단계(이번 = 데이터 · Attribute까지).
- 색: 상태이상(CC) = 빨강 · 디버프 = 노랑 · 이로운 효과 = 파랑(10-09 사용자).

## 혼자일 때 자동 해제 시간(보고만 · 이번엔 유지)
- 덫 6종 9초 · 가둠 5초 · 대공 잡기 ≤ 6초 — 혼자면 구출해 줄 사람이 없어 자동 해제까지 그대로 묶인다. 아이 기준 "행동 불가 2초 이하"보다 2.5 ~ 4.5배 길다.
- 덫 중에는 피해를 안 받고(`trap.damageTakenMultiplier = 0`) 풀린 뒤 2초 무적이라 죽음으로 이어지지는 않지만, 체감상 "아무것도 못 하는 9초"다. 9초 = 구출 인시 근거(BossData 주석) - 솔로 판에는 근거가 없다. 결정 필요: 솔로 자동 해제 단축(예: 덫 9 → 4초 · 가둠 5 → 3초) 여부 — 사용자 판단.
