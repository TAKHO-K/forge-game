## 6. 미검증 · 결정 필요

1. 삼지창 창날 = 감량으로 결정 모양이 조각나 보임(원본 = 수백 조각 · 복셀은 가는 창날에서 감량이 막혀 몸에만 썼다) → Meshy 리메시본(4,000) 받으면 해결.
2. 꼬리 감김 위치가 원본 Meshy 자세 그대로(오른쪽 → 뒤 → 왼쪽) - 보행 S자 · 꼬리 스킬에서 몸을 뚫는지 눈 확인.
3. 삼지창 던지기: 손의 삼지창은 그대로 보이고 날아가는 창은 기존 그림(boomerang) - 던지는 동안 손 삼지창 숨기기는 안 함.
4. 꼬리 휩쓸기 = 몸 회전 대신 꼬리 · 허리 휘두르기(루트를 360° 돌리면 끝날 때 거꾸로 감기는 문제).
5. 영상 금지라 꼬리 파동 · 스킬 동작 대부분은 정지 1장 + 하네스 수치로만 확인.

## 7. Studio에서 직접 확인하는 순서

준비: Edit에서 `game:GetService("ReplicatedStorage"):SetAttribute("TestSkipMainMenuUntil", os.time() + 6 * 3600)` → Play → 메시 캐시 줄까지.

1. `/gg boss frame on` → `/gg stage 15` → `/gg boss pattern abyssal_lord tide` → `/gg god on` → 보스 앞 약 20 stud.
2. 다른 스킬: `sweep` · `spout` · `colors` · `swipe`(12 stud 안) · `grab`(점프로 떠 있기) · `tailSweep` · `vortex` · `bubbles` · `mirror` · `tridentThrow`.
3. 변신: `/gg boss pattern off` → `/gg bossdmg 0.55` → 꼬리로 서며 포효 → 3초 뒤 판 털기(꼬리 내리침).
4. 비교: `/gg boss frame off`.
