## 4. 막힌 점 · 결정 필요

1. **크기 기준(K = 0.40)**: Meshy 그림은 다리가 짧고 머리가 몸에 묻힌 땅딸막한 비율이라 바이블 §4 · §5의 "키 36 · 어깨 폭 22"를 동시에 맞출 수 없다. 규칙(판정 사본 부피 ±20% · 보이는 몸 ↔ 판정 차이)과 어깨 폭에 맞췄고 **키는 직립 약 23 stud(목표 36)**. 키로 맞추면(K 0.6) 판정 사본 부피가 옛 몸 × 3.4 · 팔 끝 폭 약 50 stud. 바꾸려면 `BossRigV2Data`의 `K` 한 값 → KIT 재실행 · 재업로드.
2. **피해 × 0.80**: 시뮬 목표를 맞춘 값이지만 "처음 보는 보스" 전멸은 65 ~ 67%로 여전히 목표(30 ~ 50, 근접 60 이하) 밖이다(옛 몸 77 ~ 79%부터 이어진 구조 - 기믹 실패 고정 피해). 원래 지시대로 체력 · 피해 계수만 만졌다.
3. **원거리 유리**: 판정 사본이 × 3.96(부피)이라 원거리 명중이 쉬워지는데 BossSim은 이를 모른다. 실제 플레이 체감 확인 필요(바이블 §5-5).
4. **돌진 경로 폭**: 경로 반폭 4 stud인데 새 몸 가장자리 반폭은 10.4 — 몸이 경로 밖까지 휩쓸어 보이지만 판정은 안 된다(플레이어에 유리한 쪽). 몸 가장자리 장치에 넣을지 결정 필요(이번 지시 범위 밖이라 그대로).
5. **바이블 §7(FRAMEWORK 판정)** 은 `BIBLE-v1.md`에 없다(§6까지) - FRAMEWORK-report의 합격선(§0 · §3)으로 대신했다.
6. **겉모습 판단(사용자 검수)**: 몸이 어두운 보라(원본 텍스처 중앙값 그대로 - 구운 아틀라스 대조 확인) · 너클 자세 각 · 동작 속도 · 수정 Neon 밝기 · 눈 크기(약 1.1 stud). KIT 렌더에서 다리 돌판 일부가 엉덩이 쪽으로 가는 등 경계가 거친 곳이 있다(걸을 때 확인).
7. **가짜 원본 시험(v2)**: 옛 KIT 시험 메시(`bosses/section_guardian_v2` · 메타 `section_guardian_v2`)는 그대로 남겼다(삭제 금지 · 새 몸 = `section_guardian_v2m`).
8. **처음 Play 아틀라스 로드**: 업로드 직후 첫 Play에 아틀라스가 "생성 중"으로 한 번 실패했다가 다음부터 정상(로블록스 처리 지연).

## 5. Studio에서 직접 확인하는 순서(사용자 검수)

준비: Edit 모드에서 `game:GetService("ReplicatedStorage"):SetAttribute("TestSkipMainMenuUntil", os.time() + 3600)` → Play → 출력 창 `[ArtAssetLoader] 메시 캐시 …`(약 50초)까지 기다린다.

1. `/gg boss frame on` — 새 몸 시험 스위치(이 Play만 · 다음 보스 스폰부터).
2. `/gg boss frame` — 출력 `[BossFrame]`: 리그 검사 O · 빠짐 66줄(전용 32 · 빌림 0).
3. **전시(판정 없음)**: `/gg boss anim section_guardian all` — 등장 → 너클 대기 · 걷기 · 달리기 → 대표 스킬 10 → 변신 → 직립 → 직립 스킬 → 평타 · 잡기 · 기절(엉덩방아 + 별 · 소용돌이 눈) · 피격 · 처치.
   - 한 동작: `/gg boss anim section_guardian <동작> 3`(`heavy` · `shockwave` · `meteor` · `charge` · `cross` · `swipe` · `mirror` · `innerSmash` · `fists` · `orbs` · `earthSplit` · `transform` · `after:charge` · `stun` · `death` · `intro`). 끄기 `/gg boss anim off`.
   - 멈춰 보기: 클라 콘솔 `game.Players.LocalPlayer:SetAttribute("BossAnimFreeze", 2.3)`(동작 시작 뒤 그 초) · 풀기 `nil`.
4. **실전(전조 · 흰 테 · 몸 가장자리 반경)**: `/gg boss pattern section_guardian heavy` → 보스 쪽으로 걸어가면(약 25 stud) 반응 → 전조 원(17.3)과 두 주먹이 닿는 자리 · 흰 테 확인 → `innerSmash`(바닥 근접 원 14.2) · `swipe` · `mirror`도 같은 방법. 끄기 `/gg boss pattern off`.
5. 변신: 실전 중 `/gg bossdmg 0.55` → 진행 중 스킬이 끝나면 일어서며 가슴 치기 → 등 수정 폭발 → 직립 세트 · 3초 뒤 지반 붕괴(환경).
6. 비교: `/gg boss frame off` → 다음 스폰부터 옛 수호자.
7. (선택) 성능: 클라 콘솔 `SetAttribute("FakeParty", 3)` → `SetAttribute("PerfProbeStart", "이름|10")` → `[ArenaPerf]` 줄(Studio 창이 앞에 있어야 fps가 맞다).

검수 통과 뒤 실전 교체: `BossFrameworkData.live.section_guardian = "v2"`(별도 지시).
