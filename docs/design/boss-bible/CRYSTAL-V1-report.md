## 5. 미검증 · 결정 필요

1. **Studio Play 확인 안 함**(사용자 요청으로 사용 한도 전에 마무리) - 스폰 · 아틀라스 · 떠 있기 높이 · 스킬 동작 · fps(4인 PC/폰)는 Studio에서 첫 확인 필요. 에셋은 업로드 · 승인(Approved)까지 됨.
2. 종 치마 = 단색(드레스색 · 텍스처 없음 · 무늬 없음) - 밋밋하면 Meshy로 "닫힌 긴 드레스" 몸을 다시 받는 쪽이 낫다(사용자 판단).
3. 날개 가장자리 일부 검은 조각(굽기 거리 밖) · 홀 보석 결정이 감량으로 조각나 보임.
4. 날개 펼침 방향(ry 부호)은 하네스 수치만 - 실제로 펴지는지 접히는지 눈 확인.
5. 홀이 손에서 살짝 떨어져 보일 수 있음(손 끝 x 0.266 · 홀 중심 0.28).

## 6. Studio에서 직접 확인하는 순서

준비: Edit에서 `game:GetService("ReplicatedStorage"):SetAttribute("TestSkipMainMenuUntil", os.time() + 6 * 3600)` → Play → 메시 캐시 줄까지(첫 Play는 아틀라스 "생성 중"일 수 있음 - 한 번 더 Play).

1. `/gg boss frame on` → `/gg stage 15`(수정 여왕 차례가 아니면 `/gg boss pattern crystal_queen burst`) → `/gg god on` → 보스 앞 약 20 stud.
2. 다른 스킬: `drop` · `energyBeam` · `orgel` · `swipe`(12 stud 안) · `grab` · `spikes` · `shards` · `mirrorDash` · `mirror`.
3. 변신: `/gg boss pattern off` → `/gg bossdmg 0.55` → 날개를 펴며 떠오름 → 3초 뒤 수정 부수기.
4. 4인 성능: `/gg perf boss 4`(PC · 폰 설정).
5. 비교: `/gg boss frame off`.
