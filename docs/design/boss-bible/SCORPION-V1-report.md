## 8. 미검증 · 결정 필요

1. **처음 대면 난이도**(5절) - 피해 계수 0.70 적용 여부.
2. **색조 노브 값**: 기본 0(원본). 모래 쪽이 낫다면 `atlasTint` value = 1.
3. 4번째 다리 = 3번째 다리 복제(같은 모양 · 같은 각도 −32°) - 뒷다리가 몸 뒤 꼬리 밑으로 조금 나온다. 더 자연스럽게 하려면 Meshy에 4쌍 몸을 다시 받는 쪽.
4. 걸음 들림 0.8 stud(0.15 단위)로 낮다 - 잰걸음 느낌. 키우려면 `WALK.lift`.
5. 집게 가시(움직이는 손가락) 상자는 실측 추정 - 벌림 동작에서 집게 몸과 틈이 보이는지 눈 확인.
6. 변신 · 처치 · 기절 · 잠행(파고들기) 자세는 하네스(튐 0 · 접지)만 - Studio 실전으로 보지 않음.
7. 머리 · 집게 경계의 작은 검은 조각(외곽선 껍데기 겹침) 몇 개 남음.

## 9. Studio에서 직접 확인하는 순서

준비: Edit에서 `game:GetService("ReplicatedStorage"):SetAttribute("TestSkipMainMenuUntil", os.time() + 6 * 3600)` → Play → `[ArtAssetLoader] 메시 캐시` 줄까지(약 58초).

1. `/gg boss frame on` → (몇 초 뒤) `/gg boss pattern scorpion_queen clawSweep 20` → `/gg god on`. 명령은 한 줄씩.
2. 다른 스킬: `claw` · `swipe`(가까이) · `sting` · `stingJab` · `stab`(잠행) · `ambush` · `armadillo` · `grab` · `sandSearch`.
3. 걸음: `/gg boss pattern off` 뒤 보스에게서 멀어지면 따라옴 - 다리 1·3 / 2·4 교대.
4. 색조: 서버 명령 줄에서 `workspace:SetAttribute("BossAtlasTint", 1)` → 1번 다시(새 스폰부터 모래 쪽) · `nil` = 원래대로.
5. 변신: `/gg boss pattern off` → `/gg bossdmg 0.55`.
6. 비교: `/gg boss frame off` → 옛 전갈.

검수 통과 뒤 실전 교체: `BossFrameworkData.live.scorpion_queen = "v2"`(별도 지시).
