## 4. 결론(LOOK2로 넘김)
1. 단색 SmoothPlastic + Soft 조명 + 금속 반사 0 → 금속처럼 안 보인다. 재질 PBR만으로는 Soft에서 차이가 작다 → **색 지도(손그림 하이라이트 · 모서리 밝은 선 · 틈 그림자)를 알베도에 굽는 것**이 조명과 무관하게 효과가 있다(UV 필요).
2. 등급색이 몸 100% → 파워레인저(LOOK2 1번 색 구역 규칙).
3. 판 사이 맨살 → 바닥층 2D 옷(LOOK2 보정 1).
