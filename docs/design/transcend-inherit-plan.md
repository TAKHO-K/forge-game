## 사용자 원문 요지(10-03)

환생 뒤 태초 무기로 끝나면 아쉬우니 계승으로 초월 무기로 넘긴다. +30 달성 시 넘길 수 있고, 초월 무기를 얻으면 스테이지가 비약적으로 빨리 밀려야 한다(뚫리는 느낌 자체가 달라야). 고스테이지 몹 · 보스 공격 · 체력 · 방어를 조절하고, 몹 공격 조정이 필요하면 수련에 방어 수치를 추가 개방(골드 소모처). 무기 성능 + 직업 특성 진화(골드) + 수련 수치를 그에 맞춰 올린다. 일반 수련 50레벨 · 진화 최대 범위를 운 나쁜 유저도 +30에 닿는 지점까지 편하게 진행되게 확대(골드 → 빠른 돌파 → 골드 수급 확대의 선순환). 초월 무기를 들면 수련 51~100 = "고급 수련"(창은 같고 증가율이 다름) · 스테이지 15,000쯤이면 100레벨을 편하게 찍을 골드 배분 · 고스테이지 몹 · 보스 골드가 이와 맞는지 점 검증. 계승하면 초월 +0에서 시작 · 초월 +20까지 · 강화당 공격력 상승은 골드 소모량을 따라가 잉여 골드를 완벽히 관리. 무기 이펙트 고민. 보석 홈 광원(등급별 · 홈 위치별) 확인. 초월 보석은 반드시 계승 뒤 해금 · 계승 시 1개 제공 · 태초보다 강함 · 추출 가능. 운으로 얻은 좋은 옵션은 얻을 만하다. 모든 변수를 파악해 고스테이지 몹 체력 · 방어를 조절하고, 몹 정보 · 스탯이 즉시 정확한 수치로 반영되어야 한다.

## 요구(R)

- R1 태초 무기 +30 → 계승 가능
- R2 초월 +0 시작
- R3 계승 뒤 비약적 돌파
- R4 고스테이지 몹 · 보스 공격 · 체력 · 방어 재조정
- R5 필요 시 방어 수련 개방(골드 소모처)
- R6 무기 성능 + 직업 특성 진화 + 수련을 그에 맞춰 상향
- R7 수련 1~50 · 진화 확대(운 나쁜 P90 기준)
- R8 골드 선순환
- R9 고급 수련 51~100(초월 보유 시 · 같은 창 · 증가율 다름)
- R10 15,000쯤 100 완료
- R11 고스테이지 골드 점 검증
- R12 초월 강화 0~20
- R13 강화당 상승 = 골드 소모 비례 · 잉여 관리
- R14 무기 이펙트 조사
- R15 보석 홈 광원(등급 · 홈 위치) 확인
- R16 초월 보석 = 계승 뒤 해금(반드시)
- R17 계승 보상 초월 보석 1개
- R18 초월 보석 > 태초 · 추출 가능
- R19 운 좋은 옵션 허용
- R20 모든 변수 반영 몹 재조정
- R21 몹 정보 · 스탯 즉시 정확 반영.

## 결정(D)

- D1 계승 = 태초 +30(같은 직업) → 같은 직업 초월 +0 변환(무기 1개 유지) · +30 강화 이펙트는 외형으로 계속 선택 가능 · 확인 창 2단계 · 되돌리기 없음 · 서버 원자 처리 · 저장 버전 업.
- D2 알림 = 같은 서버 알림 + 칭호(예 "초월 계승자") · 세계 번호 · 전 서버 알림 · 명예의 전당은 드랍 초월만.
- D3 돌파 = 계승 직후 1,500 스테이지를 직전 속도 2~3배로 → 정상 복귀(P1에서 숫자 확정).
- D4 수련 1~50 · 진화 확대 = 운 나쁜 P90이 +30에 닿는 스테이지까지 자동 이동 "보통(1.0)"으로 정체 없음 · 캐주얼 32h · 초반 곡선 불변.
- D5 고급 수련 51~100 = 초월 보유 시만 · 총비용 ≈ 계승~15,000 누적 수입의 약 50% · 15,000에서 100 완료.
- D6 방어 수련 = 고급 수련 안 항목 · 위협 구간부터 · 피해 공식은 서버 · UI 한 함수.
- D7 초월 강화 0~20 = 확정 성공 · 골드만 · 하락/초기화 없음 · 공격력 1%당 골드 ∝ 시간당 수입.
- D8 완료 시점 = 고급 수련 100 ≈ 15,000 · 초월 +20 ≈ 25,300 · 상한 확장 대비 +21~ · 101~ 데이터 자리.
- D9 초월 보석 = 계승 뒤 해금 · 계승 보상 1개 · 이후 고스테이지 보스 희귀 드랍(태초 합성 보류) · 태초보다 강함.
- D10 운 좋은 옵션 허용 · 몹 기준 = 중앙값 빌드 · 운 빌드 이득 측정만.
- D11 몹 스탯 = 기준 빌드 표 + 돌파 계수 · 서버 · UI · 시뮬 같은 함수 · 30지점 정확도 하네스.
- D12 무기 이펙트 = 흑금 균열이 초월 +0 · 5 · 10 · 15 · 20에서 짙어짐 + 직업별 타격 1종 · 오라 금지 · 보스 경고 · 초월 드랍 연출 침범 금지.
- D13 보석 홈 광원 = 등급별 + 홈 위치별 · 장비 등급 핵심 보석(CoreGem)과 장착 보석(홈) 구분.
- D14 일정 = 출시 전 구현 + 기능 스위치.
- D15 2^53 = 소모처가 수입 비례 흡수 · 시간당 수입 1e15 근처면 숫자 압축 별도 검토.
- D16 초월 보석 보존 = 추출 100% 보존 · 무료 · 재장착 무제한 · 판매/분해 불가 · 기본 잠금 · 계정 귀속 · 장비 판매/분해 시 박힌 초월 보석 자동 반환(가방 가득이면 우편함) · 지급 감사 기록.
- D17 골드 지표 = 구간별 유입 · 소모 · 누적 보유 + "보유 시간"(보유 골드 ÷ 시간당 수입) ≤ 24~48h · 고스테이지 처치 골드 곡선도 조정 대상.

## 검증 기준

캐주얼 1,000 ≤ 32h · 상위 1% 25,300 ≥ 2,150h · 초반 곡선 불변 · 프로필 4종 · 돌파 D3 ±10% · 골드 예산 표 · 잉여율 · 보유 시간 · 2^53 · 고스테이지 점 검증 ±10%(도감 끔) · 몹 스탯 UI = 서버 = 시뮬(30지점 · 오차 0) · 운 빌드 · 곱셈 표 · 저장(버전 업 · 롤백 · 중복 계승 방지 · RequestGate · AuditTrail) · Play(/gg로 태초 +30 → 계승 → 초월 강화 → 고급 수련 → 초월 보석 → 고스테이지 몹 정보).

## P3 변경(10-04)

> 사용자 10-04 결정 · 원문 = `docs/phase/QUEUE-ALL9E1-prompt.md` 블록 0. 위 D1 · D7 · D12와 어긋나는 곳은 이 절이 우선한다.

- P3-1(결정 2 확정 = 옵션 A): 운 나쁜 유저 = 하락 방지를 켜지 않은 대가 → 강화 회복 보조 없음(기록만 · 구현 없음).
- P3-2(D1 변경): 계승 조건 = 그 직업의 **현재 무기**(태초든 아니든 · 환생 0회 유저의 기본 무기 포함) **+29 이상**.
  - +30을 찍은 뒤 계승 = "+30 증표" 보상: 무기 외형/이펙트 1종 영구 소유(치장 칸에서 켜고 끔 · 초월 무기에도 사용 · 판매 불가 · 저장 · 감사 기록).
  - +29에서 계승 = 증표 없음 → 확인 창 안내 "지금 계승하면 +30 증표를 받을 수 없습니다".
  - 히든 칭호: 계승 순간 환생 횟수 0 → "환생 없는 초월자"(en "Unreborn Transcendent") · 도감에서 얻기 전엔 "???".
