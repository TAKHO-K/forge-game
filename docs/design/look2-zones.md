## 1. 부위별 층(바깥 → 안)
| 부위 | ② 대검(8등급 공통 구조) | ④ 4직업(영웅 · 수정) | 등급색이 칠해지는 곳 |
|---|---|---|---|
| 가슴 | 판금 흉갑(등급색) + 금 테두리 + 가운데 문장 방패(돌출) + 가죽 X 끈 · 사슬 목 | 대검 = 판금 + 크리스털 / 쌍검 = 가죽 조끼 + 교차 벨트 / 활 = 누빔 조끼 + 후드 망토 / 치유사 = 로브 + 목깃 | 흉갑 판만(테두리 · 끈 · 천은 아님) |
| 어깨 | 둥근 판 2 ~ 3겹(아래로 작아짐) · 금 테두리 · 리벳 | 대검 = 겹판 · 쌍검 = 작은 판 + 망토 끝 · 활 = 가죽 보호대 · 치유사 = 천 어깨 | 겹판 바깥 면 |
| 팔 | 갬비슨(천) 소매 + 팔꿈치 가죽 | 같음(천 · 가죽) | 없음 |
| 허리 | 가죽 벨트 + 큰 금속 버클 + 아래로 판 2장 | 벨트 + 버클(직업 공통) | 허리 아래 판 2장 |
| 허리 아래 | 사슬 치마(회색) + 세트 천(앞 · 뒤 허리천) | 쌍검 = 허리천 · 활 = 짧은 망토 · 치유사 = 로브 자락 | 없음(세트 천 = 세트 색1) |
| 허벅지 · 무릎 | 바지(천) + 허벅지 판 · 무릎 판(작음) | 바지 + 무릎 판 | 허벅지 판 · 무릎 판 |
| 장갑 | 가죽 장갑 + 금속 커프(손목 테) + 손등 판 | 같음(손보다 얇게) | 커프 띠 |
| 신발 | 가죽 장화 + 금속 발등 판 + 정강이 커프 | 같음 | 커프 띠 |
| 망토 | 등 망토 = 세트 천(②: 이끼 초록 + 청동 테) | 대검 · 활 = 망토 / 쌍검 = 짧은 목도리 / 치유사 = 로브 | 없음(세트) |
| 테두리 · 리벳 · 버클 | 일반 ~ 영웅 = 강철 · 전설 이상 = 금(②에서 전설부터 금 테가 뚜렷) | 영웅 = 금빛 테(그림) → 규격은 강철(LOOK2 1번) | - |

- 바닥층(갬비슨 + 바지)이 늘 몸 전체를 덮고, 판금은 그 위에 "얹힌" 조각이다 - 판 사이로 보이는 것은 천 · 가죽이지 맨살이 아니다.
- 등급색 면적 = 흉갑 · 어깨 · 허리 판 · 허벅지/무릎 판 ≈ 보이는 면의 40 ~ 50%.
