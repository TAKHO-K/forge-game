# 이동 수치 · 맵 설계 기준표 v3 (MV1 · 2026-09-27 · v2 = M1-0)

M1 맵 그레이박스와 G2b 보스 난이도가 이 표를 기준으로 삼는다. 수치의 단일 출처는 `roblox/src/shared/data/MovementConfig.lua`이고, 계산식은 `shared/JumpMath.lua`(`maxReachStuds` · `airTrajectory` · `maxAirSeconds`)다. 파생값은 같은 식으로 계산했고(스크래치 `air.py` · 격자 48 = 검증 `M1-0(가)`와 ±0.01 안에서 같다), [실측]은 Studio Play에서 잰 값이다.

**v1(G2a)에서 바뀐 것**: 이단점프 상한형(발 최고 7.2 고정)을 **스택형 공중 점프**로 바꿨다(사용자 결정 - 겐지 · 한조식). 공중대시는 이제 공중 점프와 섞어 쓴다. 보스 아레나도 같은 규칙이다. 그래서 높이 · 간격 · "오를 수 없는 벽"이 전부 커졌다.

## v3 (MV1) - 바뀐 기준 요약

v3 값은 전부 데이터에서 계산한다: `JumpMath.dashRangeStuds` · `maxGapStuds` · `unjumpableGapStuds` · `maxClimbStuds` · `MoveRules.fallOutcome` · `MoveRules.s1Limits()`(S1 · BR1-4가 읽는 표). 아래 §0 ~ §9는 v2 기록이다 - **대시 16 · 못 넘는 틈 46은 v3에서 바뀌었다.**

### v3-5 해금 단계 · 도달성(MV1 보고서 §5)

- 환생 0 = 지상 점프 + 대시(공중 대시 1) / 1 = 공중 점프 1 + 공중 공격 / 2 = 활강 / 3 = 공중 점프 2 + 공중 3타 강공격 / 4 = 활강 +3초 · 공중 대시 ×1.25 / 5 = 무기 태초.
- 도달성 요약(환생 0): 필수 길 · 캠프 · 관문 = 걷기(O) · **A 둥지 33/33**(파트 0 - 바위 9곳 = 1단 점프 계단 `skill = "jump1"`(오름 6 · 간격 5) · 메사 · 피라미드 = B로 재분류) · B 2/20 · C 40/40 · 나무 1구간(정거장 1)만(2 ~ 6구간 직접 오르기 = 환생 1 - 정거장은 리프트가 레벨로 연다 · 유지) · 봉인 틈 선반 불가(태초 장갑 붙잡기면 가능 - 봉인 상자가 막는다).
- 해금 기준 = 계정 직업 중 최대 환생(`MoveTier` - 직업별 아님 · 유지).
- **태초 보유자 예외**(유지 - 지시 "극소수 허용"): 태초 신발(2단 대시) + 태초 장갑(붙잡기)이면 환생 0이어도 A · B 대부분에 닿는다(MV1 표 - A 34/35 · B 18/18 당시 기준). 맵 검사 · 보스 회피 부등식은 이 예외를 기준으로 삼지 않는다(해금 단계 표만).

## 3. 점프맵 난이도 표 v2 (걷기 16 기준)

여유 = 표 값의 약 80%(발판 끝을 겨누지 않게). 발판 폭 ≥ 4(쉬움) · 3(보통) · 2(어려움).

| 단계 | 수평 간격 | 높이 차(오름) | 필요한 기술 |
|---|---|---|---|
| 쉬움 | ≤ 6 | ≤ 5 | 1단만 |
| 보통 | 7 ~ 19 | ≤ 15 | **공중 점프 1 ~ 2회**(7 ~ 13 = 1회 · 14 ~ 19 = 2회 · 높이 6 ~ 10 = 1회 · 11 ~ 15 = 2회) |
| 어려움 | 20 ~ 34 | ≤ 15(대시 구간은 ≤ 7) | **점프 · 대시 조합**(공중 점프로 높이를 벌고 대시로 거리 - 대시는 구간당 1번) |
| (막음) | ≥ 46 | ≥ 23 | 지름길 방지 |

- 이속 상한(24)인 사람은 간격이 약 1.3 ~ 1.5배 쉬워진다. 경쟁형 보상이면 구간 안 걷기를 16으로 묶는 규칙이 필요하다(M1에서 결정).
- 점프력 옵션(+10%)은 높이 차를 1 ~ 2 늘린다 - 어려움의 높이 상한 15는 옵션이 있어도 한 단계 안이다(21.38 − 15 = 6.4 여유).

## 4. 둥지(높은 곳 보상 자리) 난이도 3단계

| 단계 | 가는 길 | 기준 |
|---|---|---|
| 걸어서 | 계단 · 경사로 | 턱 ≤ 2 · 경사 ≤ 45° · 폭 ≥ 4 |
| 연속 점프 | 1단 점프로 오르는 단을 이어서 | 단마다 높이 ≤ 5 · 간격 ≤ 6 · 전체 높이 제한 없음(단 수로 조절). 공중 점프를 쓰면 더 빨리 가는 지름길이 생긴다 - 지름길 허용이 기본 |
| 점프 · 대시 퍼즐 | 공중 점프 2회 + 대시가 모두 필요한 한 번의 도약을 1 ~ 2개 넣는다 | 오름 11 ~ 15 + 간격 20 ~ 30(표 2의 "공중 2 + 대시" 칸 80%) · 실패하면 한 단 아래로 떨어지게(처음부터가 아니게) |

- 둥지를 "공중 점프로도 못 가는" 자리로 두려면 오름 ≥ 23이거나 간격 ≥ 46이어야 한다(= 사실상 길이 없다). 그 대신 길을 막는 것은 높이 · 간격이 아니라 **천장(머리 위 막힘)**이 싸다 - 공중 점프는 천장에 막힌다.

## 5. 잠긴 구역 경계 = 관문 결계

공중 점프 2회면 발이 21.38(옵션 상한)까지 오르고, 대시 16이 더해진다. 높이만으로 막으려면:

| 방식 | 필요 높이 · 조건 | 평가 |
|---|---|---|
| 물리 벽(충돌) | **≥ 23**(발 21.38 + 여유) - 머리까지 막으려면 ≥ 27 | 23 ~ 27 높이 벽이 구역 둘레에 서면 풍경이 막힌다 |
| **투명 충돌 벽 + 보이는 결계(추천)** | 투명 충돌 36(맵 가장자리 장벽과 같은 값) + 발밑 높이 1 ~ 3의 빛나는 결계 선 · 문 | 넘을 길 0 · 풍경 그대로 · 결계 문에 "잠김 조건" 표시 |
| 밀어내기(서버) | 잠긴 구역 안에 있으면 들어온 쪽 경계 밖 + 4로 옮김(아레나 복귀 규칙과 같은 모양) | 순간이동 · 끼임 · 부정 대비 **보조**. 주 수단으로 쓰면 튕김이 잦다 |

- 추천 = 투명 충돌 36 + 결계 표시 + 서버 밀어내기 보조. 대시 광선(`DashEndpoint`)은 충돌 벽에서 멈춘다(기존).
