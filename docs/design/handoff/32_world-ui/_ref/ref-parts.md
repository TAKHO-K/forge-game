### 확인 f(32 spec 5번 "기능 자리 기둥"과 관련된 사실)
- 32 spec이 말하는 "청록 반투명 기둥"과 같은 모양의 파트는 마을에 하나 = `Workspace.TravelChannelLocal.Checkpoint_hub`(체크포인트 표시 수정 기둥 · 클라 전용 · Neon (120,220,255) · 2.2 × 7 × 2.2 · 마을 (84.1, −155.1)). **기능 자리가 아니다** - 프롬프트 없음 · 충돌 · 조회 · 터치 끔 · 체크포인트 발견은 서버 거리 판정(`server/Travel.lua:253`) → 숨겨도 기능 영향 없음.
- 마을 기능 자리(`Ground.Hub.Spot_*` 6 × 7 × 2)는 NPC · 소품 자리 7곳 = 이미 투명(보이지 않음) · 커뮤니티 광장 4자리 = 회색 상자로 보임(부화장 · 파티 게시판 · 순위판 · 명예의 전당). 기능 프롬프트는 Spot 파트에 붙고(`client/HubServices.client.lua:46-58`) 투명이어도 동작 → A안(숨김)은 투명도만 바꾸면 되고 파트를 지우면 안 된다.
