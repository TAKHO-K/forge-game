# 02 HUD — spec v5 (2026-10-05)

## 바뀐 것 (이 버전)
- **메뉴 재배치**(게임 실제 창 목록 기준): PC 왼쪽 "내 캐릭터 관리" 5칸(가방 G · 성장 C · 수련 U · 지도 M · 더보기) + 오른쪽 "진행 · 보상" 4칸(구역 선택 N · 퀘스트 J · 보상 · 상점) + 귀환 B(둥근 판). 더보기 = 파티 P · 도감 K · 순위 L · 펫 · 설정. 환생은 메뉴에서 뺌("환생 가능" 알림 ④).
- 폰 위 줄 = 가방 · 보상 · 더보기 3칸 · 더보기 안 = 자주 쓰는 것(구역 선택 · 수련 · 성장 · 퀘스트) + 나머지 8개 · 폰 내 체력 막대 왼쪽 290 → 310.
- 보상 = 받을 것이 있을 때만 빨간 점 · 상점 = 고정 1칸(압박 금지) · 보스전 = 오른쪽 열 숨김.
- PC 파티원 칸 위 672(보스전 440) · 미니맵(켰을 때) 자리 (1316, 20, 180).
- 잠긴 스킬 칸(큰 글자 "자물쇠 + 숫자") = 누르면 · PC는 마우스 올리면 "환생 N에서 열림" 말풍선 필수(`phone_05`).
- 키 칩 = 게임 키 글자(G C U M N J K P L B) 그대로 표시.
- 새 아이콘 `icon-zone` · `icon-training` · `icon-reward` · 다시 그린 스킬 아이콘 2장.


## 바뀐 것 (v4)
- 스킬 아이콘 16장 적용(Q/E/R/T 칸 = `icon-skill-<직업>-<칸>.png` · 목업은 검사).
- 글자 크기 새 값 반영 · 폰 "아주 크게"(1.3배) 목업 1장(`phone_04`).
- 큰 글자 규칙: 폰 메인 퀘스트 = 제목 줄 숨김 · 내용 두 줄까지 / 체력 막대 = 숫자 높이만큼 두꺼워짐 / 잠긴 스킬 칸 = 자물쇠 + 숫자만("2").
- PC 파티원 칸 시작 Y 548 → 568(메뉴 이름표가 커져서).
- 파일 이름 = 00 이름만(`menu-*` → `icon-*`).

> 파일 이름 = **00 디자인 시스템 이름만** 사용(예: `icon-bag.png` · `icon-atk-sword.png` · `icon-party2.png`). 묶음마다 다른 이름 없음.

> v3(이전) 변경: 메뉴 · HUD 아이콘을 **아이콘 v2(이 세계의 물건)** 로 교체 — 버튼 판 = 양피지 크림 B(진갈 테두리 3 + 입술). 파티 = PC는 얼굴 4개, 폰 44 버튼만 얼굴 2개(`icon-party2.png`). 공격 = 현재 직업 무기(대검 · 쌍검 · 활 · 지팡이 4장). 전투 버튼(공격 · Q/E/R/T · 대시 · 점프 · 고정) = 크림 원 판. **폰 버튼 좌표 · 크기는 v2 그대로.** 버튼 상태 5개 규칙 추가.

> v2 변경: 폰 오른쪽 아래 버튼 재배치 — 모든 버튼 사각 영역 사이 8px 이상 · 화면 오른쪽 · 아래 끝에서 8px 이상(측정 최소 간격 8). 공격 96이 가장 크고, 엄지 기준 호(Q 왼쪽 아래 → E 왼쪽 → R · T 위) 유지. T 칸 궁극기 게이지 링은 버튼 바깥 6px까지 그려지는 장식(터치 영역 아님).

> 캔버스 "장비 아바타 정비 가이드" › 페이지 **2번 HUD (확정)** 목업이 정답 그림. 이 목업은 **기본 배치** — 게임의 "HUD 직접 배치"(유저가 버튼 위치 옮기기) 기능은 그대로 유지하고, 유저가 옮긴 위치가 있으면 그것이 우선.

## 원칙
- 좌표 = 기준 해상도 px: PC 1920×1080 · 폰 800×360. 1번 화면 묶음과 같은 스케일 방식.
- **단축키는 새로 정하지 않음.** 목업의 "키" 칩 = 게임 현재 키를 게임 데이터 기준으로 붙일 자리. Q · E · R · T는 칸 이름. 폰은 키 칩 없음.
- 더미: 전사 R 스킬 이름("[R 스킬 미정]"), 스킬 아이콘, 파티원 이름, 퀘스트 문구, "탐험가123" 등 → 게임 데이터로 교체.
- 색 · 글꼴 토큰은 1번 화면 묶음과 동일. 추가: 내 체력 `#3FC97A`(바탕 `#14321F`) · 보스 체력 `#F2453D`(바탕 `#3A1416`) · 게이지 `#8FD8FF` · 경고 깜빡 `#FFC83D` · 궁극기 `#FFE7A3` · 전 서버 배너 `#202127` + `#D8B96E`.

## 로블록스 구현 메모
- 체력 · 보스 막대 = Frame + UIGradient + UICorner(1,0). 원형 쿨다운 · 활강 링 = 원형 진행 이미지(반원 2장 회전 또는 UIGradient Transparency). T 게이지 = UIStroke + UIGradient(Transparency 키포인트).
- 캐릭터 옆 점 · 링 = BillboardGui(AlwaysOnTop, 캐릭터 Attachment 기준) — 쓸 때만 Enabled.
- 파티원 체력 · 쓰러짐 = 서버 값 복제(Attribute 등) → 클라이언트 표시.
- 폰 기본 점프 버튼만 숨기는 방법은 현재 API로 확인(조이스틱은 유지).
- **HUD 직접 배치 기능 유지** — 이 문서 좌표 = 기본값(리셋 시 돌아갈 위치).

## 글꼴 메모

목업 PNG의 숫자 · 영문 = Fredoka, 한글 = Noto Sans KR(목업용). 게임에서는 한글 = 로블록스 기본 글꼴 Bold, 숫자 · 영문 = 카툰 글꼴. 메뉴 아이콘 = 색이 들어간 카툰 그림(icon PNG 그대로) · 버튼 판 = `btn-plate-*` 9-slice(양피지 크림). 기능 계열색 바탕은 폐기.
