# 02 HUD v5 — checklist

실제 Play 캡처를 `mockups/` 같은 이름 옆에 나란히 두고 확인.

- [ ] 폰 왼쪽 아래 조이스틱 영역(아래 약 40%)에 아무 버튼 · 파티원 칸도 없음
- [ ] 폰 오른쪽 아래: 공격(688,250,96) · Q(616,294) · E(608,222) · R(672,186) · T(736,186) · 점프(536,286,64) · 대시(544,198,52) · 고정(616,160,44) — v2 좌표 그대로, 사각 영역 간격 8px 이상
- [ ] 메뉴 아이콘 = 아이콘 v2 · 판 = 양피지 크림 · 폰 44에서도 무엇인지 보임
- [ ] 폰 위 줄 3칸 = 가방 · 보상 · 더보기 · 더보기 첫 줄 = 구역 선택 · 수련 · 성장 · 퀘스트
- [ ] 공격 버튼 그림 = 현재 직업 무기로 바뀜
- [ ] 파티 2~4인일 때만 파티원 칸 · 쓰러짐이 한눈에 보임 · 보스전에도 보임
- [ ] 퀘스트: PC 상시 · 폰 접기/펴기 · 보스전 숨김
- [ ] 점프 점 · 활강 링은 쓸 때만
- [ ] 잠긴 스킬 칸 문구 = "환생 N에서 열림"
- [ ] 키 칩 글자 = 게임 현재 키
- [ ] 전투 버튼은 누르는 순간 발동 · 일반 버튼은 뗄 때 발동 · 밖으로 끌면 취소
- [ ] **옛 흰 기호 아이콘 없음**
- [ ] Q/E/R/T 그림 = 현재 직업 스킬 아이콘 · T 금 고리
- [ ] 글자 크기 1.3배: 퀘스트 두 줄 · 체력 숫자 안 잘림 · 잠긴 칸 숫자만 · 버튼 크기 그대로
- [ ] 전투 HUD 위 빨강 = 알림 점 + 보스 체력 막대만
- [ ] 메뉴 항목 = 게임 실제 창 · 키 칩 = 게임 키
- [ ] PC 오른쪽 열이 재화 · 퀘스트 칸 · 드랍 알림 · 미니맵과 안 겹침 · 보스전에 숨김
- [ ] 보상 점 = 받을 것이 있을 때만 · 상점 압박 표시 없음
- [ ] 귀환 = 둥근 판(창 버튼과 다른 모양)
- [ ] 잠긴 스킬 칸 누르면(PC 마우스 올리면) "환생 N에서 열림" 말풍선
- [ ] HUD 직접 배치로 옮긴 위치가 유지되고, 리셋하면 이 기본 배치로 돌아옴
