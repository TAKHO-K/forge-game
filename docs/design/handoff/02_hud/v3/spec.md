# 02 HUD — spec v3 (2026-10-05)

> v3 변경: 메뉴 · HUD 아이콘을 **아이콘 v2(이 세계의 물건)** 로 교체 — 버튼 판 = 양피지 크림 B(진갈 테두리 3 + 입술). 파티 = PC는 얼굴 4개, 폰 44 버튼만 얼굴 2개(`menu-party-phone.png`). 공격 = 현재 직업 무기(대검 · 쌍검 · 활 · 지팡이 4장). 전투 버튼(공격 · Q/E/R/T · 대시 · 점프 · 고정) = 크림 원 판. **폰 버튼 좌표 · 크기는 v2 그대로.** 버튼 상태 5개 규칙 추가.

> v2 변경: 폰 오른쪽 아래 버튼 재배치 — 모든 버튼 사각 영역 사이 8px 이상 · 화면 오른쪽 · 아래 끝에서 8px 이상(측정 최소 간격 8). 공격 96이 가장 크고, 엄지 기준 호(Q 왼쪽 아래 → E 왼쪽 → R · T 위) 유지. T 칸 궁극기 게이지 링은 버튼 바깥 6px까지 그려지는 장식(터치 영역 아님).

> 캔버스 "장비 아바타 정비 가이드" › 페이지 **2번 HUD (확정)** 목업이 정답 그림. 이 목업은 **기본 배치** — 게임의 "HUD 직접 배치"(유저가 버튼 위치 옮기기) 기능은 그대로 유지하고, 유저가 옮긴 위치가 있으면 그것이 우선.

## 원칙
- 좌표 = 기준 해상도 px: PC 1920×1080 · 폰 800×360. 1번 화면 묶음과 같은 스케일 방식.
- **단축키는 새로 정하지 않음.** 목업의 "키" 칩 = 게임 현재 키를 게임 데이터 기준으로 붙일 자리. Q · E · R · T는 칸 이름. 폰은 키 칩 없음.
- 더미: 전사 R 스킬 이름("[R 스킬 미정]"), 스킬 아이콘, 파티원 이름, 퀘스트 문구, "탐험가123" 등 → 게임 데이터로 교체.
- 색 · 글꼴 토큰은 1번 화면 묶음과 동일. 추가: 내 체력 `#3FC97A`(바탕 `#14321F`) · 보스 체력 `#F2453D`(바탕 `#3A1416`) · 게이지 `#8FD8FF` · 경고 깜빡 `#FFC83D` · 궁극기 `#FFE7A3` · 전 서버 배너 `#202127` + `#D8B96E`.

## 요소 규칙
| 요소 | 규칙 |
|---|---|
| 메뉴(PC) | 왼쪽 세로: 가방 · 성장 · 지도 + 더보기(파티 · 펫 · 도감 · 순위 · 환생 · 귀환 · 상점 · 설정). 72px, 알림 = 빨간 점 + 숫자 |
| 메뉴(폰) | 로블록스 버튼 자리 오른쪽 위 줄에 **가방 · 더보기 2개만**(44). 성장 · 지도 등은 더보기 안. 왼쪽 아래 조이스틱 영역과 겹치지 않음 |
| 가방 아이콘 | **전사의 가죽 배낭**(금 버클) — `menu-backpack.png` |
| 파티원 | 파티 2~4인일 때만. 나를 뺀 1~3칸: 작은 직업 얼굴 + 이름 + 체력바. **쓰러짐** = 얼굴 흑백 + "쓰러짐" 태그 + 노랑 테두리. 보스전에도 표시. PC = 왼쪽 메뉴 아래(270폭), 폰 = 왼쪽 위(176폭 · 한 줄 28, 조이스틱 영역 위) |
| 메인 퀘스트 | 1줄 + [길 안내] 켜기(44). PC = 재화/스테이지 아래 상시(380폭). 폰 = 접힘(퀘스트 버튼 44) ↔ 펼침(262폭: 접기 · 내용 · 길 안내). **보스전 숨김** |

| 대시 | 버튼 둘레 원형 쿨다운 + 버튼 아래 충전 점. 따로 떠 있는 게이지 없음 |
| 폰 조작 | 이동 = 로블록스 기본 조이스틱. **기본 점프 버튼 숨김**(3단 점프 · 활강). 오른쪽 아래: 공격 96(가장 크게) · Q E R T 56 · 점프 64 · 대시 52 · 고정(락온) 44 |

## 로블록스 구현 메모
- 체력 · 보스 막대 = Frame + UIGradient + UICorner(1,0). 원형 쿨다운 · 활강 링 = 원형 진행 이미지(반원 2장 회전 또는 UIGradient Transparency). T 게이지 = UIStroke + UIGradient(Transparency 키포인트).
- 캐릭터 옆 점 · 링 = BillboardGui(AlwaysOnTop, 캐릭터 Attachment 기준) — 쓸 때만 Enabled.
- 파티원 체력 · 쓰러짐 = 서버 값 복제(Attribute 등) → 클라이언트 표시.
- 폰 기본 점프 버튼만 숨기는 방법은 현재 API로 확인(조이스틱은 유지).
- **HUD 직접 배치 기능 유지** — 이 문서 좌표 = 기본값(리셋 시 돌아갈 위치).

## 버튼 상태 (00 디자인 시스템과 같음)

- 버튼 그림 = `assets/btn-<종류>-<상태>.png` 9-slice(원본 2배 · SliceScale 0.5). 상태 = normal · hover(PC) · pressed · disabled. 선택 테두리 = `focus-ring-*.png`를 버튼 바깥 3px에 겹침(게임패드 · 키보드만).
- 누름 0.06초(Quad Out): UIScale 1 → 0.95 · pressed 이미지(약 10% 어둡게) · 입술 4 → 2px · 내용 y +2. 떼면 0.10초(Back Out)로 살짝 튀며 1.0.
- **일반 버튼 = 버튼 위에서 뗄 때만 발동.** 누른 채 밖으로 끌면 누름 모양이 풀리고 떼도 발동 안 함 · 다시 들어오면 누름 복귀 · 꾹 눌러도 발동 안 함. 스크롤 목록 안 버튼은 8px 넘게 끌면 취소. 비활성 = 회색 · 누르면 x ±4px 흔들림(0.24초).
- 자세한 수치표 · SliceCenter = `handoff-00-design-system-v1` spec.
- **전투 버튼(공격 · Q/E/R/T · 대시)은 누르는 순간 발동** — 누름 모양은 같음. 쿨타임 중 누름 = 비활성 흔들림.

| `focus-ring-r12.png` | 120×120 | `Rect(40, 40, 80, 80)` |
