# 01 메인 메뉴 v3 — checklist

실제 Play 캡처를 `mockups/` 같은 이름 옆에 나란히 두고 확인.

- [ ] PC · 폰 모두 얼굴 · 초월 대검이 이어하기 창에 안 가려짐
- [ ] 왼쪽 위 로블록스 버튼 자리 비어 있음
- [ ] 폰 모든 버튼 44px 이상 · 글자 12 이상
- [ ] 캐릭터 0개 → [시작하기] → 바로 직업 선택 · [직업 선택] 버튼 숨김
- [ ] 마지막 캐릭터가 맨 위 · 선택 · 두 번 눌러 시작 · 같은 직업 2개일 때만 ① ②
- [ ] 보관 확인 창 첫 포커스 = [취소], Enter = 취소
- [ ] 칸 꽉 참 → 직업 선택 구경 모드(띠 · 확정 비활성)
- [ ] 설정 문구 1회만, 폰은 탭으로 즉시 넘김
- [ ] 이어하기 카드 무기 = 그 캐릭터의 장착 무기 아이콘(게임 데이터)
- [ ] 직업 선택 = 2D 전설 일러스트만 · 직업 이름 · 스킬 · 수치는 게임 데이터
- [ ] 카드 목록 = ScrollingFrame, 폰에서 아래 칸이 스크롤로 보임
- [ ] **아이콘 v2만 쓰임 — 옛 흰 기호(흰 X · 흰 자물쇠 · 흰 꺾쇠 등) 없음**
- [ ] 버튼 5상태: 누름 = 0.95 + 어둡게 + 입술 2px 줄어듦이 한눈에 보임 · 떼면 살짝 튀며 복귀
- [ ] 누른 채 밖으로 끌면 누름 풀림 · 떼도 발동 안 함 · 목록 안 카드는 끌어서 스크롤하면 취소
- [ ] 게임패드 · 키보드로 고르면 흰 선택 테두리
- [ ] 16:9 · 4:3 · 폰에서 전사 얼굴 · 초월 대검이 메뉴 · 이어하기 창 · 그라데이션에 가려지거나 잘리지 않음(창 열려도)
- [ ] 좁은 창에서 이어하기 창 열면 메뉴 패널 숨김 · X로 복귀
- [ ] 글자 크기 1.3배에서 카드 글자 잘림 없음(카드 높이 늘고 목록 스크롤)
