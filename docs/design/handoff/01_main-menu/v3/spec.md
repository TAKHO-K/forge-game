# 01 메인 메뉴 · 이어하기 · 직업 선택 — spec v3 (2026-10-05)

## 바뀐 것 (이 버전)
- **키 아트 초점 규칙** 추가(초점 = 원본 (850, 500) · 지킬 영역 = 얼굴 + 초월 대검) — 아래 "키 아트 초점" 절 · 비율별 목업 3장(`pc_08` · `pc_09` · `phone_08`).
- 좁은 창(4:3 등): 이어하기 창이 열리면 메뉴 패널을 숨기고 창을 왼쪽(x 24)으로.
- 글자 크기 새 값 반영(폰 caption 14 · body 16 등) — 모든 목업 다시 그림.
- 글자 크기 "아주 크게"(1.3배) 폰 목업 1장(`phone_09`) — 카드 높이가 늘고 목록은 스크롤.
- 파일 이름 = 00 이름만.

> 파일 이름 = **00 디자인 시스템 이름만** 사용(예: `icon-bag.png` · `icon-atk-sword.png` · `icon-party2.png`). 묶음마다 다른 이름 없음.

> v2(이전) 변경: 아이콘을 **아이콘 v2(이 세계의 물건 · 굵은 외곽선 카툰)** 로 교체(닫기 · 자물쇠 · 더하기 · 더보기 · 보관 · 뒤로 · 정보 · 별). 옛 흰 기호 아이콘은 쓰지 않음. 버튼 = 9-slice 상태 이미지 5개 규칙(00 디자인 시스템). ⋯ 버튼 = 양피지 크림 판 B. 화면 배치 · 좌표 · 동작은 v1과 같음.

> 캔버스 "장비 아바타 정비 가이드" › 페이지 **1번 화면 · 메인 메뉴 (확정)** 의 목업이 정답 그림. 이 문서는 그 목업을 로블록스로 옮길 때 필요한 숫자 · 규칙 · 동작만 모은 것.

## 범위와 원칙

- 이번 묶음: 메인 메뉴, 이어하기 창(캐릭터 카드 목록), 보관 확인 창, 직업 선택(새 캐릭터 · 구경 모드), 첫 실행 설정 문구.
- 직업 선택은 2D 전설 일러스트만 크게 — 내 아바타 미리보기 없음(10-05 확정).
- 다음 묶음으로 미룸: 보관함 화면, 스킬 아이콘, 치유사 · 도적 전설 그림(지금은 임시 실루엣).
- 좌표는 **기준 해상도 px**: PC 1920×1080, 폰 800×360(가로). 원점 = 화면 왼쪽 위, (X, Y, W, H).
- 구현 권장(제안): PC · 폰 레이아웃을 따로 두고, 루트 Frame에 UIScale = min(화면W/기준W, 화면H/기준H). 폰 판정 = UserInputService.TouchEnabled 이고 KeyboardEnabled 아님(또는 화면 높이 기준). 로블록스 상단 바 Inset(IgnoreGuiInset) 처리 방식은 실제 기기에서 확인 필요.
- 직업 이름 · 스킬 · 난이도 · 성향은 **가안**. 게임 데이터 테이블의 실제 이름 · 수치로 교체하고, 화면은 데이터를 읽어 그릴 것(하드코딩 금지).

## 상태별 동작

| 상황 | 동작 |
|---|---|
| 캐릭터 0개 | 주 버튼 = **[시작하기]**(부제 없음) → 이어하기 창 없이 바로 직업 선택(빈 칸 4). "저장된 캐릭터 없음" 화면 없음 |
| 캐릭터 0개 · 메뉴 | **[직업 선택] 버튼 숨김** — [시작하기]와 같은 곳으로 가므로 |
| 캐릭터 1개 이상 | 주 버튼 = **[이어하기]** + 부제(마지막 캐릭터 · Lv · 최고 스테이지) |
| [이어하기] 누름 | PC: 메뉴 폭 440→300, 창이 오른쪽에서 펼침(X −40→0, 투명 1→0, 0.25초 Quad Out). 폰: 메뉴 숨김 → 같은 자리에 창, 왼쪽 위 [<]로 복귀 |
| 창 열림 | 마지막 플레이 캐릭터 맨 위 + 선택 상태(노랑 테두리 3 + "한 번 더 누르면 시작") |
| 카드 누름 | 선택만 바뀜. **같은 카드를 한 번 더 누르면 시작** |
| 빈 칸 누름 | 직업 선택(새 캐릭터) |
| 잠긴 칸 | 누를 수 없음. "새 직업 출시 때 열림"(날짜 없음). 출시 직업 수 + 1 칸만 표시 |
| 칸 수 | = 출시된 직업 수(지금 4). 어느 칸이든 아무 직업. 같은 직업 2개 이상이면 "전사 ①" "전사 ②"(1개면 번호 없음) |
| 카드 [⋯] | 메뉴 [보관](회색) → 보관 확인 창 |
| 보관 확인 창 | 합쇼체. [취소](왼쪽, **기본 선택 = 첫 포커스 · Enter**) / [보관](오른쪽, 회색 보조). 삭제 아님 — 칸이 비워지고 [보관함]에서 되돌림 |
| [보관함] | 창 아래 버튼 + 보관 수. 화면은 다음 묶음. 되돌리기는 빈 칸 필요 |
| 메뉴 [직업 선택] · 빈 칸 있음 | 직업 선택(새 캐릭터) |
| 메뉴 [직업 선택] · 칸 꽉 참 | **구경 모드**: 맨 위 띠 "빈 칸이 없어 새 캐릭터를 만들 수 없습니다 · 캐릭터를 보관하면 칸이 생깁니다", 그림 · 정보는 보임, [○○로 시작]만 비활성(자물쇠). 메뉴 버튼 오른쪽에 "빈 칸 없음 · 구경" |
| 직업 선택 확정 | [○○로 시작](노랑 주 버튼) → 캐릭터 생성 → 게임 시작 |
| 첫 실행 설정 문구 | 1회만(저장값). PC = 메뉴 아래 3초 뒤 페이드. 폰 = 전체 덮개, **화면 아무 데나 탭하면 바로** 메뉴로 |

## 배경 · 가리지 않기

- 키 아트 = menu_keyart_v2(1536×1024). 로블록스 이미지 1장 최대 1024 → **좌 · 우 768×1024 두 장**(`assets/keyart-v2-left.jpg` · `assets/keyart-v2-right.jpg`)으로 나눠 나란히 배치.
- PC: 이미지 영역 X 300 · Y 0 · W 1620 · H 1080 (좌 810 + 우 810). 폰: X 262 · W 540 · H 360 (좌 270 + 우 270).
- 이미지 왼쪽 22%는 투명 → 불투명 페이드(이미지 UIGradient Transparency), 그 위에 #0E1120 덮개 Frame(UIGradient Transparency: 0→0.05, 0.20→0.14, 0.38→0.55, 0.50→1). 맨 뒤 바탕 #1E3050→#15203A.
- 가리지 않을 영역(v2 기준): PC 얼굴 X≈1165, 초월 대검 X≈1200~1640 · Y≈640~800 / 폰 얼굴 X≈550, 대검 X≈564~. 이어하기 창 오른쪽 끝 PC 1012 · 폰 482. 확인 창은 잠깐 뜨는 모달이라 예외.
- 왼쪽 위 비움: PC 132×60, 폰 140×52(로블록스 기본 버튼).

- 이어하기 창의 캐릭터 카드 목록(카드 · 빈 칸 · 잠긴 칸)은 **ScrollingFrame**. 아래 좌표표의 "목록 안 X/Y" = 목록 왼쪽 위 기준 좌표(이게 구현 기준). "X/Y" 열은 스크롤 0일 때의 화면 좌표.
- 폰은 창 높이(290)보다 목록이 길어 아래 칸은 **목록 아래로 넘침 — 스크롤해야 전부 보임**(비고 표시 행). PC는 4칸 + 잠긴 칸이 다 보이지만 같은 ScrollingFrame 구조(직업이 늘면 스크롤).

## 키 아트 초점 (10-05)
- 원본 `keyart_v2.jpg` 1536×1024 · **초점 = 전사 얼굴 (850, 500)** · **지킬 영역 = (780, 400) ~ (1270, 770)**(얼굴 + 초월 대검).
- 크기: s = 화면 높이 / 1024(높이를 꽉 채움). 지킬 영역 너비 = 490 × s.
- 빈 구역 = [가장 넓은 UI 오른쪽 + 24, 화면 오른쪽 − 24]. 가장 넓은 UI = **이어하기 창**(PC 오른쪽 끝 1012 · 폰 482) — 창이 열리고 닫혀도 그림은 같은 자리(점프 없음).
- 가로 위치: 지킬 영역 가운데 = 빈 구역 가운데 → 이미지 X = 빈 구역 가운데 − 1025 × s. 이미지가 화면 오른쪽을 못 덮으면 X = 화면 너비 − 1536 × s.
- 빈 구역이 지킬 영역보다 좁으면(PC 1080 높이 기준 화면 너비 1577 미만 · 4:3 등) = **좁은 창 모드**: 이어하기 창이 열릴 때 메뉴 패널을 숨기고 창을 x 24로(오른쪽 끝 604). 닫기 X로 메뉴 복귀.
- 어두운 그라데이션(왼쪽 → 오른쪽)은 빈 구역 왼쪽 − 24에서 끝남 · 이미지 왼쪽 가장자리 페이드는 지킬 영역 왼쪽 − 24 전에 끝남.
- 결과값(목업): PC 16:9 1920×1080 → s 1.055 · 이미지 X 385 · 지킬 영역 화면 (1208, 422)~(1724, 812). 4:3 1440×1080(좁은 창 모드) → X −59 · 영역 (764, 422)~(1280, 812). 폰 19.5:9 780×360 → s 0.352 · X 271 · 영역 (545, 141)~(717, 271). 폰 800×360 → X 281.
- 실기기 비율이 달라도 같은 식으로 계산(하드코딩 금지). 목업의 하늘색 점선 = 지킬 영역 · 십자 = 초점 · 아래 막대 = 빈 구역(가이드 · 게임에는 없음).
