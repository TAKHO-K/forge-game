# 01 메인 메뉴 — checklist

실제 Play 캡처를 `mockups/` 같은 이름 옆에 나란히 두고 확인.

- [ ] PC · 폰 모두 얼굴 · 초월 대검이 이어하기 창에 안 가려짐
- [ ] 왼쪽 위 로블록스 버튼 자리 비어 있음
- [ ] 폰 모든 버튼 44px 이상 · 글자 12 이상
- [ ] 캐릭터 0개 → [시작하기] → 바로 직업 선택
- [ ] 마지막 캐릭터가 맨 위 · 선택 · 두 번 눌러 시작
- [ ] 같은 직업 2개일 때만 ① ② 표시
- [ ] 보관 확인 창 첫 포커스 = [취소], Enter = 취소
- [ ] 칸 꽉 참 → 직업 선택 구경 모드(띠 · 확정 비활성)
- [ ] 설정 문구 1회만, 폰은 탭으로 즉시 넘김
- [ ] 노랑 버튼은 시작/구매에만 쓰였는지
- [ ] 캐릭터 0개일 때 [직업 선택] 버튼이 숨겨짐
- [ ] 이어하기 카드 무기 = 그 캐릭터의 장착 무기 아이콘(게임 데이터) · 틀 · 강화 표시 규칙 그대로
- [ ] 직업 선택에 내 아바타 미리보기 없음 · 2D 전설 일러스트만 크게
- [ ] 직업 이름 · 스킬 · 수치가 게임 데이터에서 읽힘(하드코딩 아님)
