## 바뀐 것 (이 버전)
- 글자 크기 새 값 반영(폰 caption 14 · body 16 등) — 모든 목업 다시 그림.
- 폰 가방 왼쪽 칸: 글자가 커져 "공격력 숫자 한 줄 + 세트 한 줄"로 줄임.
- 글자 크기 "아주 크게"(1.3배) 폰 목업 1장(`phone_05`).
- 보석함 칸 수 = 게임 데이터(목업 "24개" = 예시).
- 빨강 사용 제한: 위험 버튼([분해])은 확인 창 · 시트 안에서만 빨강. 가방 화면의 [분해] [판매]는 보조(남색).

> 파일 이름 = **00 디자인 시스템 이름만** 사용(예: `icon-bag.png` · `icon-atk-sword.png` · `icon-party2.png`). 묶음마다 다른 이름 없음.

> 캔버스 "장비 아바타 정비 가이드" › 페이지 **3번 가방 · 보석 홈 (확정)** 목업이 정답 그림. 아이콘 = 아이콘 v2 · 버튼 = 버튼 상태 5개 규칙(00 디자인 시스템).

## 원칙
- **숫자와 이름은 전부 게임 데이터에서 읽음.** 목업 숫자 옆 "예시" = 게임이 계산하는 값(spec에서 "값 = 데이터"). 장비 이름 · 옵션 · 세트 · 직업 특화 보석 이름도 데이터.
- 좌표 = 기준 해상도 px: PC 1920×1080 · 폰 800×360. 1번 · 2번 묶음과 같은 스케일 방식.
- 색 · 글꼴 토큰 = 00 디자인 시스템. 그림자 · 흐림 없음.
- 상점 · 패스 안내 문구 = "더 화려하게 / 힘 아닌 편의"까지만. "X2 · 더 강하게" 같은 표현 · 그림 금지.

## 로블록스 구현 메모
- 칸 = ImageButton(`btn-card-*` 9-slice) + 아이콘 ImageLabel · 목록 = ScrollingFrame + UIGridLayout(CellSize PC 88 / 폰 56 · CellPadding 10 / 8) · AutomaticCanvasSize = Y.
- 칸 늘리기 안내 버튼 = 목록 마지막 칸 다음 행(ScrollingFrame 안) · 패스 보유 시 Visible = false.
- 홈 = 원형 ImageButton + UIStroke(상한 등급색, 두께 PC 8 · 폰 5) · 잠김 = 회색 + `icon-lock.png`.
- 무기 미리보기 = ViewportFrame 1개(회전) — 목업 칼 그림은 자리 표시.
- 분해 · 판매 · 자동 정리 = 박힌 보석 반환과 장비 삭제를 한 번의 저장 안에서(ALL10 홈 규칙).

## 버튼 상태 (00 디자인 시스템과 같음)

- 버튼 그림 = `assets/btn-<종류>-<상태>.png` 9-slice(원본 2배 · SliceScale 0.5). 상태 = normal · hover(PC) · pressed · disabled. 선택 테두리 = `focus-ring-*.png`를 버튼 바깥 3px에 겹침(게임패드 · 키보드만).
- 누름 0.06초(Quad Out): UIScale 1 → 0.95 · pressed 이미지(약 10% 어둡게) · 입술 4 → 2px · 내용 y +2. 떼면 0.10초(Back Out)로 살짝 튀며 1.0.
- **일반 버튼 = 버튼 위에서 뗄 때만 발동.** 누른 채 밖으로 끌면 누름 모양이 풀리고 떼도 발동 안 함 · 다시 들어오면 누름 복귀 · 꾹 눌러도 발동 안 함. 스크롤 목록 안 버튼은 8px 넘게 끌면 취소. 비활성 = 회색 · 누르면 x ±4px 흔들림(0.24초).
- 자세한 수치표 · SliceCenter = `handoff-00-design-system-v1` spec.
