# 03 가방 · 장비창 + 보석 홈 v1 — checklist

실제 Play 캡처를 `mockups/` 같은 이름 옆에 나란히 두고 확인.

- [ ] 가방 칸 수 = 데이터(35 / 55 / 75) · PC 7열 · 폰 5열 · 넘치면 스크롤
- [ ] 기본 35칸 = PC 한 화면 5줄에 다 보임
- [ ] 칸 늘리기 안내 = 목록 끝 작은 글자 1개 · 패스 보유하면 안 보임 · 잠긴 칸 줄 없음
- [ ] 숫자 · 이름 · 효과 수치 = 게임 데이터/계산(하드코딩 없음)
- [ ] 보석 종류 8 + 직업 특화 2 · 직업 특화 이름 = 스킬 이름
- [ ] 보석 등급 영웅~초월만(일반 · 희귀 보석 없음)
- [ ] 보석 아이콘 = 몸통 + 문양 2겹 · 문양만 바꿔 끼워짐
- [ ] 홈 n = 환생 n에 열림 · 잠긴 홈 "환생 N에서 열림"
- [ ] 홈 상한 1 태초 · 2 영웅 · 3 전설 · 4 유물 · 5 고대(데이터) · 계승 시 태초 홈 → 초월 홈
- [ ] 홈 자리: 1번 가장 덜 띔 → 5번 꼭대기
- [ ] "N번 홈에 들어가는 것만" 토글이 상한 이하만 보여 줌
- [ ] 등급 골라 분해: PC 640×480 창 · 폰 아래 시트 · [취소] 기본 · 전설 이상 일괄 불가 · 잠금 · 장착 제외 · 보석 반환
- [ ] 잠긴 장비 [분해] [판매] 회색 · 누르면 흔들림
- [ ] 태초 각인 · [각성]은 태초에만
- [ ] 폰 모든 버튼 44 이상 · 창 머리 48
- [ ] 버튼 5상태 · 뗄 때 발동 · 끌어내면 취소 · 목록 끌기 = 취소
- [ ] 상점 · 패스 문구에 "X2 · 더 강하게" 없음
- [ ] 옛 흰 기호 아이콘 없음
