# 보스 전면 개편 설계 (BR1 · 2026-09-25)

이 문서가 BR1 구현의 기준이다. 원칙 = `boss-rules.md` §1 무게 3단계 · §2 공중 전제. 이동 수치 = `movement-metrics.md` v2. 수치의 단일 출처는 구현 뒤 `roblox/src/shared/data/BossData.lua`다 - 여기 표는 설계 값이고, 구현 중 바뀐 값은 §9 변경 기록에 남긴다.

## 0. 읽는 법 · 공통 기준

| 항목 | 값 | 비고 |
|---|---|---|
| 회피 부등식 | 전조 ≥ 0.5 + (회피 거리 ÷ 16) × 1.25 | 거리 5 → 0.89초 · 7 → 1.05 · 10 → 1.28 · 15 → 1.67 · 20 → 2.06 · 30 → 2.84 · 46 → 4.09 |
| 무게 · 작음 | 전조 0.8 ~ 1.2초 · 최대체력 10 ~ 20%(배율 ×0.7 ~ ×1.4) | ×1 = 14.3%(앵커 7타) |
| 무게 · 중간 | 1.2 ~ 2.0초 · 20 ~ 35%(×1.4 ~ ×2.45) | |
| 무게 · 큼 | 2.0초 이상 · 35 ~ 55%(×2.45 ~ ×3.85 또는 %최대체력) | 기믹 실패는 §3 |
| 공중으로 피하기 | 바닥 판정(발 ≤ 지면 + 8)은 공중 점프 1회(발 13.3)로 피한다 | 그래서 패턴마다 "공중/지상 대응" 칸을 둔다 |
| 대공 | 공중에 뜬 사람만 노린다(투사체 3D 거리 · 잡기 체공 시간 · 공중 파동 띠) | 예고는 하늘 쪽(머리 위 조준 · 손바닥) |

**새 범용 조각(보스 이름이 들어간 함수 없음 - 데이터 조합)**

| 조각 | 무엇 | 판정 |
|---|---|---|
| `sector` | 보스 중심 부채꼴 · 반원 · 반면(각도 · 반경 · 안쪽 반경 · 방향 = 대상/무작위 좌우). `jumpable` = 판정 순간 공중이면 안 맞는다(점프로 넘기) | 판정 순간 부채꼴 안 + 발 기준 같은 층 |
| `projectile` | 투사체 count개 - 속도 · 회전력(0 = 직선) · 수명 · 대상 규칙(공중 우선) · 높이 모드(`air` = 3D 추적 / `ground` = 지면을 굴러 옴, 점프로 넘기) | 서버가 매 틱 위치를 계산 · 3D 거리 ≤ 반경. 클라는 서버 위치(10Hz)를 따라 그린다 |
| `grab` | 대공 잡기(§2) | 시전 동안 연속 체공 ≥ N초인 사람 전원 |
| `circleTarget.shots` | 연발의 칸별 반경 · 배율 · 전조(작게 → 크게) | 기존 연발과 같다 |
| `circleTarget.chain` | 보스 → 대상 직선을 따라 원이 차례로 솟는다(연쇄 가시) | 원마다 제 시각에 판정 |
| `circleTarget.ambush` | 잠행 후 대상 발밑을 추적하다 멈춘 뒤 솟는다(P3c 추적 원 재사용) | 멈춘 자리 |
| `line.volleyShots` | 볼리별 배율 · 전조 · 반폭(마지막이 강함) | 기존 직선 |
| `line.reflect` | 벽에 닿으면 한 번 반사(반사 레이저) | 꺾인 두 선분 |
| `ring` 리듬의 `air = true` | 공중 파동 - 발 높이 지면 + 4 ~ 14 띠만 친다(서 있으면 안전 · 뛰면 맞는다) | 띠가 지날 때 그 높이인가 |
| `vortex` | 끌어당김(클라가 자기 캐릭터를 당긴다 · 걷기 16보다 느리게) → 끝에 중심 폭발 | 폭발 원 |
| 환경 트랙 `environment` | 기본 패턴과 **따로 도는** 두 번째 시계(§4) | 구역(원 · 부채꼴 · 고리 · 사각) + 도트 · 튕김 · 밀기 · 당기기 |

## 4. 환경 변화

### 4-1. 공통 규칙

- 보스 체력 **50% 이하**부터(`environment.hpBelow`). 처음 50%를 지나는 순간 + 3초에 첫 발동, 그 뒤 쿨 **35초**.
- 기본 패턴과 **따로 돈다**(두 번째 시계) - 환경이 도는 동안에도 기본 패턴이 나온다(사용자 결정: 겹침 허용).
- 서버 = 구역 판정 · 도트 · 튕김 · 높이만. 기울기 · 흔들림 · 물 · 모래 소용돌이는 클라 연출(큰 파트를 물리로 뒤집지 않는다).
- 전조 = 보이는 구역 그대로(금 · 물 넘침 · 모래 소용돌이). **보이는 장판 = 실제 판정.**
- 도트는 발 기준 같은 층(떠 있으면 안 탄다) · 잡힌 사람 면역 · 발동당 %피해 상한은 환경 발동마다 따로(55%).
- 맵 수정은 **간단하게**(사용자): 공중 발판 · 점프대 · 핵은 보스전 동안만 서는 단순 파트(정확한 맵은 나중).

### 4-2. 수정 계열 "중력 반전" 시범

시범 항목과 결과는 §9(시범 뒤 채움). 판단 기준: ① 천장 보행 = 로블록스 기본 캐릭터로 불가 → `ControllerManager`(UpDirection) 전용 이동이 필요 ② 폰 조작 · 카메라 뒤집힘 ③ 서버 높이 검증(마지막 지면 + 22.38) · 맵 밖 복귀 · 모든 바닥 판정(발 = 루트 − 엉덩이 높이)이 "아래 = −Y"를 전제 ④ 성능. 하나라도 큰 충돌이면 **대체안(수정 공중 정원)**.

### 4-3. 겹침 분류(자동 검사)

- 환경 × 패턴 쌍마다: 환경이 막은 구역을 빼고, 환경의 힘(밀기 · 당김)을 이동 속도에 넣어 패턴을 피할 수 있는지 격자로 잰다.
  - **피할 수 있음** = 회피 부등식(여유 ×1.25) 통과 · **어려움** = 여유 ×1.0으로만 통과(최단 직선을 바로 걸어야) · **피할 수 없음** = 둘 다 실패.
- 스케줄러: 환경이 도는 동안 "피할 수 없음" 패턴은 **나올 차례에 70%로 건너뛴다**(다른 후보가 없으면 나간다) · 같은 환경 발동 안에서 **두 번 연속 금지**.
- 보고: 분류 표 + 모형(몬테카를로)에서 실제 등장 비율.
