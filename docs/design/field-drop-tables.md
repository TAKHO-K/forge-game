> 단일 소스: 등급 = `DropTableData.fieldGradeWeights`(정수 가중치 ÷ 10,000,000 · 합 검사) · 개수 = `MonsterData.dropCountMultiplier`(= killUnits × `DropTableData.fieldDropCountAdjust` · 스위치 `dropCountBasis`) · 초월 = `DropTableData.transcendent` · 반짝이 = `RareMonsterConfig` · 상자 = `TreasureChestConfig` · 강화석 = `EnhanceMaterialData` · 골드 · 경험치 = `MonsterData.tierN`(HP 비 = killUnits).
