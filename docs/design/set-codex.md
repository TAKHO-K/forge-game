# 세트 도감 설계 (A2-N4 §4-2 · 스위치 뒤 1차 구현)

> 상태: 1차 구현 = 장비창 "도감" 탭(`client/panels/Inventory/CodexTab.lua`) · 스위치 `SetData.codex`(기본 끔 · 개발 `/gg set codex on|off`). 수집 기록 · 보상은 이 문서의 설계만(결정 필요).

## 1. 무엇을 모으나

| 축 | 값 | 출처 |
|---|---|---|
| 구역(세트 계열) | 6 - 석조 평원 · 수정 동굴 · 수몰 사원 · 모래 유적 · 폭풍 첨탑 · 빙하 동굴 | `WorldMapData.zones` · 장비 `item.setZone`(없으면 itemLevel이 닿는 보스 구역 - `ArtMeshKit.armorZone`) |
| 등급 | 8 - 일반 ~ 초월 | `ArmorData.gradeOrder` |
| 부위 | 3 - 갑옷 · 장갑 · 신발 | `SetData.parts` |

- 칸 = 구역 × 등급(48칸) · 칸마다 부위 0 ~ 3 · 3부위 = **완성**(금테). 합계 = 완성 세트 n / 48 · 모은 조각 n / 144.
- 외형은 등급 → 3외형(`ArtImportData.armorLookOfGrade` - 일반 · 전설 · 초월 계열)이라 한 외형이 여러 등급 칸에 걸친다 - 칸은 "외형"이 아니라 "등급" 단위로 센다(등급 색 테두리가 구분).

## 2. 1차 구현(지금)

- 센다 = **지금 가진 것**(가방 + 착용 3부위, 서버 스냅샷 `InventorySync`). 팔거나 분해하면 칸이 빈다 - 저장 변경 0.
- 탭 = 장비창 마지막 탭(PC · 폰 공통 · 가로 스크롤) · 칸 48 × 48(터치 44 이상) · 글씨 caption 12 이상.

## 3. 2차(결정 필요)

1. **수집 기록 저장**: 한 번이라도 가진 (구역, 등급, 부위)를 영구 기록 → 팔아도 칸 유지. 저장 = `profile.setCodex[zone][grade] = 부위 비트(1 · 2 · 4)` - SAVE_VERSION + 1 · migrate(지금 가방 + 착용으로 시드) · DevTools 백업 대상(COMMON §1).
2. **완성 보상 후보**(가치 = 경제 밖 - 치장 · 칭호만, 전투 수치 0):
   - 구역 한 줄(8등급 전부) 완성 → 칭호 "○○의 수집가"(`TitleData` 한 줄)
   - 전설 이상 한 칸 완성 → 치장 조각 1(`CosmeticSlotData` - 기존 경로 재사용)
   - 48칸 전부 → 칭호 "세트 도감 완성" + 트레일 1(`TrailData`)
3. 서버 판정: 칸 완성은 서버가 기록 갱신 때 계산(클라 표시와 같은 순수 함수 `CodexTab.collect`를 shared로 옮겨 공용).
4. 알림: 새 칸이 처음 채워지면 드랍 피드 한 줄(`DropNotice` 공통 입구).
