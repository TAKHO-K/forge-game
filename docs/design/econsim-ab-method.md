# EconSim 안 비교 방법 (QUEUE-6h-b R4 · 앞으로의 경제 결정 기준)

1. **공통 난수**(`EconSimConfig.commonRandom = true` · 기본): 강화 굴림 = (시작 단계, 그 단계의 n번째 시도)마다 고정된 수(`EconSim.commonDraw` - 정수 해시 · Random 구현과 무관). 같은 시드 두 번 = 완전히 같은 결과(실측: 3프로필 소수점까지 동일).
2. **재기준선**(2026-09-29 · HEAD): 상위 1% 25,300 = 2,322.6h · 5,000 = 82.5h / 일반 25,300 = 5,560h · 5,000 = 159.5h · 환생 5 = 9.06h · 환생 1 = 34분 / 캐주얼 1,000 = 28.9h(옛 한 흐름 값 2,382h · 27.5h와 목표 범위 안에서 같은 수준 - 옛 값도 표본 하나였다).
3. **남은 차이 ±2%는 잡음이 아니라 문턱 효과**: 강화 난수를 고정해도 장비 교체 점검 · 사냥 티어 선택 · 보스 도전 문턱 같은 이산 결정이 한 번 어긋나면 뒤가 갈린다(예: 초반 드랍 칸 ×0.75 = 상위 +2.1% · ×0.5 = 0.0% - 단조 아님).
4. **판정 규칙**: 한 축만 바꾼 안의 차이가 **3% 미만이면 "효과 없음"**으로 본다. 3% 이상이거나 목표 경계(±10%) 근처면 시드 3개(`EconSimConfig.seed` 20260923 · +1 · +2) 평균으로 다시 잰다.
5. **안 스크립트 규칙**: 한 안 = 현재 HEAD + 값 한 가지(스크래치 `dec_gen.py` 형식 - MODS 표를 테스트 첫머리에서 바꿈) · 프로필 3개 · 결과 줄 형식 `DEC|안|프로필|1000=|5000=|25300=|rebirth1=|rebirth5=|gold left`.
