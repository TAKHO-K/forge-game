## B. 연출 점검 → 구현 (원래 V0 보완판 = 아래 규칙 · 질문 목록)
### 안전 규칙 (어기면 안 됨)
0. 먼저 docs/visual-audit.md에 점검 결과(상위 20개 이내 · 현재 구현 여부는 파일 · 함수 근거 · 확인 못 한 것은 [추정] · Play 확인은 캡처 경로)를 쓰고 커밋한 **뒤에** 구현한다. 구현 = 1순위(즉시 효과 큼) · 2순위(적은 비용)만. 3순위는 목록만. 유지/통합/삭제는 **통합 · 삭제 실행 금지**(제안만).
1. 폰트 단계 · 중앙 금지 구역(40% × 50%) · ScreenMap · 회피 부등식(전조 ≥ 인지 + 거리 ÷ 최저 이속 × 여유)을 깨지 않는다.
2. 플레이어 입력(평타 · 스킬 · 버튼)에 입력을 늦추는 준비 동작 금지. 준비 동작은 적 · 보스 전조만.
3. 히트스톱 · 화면 흔들림 · 카메라 줌/킥 = 클라 로컬 연출만(서버 로직 · 시간 불변). 보스 전조를 가리거나 인지 시간을 줄이면 안 됨.
4. 성능 예산: 필드 12인 · 보스 4인 · 폰. 내 효과 강 · 남 효과 약. 설정 "화면 흔들림 줄이기" · "번쩍임 줄이기"(초당 3회 미만) 연결.
5. 이미 결정된 것 재논의 금지: 보스바 하단 가운데 · 평타 바닥 전조 없음(예외 심해 삼지창) · 태초/초월 알림 범위와 밀도 · 이동 게이지 · 보스 난이도 수치.
6. 모든 새 연출 = ArtStyleV1 뒤 · 끔 = 전과 같음.
### 클라이맥스 목록 (전투와 같은 무게로)
강화 성공 · 실패 · 19~21강 하락 · 22강 이상 12강 초기화 · 방지권 발동 · 태초 드랍 · 초월 드랍(밀도 규칙) · 보스 첫 처치 · 환생 · 도감 칸 완료 · 줄 칭호 · 초월 세트 줄 완료 · 균열 시작/종료 · 합동 목표 단계 달성 · 레벨업.
### 점검 질문
- 각 사건 = 입력 → 준비 → 행동 → 충돌/변화 → 결과 → 정착 흐름으로 분석.
- 입력 직후 시각 · 청각 · 햅틱 / Tween · Easing / 준비 · 찌그러짐 · 여운 · 2차 움직임 / 히트스톱 · 번쩍임 · 넉백 · 흔들림 / 입자 · 궤적 · 충격 · 잔상 / 피해 미리보기 · 늦게 줄어드는 체력바 · 숫자 올라감 / 카메라 / 등장 · 획득 · 레벨업 · 사망 · 퇴장 / 결과 화면 · 승리 · 게임 오버 / 버튼 상태 / 정보 위계 · 가독성 / 등장 · 퇴장 타이밍 / 소리 · 화면 동기화 / 폰 햅틱(HapticService가 대상 기기에서 동작하는지 먼저 확인 - 안 되면 제안 안 함) / 반복 시 지루하게 긴 연출 / 같은 정보 중복 · 시선 방해 / 보스 판정 크기 vs 모션 · 궤적 / 균열 날씨가 전조 · 드랍 빛 · 이름표를 가리는지.
- 로직은 있는데 표현이 부족한 사건을 먼저(맞은 느낌 약함 · 죽는 과정 없음 · 획득감 없음 · 버튼 반응 없음 · 레벨업이 숫자만 · 보스 등장이 잡몹과 같음 · 승리에 마침표 없음 · 도감 칸이 차도 반응 없음).
- 중요도 비례 세기(일반 / 중요 / 클라이맥스). 모든 사건에 같은 흔들림 · 입자 · 소리 · 줌 금지.
- 연속 경험으로: 보스 마지막 타격 → 사망 인지 → 짧은 여운 → 승리 → 보상(반복 방해 안 되게 짧게) · 초월: 암전 → 하늘 균열 → 빛기둥 → 슬로모션 → 배너 → 도감 세트 줄.
- 정리 = 1 즉시 수정 효과 큼 · 2 적은 비용 · 3 나중 디테일.

## B-2. 연출 추가 지시 (사용자 10-01 · B의 안전 규칙보다 구체적이면 이것이 우선)
- **피로 금지**: 게임 진행을 방해하거나 피로 · 불편을 느낄 만큼 흔들림 · 번쩍임 · 효과를 넣지 않는다. 기준(초안 - Play로 조정): 일반 사냥 중 화면 흔들림 0(내 강공격 적중만 아주 약하게) · 흔들림/번쩍임은 같은 3초 안에 1번까지 · 화면 전체 번쩍임은 클라이맥스만 · 설정 "연출 세기(끔 · 약 · 보통)" 하나로 흔들림 · 번쩍임 · 남의 효과를 함께 줄임.
- **클립 순간 과장**: 플레이어가 영상으로 남기고 싶어지는 순간만 크게. 예) 몬스터를 강하게 쳐서 **멀리 날아가면 하늘로 날아가다 "반짝" 별빛과 함께 사라짐**(로켓단식 - 마무리 강공격 · 치명타 처치 · 넉백 큰 스킬일 때만, 판정 · 드랍 위치 불변 = 드랍은 원래 자리) · 태초 · 초월 드랍 · 보스 마무리 일격 · 22강 초기화 · 초월 세트 줄 완료.
- **때린 느낌**:
  - 일반 몹 = "내가 때렸다"가 확실하게: 맞은 몹 흰 번쩍임(0.06초) · 작은 뒤로 밀림(보이는 것만) · 내 피해 숫자 크게 · 타격음 · 치명타는 숫자 모양 · 색 다르게. 히트스톱은 내 강공격만 아주 짧게(로컬).
  - 보스 = "누가 언제 때렸는지" 알 수 있게: 파티원마다 색(최대 4색 - 이름표 · 파티 창과 같은 색) · 적중 불꽃이 그 색 · 내 적중 = 크고 밝게, 남 적중 = 작고 옅게 · 피해 숫자도 같은 규칙 · 보스 체력바 잔상은 공통.
- **내가 맞을 때 = 공격 크기에 비례**: 평타 · 작은 피해 = 화면 가장자리 옅은 붉은 번짐만 · 큰 전조 공격(강공격 · 패턴 · 기믹)에 맞으면 = 가장자리 붉은 번짐 진하게 + 짧은 흔들림(설정 따름) + 묵직한 소리 · 체력 30% 아래 = 가장자리 심장 박동 번짐(약하게). 전조를 가리는 번짐 금지(가장자리만).

## B-3. 단축키 · 화면 정리 (사용자 10-01: 로블록스 인기 게임 · 일반 RPG 관례에 맞추고, 중복 기능 삭제, 간결 · 직관)
- 원칙: PC 게임 · 로블록스 RPG에서 흔한 배치로 묶는다. 로블록스 기본 키와 겹치지 않게(Esc 메뉴 · Tab 플레이어 목록 · / 채팅 · ` 가방 도구줄 · **I / O = 기본 카메라 확대/축소** · F9 콘솔). 모든 창 = 같은 키로 열고 닫기 + Esc로 닫기. 폰 = 키 칩 숨기고 버튼.
- ★최종 단축키 표(사용자 10-01 확정 방향 - 10 문서와 같음):
  | 키 | 기능 |
  |---|---|
  | WASD · Space · Shift · Q/E/R/T · Ctrl · F | 이동 · 점프 · 대시 · 스킬 · 시점 고정 · 상호작용(유지) |
  | **B** | **귀환**(리그 오브 레전드와 같은 키) - 채널 중 B 다시 · 이동 입력 · 피격 = 취소 |
  | **G** | 가방(펫 = 가방 안 탭). I는 로블록스 카메라 확대 키라 피함 |
  | C | 캐릭터(성장 · 능력치 · 직업 변경) |

  | **M** | 지도(전체 지도 · 핀 · 자동 이동 · 체크포인트) - 미니맵은 화면 오른쪽 위에 상시 작게 |

- 최신 로블록스 인기 게임 느낌: 큰 아이콘 · 짧은 글자 · 알림 빨간 점 · 화면 가장자리에 모으고 가운데 비우기(ref 16 규칙과 같음).

## B-4. GUI 추가 (사용자 10-01 + 꼭 필요한 것만)
1. **상점 버튼(로벅스)**: 다른 인기 게임처럼 바로 보이게 - 왼쪽 메뉴 줄 맨 아래 또는 화면 오른쪽 가장자리에 금색 상점 아이콘 1개. 열면 탭 = 추천 · 치장(테마 · 글라이더 · 이름표) · 시즌 패스 · 편의(게임패스). 각 상품 = 미리보기(치장은 내 캐릭터에 입혀 보기) + 가격 + [구매](MarketplaceService 창). 규칙 = monetization-p4c(돈으로 강해지지 않음 · 유료 랜덤 없음 · checkCatalog). 시즌 패스 받을 칸 있으면 빨간 점.
2. **친구 초대 버튼**: 파티 창 맨 위 + 첫 보스 처치 뒤 1회 안내. 초대 보상(05 문서)과 연결.
3. **오늘의 목표(퀘스트 추적 칸)**: 화면 왼쪽 메뉴 아래 작은 칸에 지금 할 일 1~3줄(메인 퀘스트 · 일일 · 다음 이정표) + 진행도 + 누르면 길 안내 시작. 전투 · 보스전 중 자동 접힘. 초반 이탈 방지 핵심.
4. **접속 보상 · 7일 출석 창**: 하루 첫 접속 때 한 번 자동으로 뜨는 달력 창(이미 있는 QuestData 보상 재사용 · 새 보상 만들지 않음) · 닫으면 퀘스트 버튼에 빨간 점으로 남음.
5. **설정 정리**: 연출 세기(끔 · 약 · 보통) · 번쩍임 줄이기 · 음량 4(효과 · UI · 환경 · 음악) · 그래픽 품질 · 다른 서버 초월 알림(전체 · 배너만 · 끔) · 코드 입력 - 한 창에 분류 탭.
- 그 이상 늘리지 않는다(화면 복잡도 우선).

## C. 사운드 (지금 게임 = 무음)
- 로블록스 오디오 업로드 한도(공식 문서): ID 인증 계정 월 100개 · 미인증 월 10개, 업로드 뒤 수정 불가, MP3 · OGG · WAV · FLAC.
- 그래서 **짧은 효과음 여러 개를 한 파일에 이어 붙이고(사운드 시트) Sound.PlaybackRegion으로 구간 재생** → 파일 2~4개로 30개 이상 효과음.
- 만들기: 설치 없이 절차적 합성(Blender 내장 파이썬 + numpy 또는 파이썬 표준 라이브러리 wave) - 타격 · 휘두름 · 줍기 · 등급별 드랍(유물 이상 층층이) · 강화 성공/실패/하락 · 레벨업 · 버튼 누름/닫힘 · 도감 칸 · 칭호 · 보스 등장/사망 · 균열 시작 · 초월(암전 뒤 저음 → 상승) · 경고음. 카툰 톤 · 과하지 않게 · 음량 표준화(피크 −1dB).
- 소리 그룹(SoundGroup): 효과 · UI · 환경 · 음악(자리) + 설정 창 음량 슬라이더 4개. 남의 효과음은 작게 · 거리 감쇠.
- 업로드 = upload.py(Audio 지원 추가). 첫 업로드에서 한도 오류가 나면 **바로 멈추고** 남은 개수 · 필요 개수를 보고(억지로 나누지 않음).
- 배경 음악 = 이번엔 자리만(저작권 · 품질 이유로 사용자 결정).
