# 05 친구 보상 · 코드 · 주간 도전 (사용자 09-30)

> 근거: 로블록스 추천(2026-06 개편)은 D1 · D2~7 · D8~28 재방문, 친구 데려오기, 지출을 본다.

## 1. 친구 보상 3종 (사용자 동의)
- **같이 하기 보너스**: 로블록스 친구와 같은 파티면 드랍 · 경험치 작은 보너스(값 = EconSim 안, 예 경험치 +10%). 파티 화면에 "친구 보너스" 표시.
- **초대 보상**: 로블록스 기본 초대창(SocialService) + 참가 데이터로, 초대받은 친구가 **처음** 들어오면 **양쪽** 보상(1쌍 1회 · 초대자 하루 상한 · 부계정 악용 방지 규칙 기록). 보상 = 강화석 · 알 · 치장 재화(반짝 조각).
- **파티 모집** = A2-N4 1단계(같은 서버 게시판 · 태그식) 유지, 서버 간 매칭은 출시 후.

## 2. 코드 시스템
- 설정 창에 코드 입력칸 → 서버 검증(존재 · 기한 · 계정당 1회) → 보상. 코드 표 = 데이터 파일 한 곳(코드 · 보상 · 만료일). 대소문자 무시 · 입력 속도 제한 · 기록.
- 보상 = 작게(강화석 · 반짝 조각 · 짧은 부스트) - 경제 흔들지 않게. 로벅스 판매 금지 목록과 무관(무료 지급).
- 게임 안 **업데이트 게시판**(허브 · 로비): 새 소식 · 현재 유효 코드 표시. 게임 설명란에 붙일 문구 틀도 docs에 생성.
- 커뮤니티(그룹) = 아직 없음 → 그룹 가입 보상은 만들지 않음(자리만).

## 3. 주간 도전 (기본 보스 · 리더보드 불변)
- 별도 모드 "주간 도전": 매주 보스 1~2종에 변형 규칙(예: 분신 2배 · 투사체 유도 강화 · 바닥 붕괴 빨라짐 · 번개 2배) - 변형 표 = 데이터.
- 주간 순위(처치 시간) + 참여 · 순위 보상(치장 재화 · 칭호). 기본 보스 기록 · 시즌 리더보드와 분리.
- 변형도 회피 부등식 · 판정 규칙을 지킨다(BossSim 검사).
