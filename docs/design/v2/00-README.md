## 결정 1 — 강공격 3줄 분리 뒤 전멸률 상승 (STATUS-0930 §⑤)
- 사실: 쿨 · 피해 배수만으로는 ±4%p밖에 안 움직인다(강공격 횟수 ×3~6).
- 확정 방향(설계): **3줄 분리 유지 + 줄 자체를 조절한다.**
  1. **초반 완화 구간**: 첫 환생 전(또는 스테이지 ≤ 50 - 더 자연스러운 쪽을 측정으로) = 강공격 줄 끔 + 보스 피해 ×0.7. "초반은 스트레스 없이"(사용자). 첫 만남 기준이 아니라 **스테이지 구간 기준**(규칙 하나 - 두 번째 싸움부터 갑자기 어려워지는 일 없음).
  2. **그 뒤 = 전조 있는 공격 사이 최소 간격 X초**(강공격 · 패턴 공통, 평타 제외). X 후보 2.5 · 3.5 · 4.5 · 5.5초를 BossSim으로 돌려 **1 · 2 · 4인 · 솔로 근접/원거리 모두 옛 규칙 + 10%p 이하**를 만족하는 가장 작은 X를 쓴다(= 강공격을 가능한 한 자주). 강공격 피해 ×0.8 유지.
  3. 6.0초까지 올려도 못 맞추면 멈추지 말고 "첫 도전 한정 강공격 줄 끔"(옛 선택지 다)을 추가 적용하고 보고.
- BR1(가) 기대값(수호자 전멸 · 수정 여왕 처치 시간)은 위 결과로 갱신(값이 바뀐 이유를 주석).

## 초반 곡선 (사용자 09-30: "정체 구간을 빨리 밀고, 초반은 캐주얼하게 스트레스 없이")

- 목표: 첫 보스 ≤ 10분 · **레벨 25까지 어떤 레벨도 3분 넘게 걸리지 않음** · 12→25 구간 ≤ 15분 · 첫 환생 약 35분 · 첫 1시간 동안 3분마다 무언가(레벨업 · 새 구역 · 보스 · 장비 · 해금)가 일어남. 맵 이동 시간이 모형에 없으니 실제 Play로 1회 재서 보정.
