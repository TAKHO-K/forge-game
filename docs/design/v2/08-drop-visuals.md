# 08 바닥 드랍 연출 — 디아블로4식 "검은 실루엣 + 빛" (사용자 09-30)

> 사용자 지시: 장비 외형(02 방어구 v3 · 무기 메시)이 확정되면, 바닥에 떨어진 장비는 **그 외형 에셋을 쓰되 색은 검정 실루엣 + 빛**(디아블로4 장비 드랍 느낌). 등급이 높을수록 더 화려하게. 사용자가 준 참고 사진(디아블로4 "선조" 드랍 = 주황 · 빨강 빛기둥 여러 줄 + 등급색 이름표)은 **우리 유물 등급 정도의 세기**.
> 순서: P2에서 방어구 v3 완료 뒤 마지막 단계로.

## 1. 공통 모습
- 아이템 = 실제 장비 메시(방어구 v3 조각 · 무기 메시)를 바닥에 눕히거나 살짝 떠서 천천히 회전. 색 = 거의 검정(예 RGB 20 · 20 · 24) · 등급색 테두리 빛.
- 빛기둥 = 아이템에서 하늘로 곧게 선 가느다란 빛(Beam) - 등급색. 여러 가닥 · 흔들림 · 높이로 등급 차이.
- 바닥 빛 = 아이템 밑 **부드러운 번짐**(경계 없는 원). 보스 전조 장판(테두리 있는 빨강 · 주황 영역)과 헷갈리지 않게 **테두리 · 채운 원 금지**.
- 이름표 = 아이템 위 등급색 글씨(외곽선) "석조 평원 장갑 (유물)" 식. 여러 개면 겹치지 않게 위아래로 쌓음. 기본 = 영웅 이상 표시, 낮은 등급은 가까이(약 15 stud) 있을 때만.
- 떨어짐 = 튀어 올라 포물선 → 한 번 통통 → 착지 순간 등급 번쩍(유물 이상).

## 2. 등급별 세기
| 등급 | 빛기둥 | 바닥 빛 · 입자 | 이름표 | 착지 |
|---|---|---|---|---|
| 일반 | 없음 | 아주 약한 번짐 | 가까이서만 | 작게 튐 |
| 희귀 | 얇고 짧게(약 6 stud) | 약한 번짐 | 가까이서만 | 작게 튐 |
| 영웅 | 얇게(약 10) | 번짐 | 항상 | - |
| 전설 | 중간(약 16) · 1가닥 | 번짐 + 희미한 입자 | 항상 · 조금 크게 | 작은 번쩍 |
| **유물** | **참고 사진 수준: 높고 가는 기둥(30+) 여러 가닥 · 살짝 흔들림** | 번짐 + 떠오르는 불씨 | 항상 · 강조 | 번쩍 + 짧은 충격 빛 |
| 고대 | 유물 + 두 겹(바깥 옅은 기둥) + 회전 입자 | 더 넓은 번짐 | 크게 | 번쩍 + 원형 빛 퍼짐 |
| 태초 | 흰 + 자홍 규칙 · 04 문서 클립(같은 서버) | | | |
| 초월 | 흑금 · 04 문서 클립(떨어진 서버 풀 연출) | | | |

## 3. 규칙 · 성능
- 등급색 = 기존 등급색 표(GradeColor/ItemVisualData) 그대로.
- 테두리 빛(Highlight)은 동시 표시 개수 제한이 있으니(엔진 제한 - 확인 후 수치 기록) **가까운 · 높은 등급 순 상위 n개만**, 나머지는 빛기둥 · 번짐만.
- 빛기둥 동시 상한(가까운 · 높은 등급 순, 예 30) · 폰 품질에서 가닥 수 · 입자 감소.
- 드랍이 개인용이면 본인에게만, 공용이면 남의 드랍은 약하게(내 효과 강 · 남 효과 약 원칙).
- ArtStyleV1 뒤(끔 = 지금 드랍 모습).
- 캡처: 등급 8종 나란히(낮 · 밤 · 균열 날씨) + 필드 12인 가정 성능.
