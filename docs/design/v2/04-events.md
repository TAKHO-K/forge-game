# 04 전 서버 이벤트 · 클립 순간 (사용자 확정 09-30)

> 핵심 판타지(사용자 결정) = "초월 대박 드랍". 타깃 9~17세. 알림 규칙: 태초 = 같은 서버 + 본인 연출, 전 서버 = 초월부터(아래 밀도 조절).

## 1. 초월 알림 밀도 조절 (초월은 동접에 비례 → 흥행하면 노이즈)
- 항상: 전 서버 채팅 한 줄 + 작은 배너 + 명예의 전당. 떨어진 서버 = 항상 최대 연출.
- 전 서버 풀 연출: 시즌 첫 초월 · 부위별 첫 초월 · 세계 번호 10 · 50 · 100번째… · 최근 30분간 풀 연출 없음일 때만.
- 몰리면 배너 묶음("최근 1시간 초월 n개 · #a~#b").
- 설정: 다른 서버 초월 알림 = 전체 / 배너만 / 끔.

## 2. 클립 순간 (태초부터, 초월은 압도적)
- **태초**(같은 서버): 본인 = 0.4초 슬로모션(로컬) · 카메라가 빛기둥을 올려다봄 · 흰 빛 폭발. 같은 서버 = 멀리서도 보이는 흰 빛기둥 10초 + 서버 배너.
- **초월**(떨어진 서버 = 항상, 전 서버 = 1의 조건일 때):
  1. 0.3초 암전 + 무음 → 2. 하늘이 흑금으로 갈라짐 · 땅 울림(~1.5초) → 3. 흑금 빛기둥(맵 어디서든 보임, 60초 유지) · 본인 슬로모션 + 카메라 한 바퀴 → 4. 전 서버 배너 + 명예의 전당 · 획득자 흑금 오라 수 분 → 5. 도감 세트 줄 완료 연출(06 문서).
  - (후보 · 마지막 순서) 다른 서버 "구경 가기" 버튼(그 서버로 이동) - 이동에 수 초 걸리므로 빛기둥 60초 · 오라가 있어야 의미. 서버가 꽉 차면 실패 안내.
- 슬로모션 · 암전 · 카메라는 **클라 로컬 연출만**(서버 시간 · 판정 불변). 보스전 중이면 전조를 가리지 않게 축소판.
- 첫 보스 처치(견습) = 확정 전설 드랍을 풀 연출로(첫 대박 맛보기).
- 가짜 "아깝게 놓침" 연출 금지(아이 대상).

## 3. 균열 시간
- 모든 서버 동시, **하루 2번 × 20분**(한국 저녁 20시 + 미국 저녁대 1회 - 서버 UTC 표로 데이터화).
- 하늘 안개 · 기상 악화 · 맵 전체 분위기 전환, 보스 아레나도 기상.
- 구역별 날씨: 석조 평원(슬라임) = 산성비 · 수정 = 결정 비 · 폭풍 = 뇌우 · 모래 = 모래 폭풍 · 수몰/심해 = 해무 · 빙하 = 눈보라. 아레나 = 보스 테마 날씨.
- 아레나 날씨 = 화면만(안개 농도 상한, 전조는 날씨 위에, 판정 불변 - 리더보드 공정성).
- 번개 번쩍임 초당 3회 미만 + 설정 "번쩍임 줄이기". 입자 = 카메라 주변 클라 전용, 그래픽 품질 따라 감소.
- 효과: 골드 획득 증가 + **전설 · 유물 · 고대 확률 ×1.5(예)**, 태초 · 초월 제외. 확률 공개 UI에 균열 배율 표시(공개 확률 = 서버 굴림 같은 표). 다른 부스트와 중첩 상한.
- EconSim: "균열 참여 비중"(예 30%) 변수 → 캐주얼 목표 26~32h 유지하는 배율로 확정.
- 시작 · 종료 알림(전 서버 배너 · 하늘 변화), 남은 시간 표시.

## 4. 전 서버 합동 목표
- 주기 1주(월요일 UTC - QuestData 주간과 같음). 지표 = **보스 처치 수 + 초월 보너스(큰 칸)**. 보상 = 단계별 **강화석 → 알 → 한정 칭호**(3칸: 60% · 85% · 100%, 못 채워도 부분 보상).
- 목표치 = "전주 플레이 기준이면 이번 주도 간당간당하게 달성": 기준선 = 지난 2~3주 가중 평균, 주간 변화 ±25% 제한, 목표 = 기준선 × 약 0.95(평균 페이스면 일요일쯤 달성). 1주차 = 오픈 첫 24시간 실측 × 7 × 0.7, 주 중간 불변.
- 1인 하루 기여 상한. 집계 = 서버별 30~60초 모아 서버 간 저장소 합산(MemoryStore/MessagingService 호출 한도 확인 후 수치 기록).
- UI = 허브 게이지 + HUD 작은 진행 표시 + 단계 달성 전 서버 배너.
- 초월 축복 버프 = 보류(균열 시간에 흡수).
