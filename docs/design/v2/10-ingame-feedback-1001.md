> 사용자가 10-01 게임 안에서 직접 확인하고 준 지시다. 축약하지 말고 아래 내용을 전부 구현 대상으로 본다. 다른 v2 문서와 충돌하면 이 문서가 우선(단축키 = 09 문서 B-3 최종 표와 같음).
> 공통 원칙: 글자보다 그림, 한눈에 무엇을 · 어디서 · 무엇을 받는지. 폰 800 × 360에서도 손가락으로 누르기 쉬운 크기(버튼 최소 PC 48px · 폰 60px 높이). 레퍼런스 docs/art/ref/16~18 스타일(3톤 · 굵은 외곽선 · 둥근 모서리 · 기능별 색).

## 1. 도감 — 그림 넣기 · 글자 줄이기 · 보상판 다시
### 문제 (사용자)
- 도감에 그림이 없어서 무슨 장비인지, 무슨 맵인지 정보가 부족하고 글자만 많다.
- 보상을 받을 때 무슨 보상을 받을 수 있는지 안 보이고 버튼이 작다.
### 해결
1. **모든 칸에 그림**: 칸 = 큰 그림 + 이름 한 줄 + 진행(예 3/4) + 완료 표시. 설명 글은 칸을 눌렀을 때 오른쪽 상세 칸에만.
   - 장비 칸 = 방어구 v3 아이콘(직업 × 부위 × 등급 외형 + 세트 색). 없으면 렌더해서 만든다(Blender 또는 Studio 촬영 → PNG → upload.py Decal). 빙고판의 "칸 안 부위 3개"도 작은 그림 3개로.
   - 몬스터 12 · 보스 6 · 펫 24(부화 등급별 색) = 초상화 그림(정면 약간 위 · 투명 배경 · 256px). 모르는 칸(아직 못 만난 것) = 검은 실루엣 + "?".
   - 탐험(둥지) = 그 둥지 자리 사진(게임 안 촬영 · 작은 가로 사진). 못 찾은 둥지 = 흐린 사진 + 구역 이름만(위치 누설 금지).
   - 직업 = 직업 그림 + 무기 등급 그림.
2. **상세 칸(칸을 눌렀을 때)**: 큰 그림(가능하면 3D 회전 미리보기 = ViewportFrame, 선택한 1개만 - 성능) · 이름 · 등급 · **어디서 얻는지(구역 이름 + 작은 지도 조각 + [길 안내] 버튼 = 자동 이동 · 길 안내와 연결)** · 진행 · 칸 보상 미리보기.
3. **그림 자리 비워 두지 않기**: "사진 넣을 공간"만 만들고 끝내지 말고 **실제 그림으로 전부 채운다**. 다 채운 뒤 빈 칸 0 검사(도감 전체 스크롤 캡처).
4. **보상판 간결화**:
   - 점수 보상판 = 가로 진행 줄 한 개 + 칸마다 **보상 그림(아이콘) + 수량**을 그대로 보이게(글자 설명 없음). 받을 수 있는 칸 = 빛나고 흔들림(아주 약하게) · 받은 칸 = 체크 · 다음 칸 = 강조 테두리.
   - 칸 보상 · 줄 칭호도 같은 방식: [받기] 버튼 옆에 받을 것 그림 + 수량.
   - **[받기] · [모두 받기] 버튼 크게**(폰 60px 이상 높이 · 초록 · 굵은 글씨). 받는 순간 보상 그림이 해당 재화 표시 쪽으로 날아가는 짧은 연출(0.4초 · 피로 금지 기준).
   - 탭 이름도 그림 + 짧은 글자(장비 · 펫 · 탐험 · 몬스터 · 보스 · 직업 · 보상판 · 칭호).

## 2. 수련 — 단축키 · 안내 · 그림
- 단축키 **U**(09 문서 B-3 표). 왼쪽 메뉴에 수련 아이콘(레퍼런스 스타일 - 성장 계열 초록, 예 아령 · 불꽃 수련 그림) + 모서리 U 칩.
- 수련 창 맨 위에 **그림 한 장**(캐릭터가 수련하는 장면 또는 능력이 오르는 그림) + 한 줄 설명(40자 이하, 예 "골드로 능력을 영구히 올려요") + 지금 올릴 수 있으면 [올리기] 버튼 강조.
- 처음 수련이 가능해지는 순간(골드 · 해금 조건 충족) 말풍선 1회 안내 + 메뉴 아이콘 빨간 점. 오늘의 목표 칸에 "수련 1번 하기" 이정표 연결.
- 능력 항목마다 작은 그림 + 지금 값 → 다음 값(▲ 초록) + 비용.

## 3. 퀘스트 — 초반 순차 미션 · 보상 커짐 · 구간별 도움 재화
- **초반 여정(메인 퀘스트 사슬)**: 새 유저가 실제로 해낼 수 있는 미션을 **한 번에 하나씩 순서대로** 보여 준다(끝나면 다음이 열림). 약 25~30단계로 첫 약 2시간(첫 환생 · 보스 몇 번 · 강화 · 알 · 도감 · 수련 · 파티)을 이끈다. 예:
  1 슬라임 10마리 → 2 장비 착용 → 3 첫 보스(스테이지 5) → 4 강화 +3 → 5 수련 1번 → 6 두 번째 구역 도착 → 7 알 줍기 · 부화 → 8 도감 칸 1개 받기 → 9 보스 스테이지 10 → 10 강화 +6 … → 첫 환생 → 파티로 보스 1번 → 균열 시간 참여 …(실제 게임 흐름 · 해금 순서에 맞게 터미널이 데이터로 확정).
  - 각 단계 = 할 일 한 줄 + 진행도 + [길 안내](해당 장소로) + 보상 그림.
- **보상**: 단계가 올라갈수록 커진다(골드 = 계정 최고 스테이지 기준 공식 재사용 · 강화석 증가). **구간마다 그때 필요한 도움 재화**를 준다(예: 처음 강화가 위험해지는 구간 직전 = 하락 방지권 1장, 알 해금 직후 = 알 1개, 보석 해금 직후 = 보석 가루, 첫 환생 직전 = 강화석 묶음). 새 재화는 만들지 않는다(기존 것만).
  - EconSim에 넣어 캐주얼 목표 26~32h 안 · 첫 환생 시간 변화 보고(빨라지는 건 OK, 후반 불변).
- **퀘스트 창 구조**: 창 맨 위 **토글 탭** = [메인(초반 여정)] [일일] [주간] [전 서버 협동(합동 목표)] [주간 도전]. 지금 따로 떠 있는 합동 목표 알약 · 주간 도전 버튼은 **퀘스트 창 탭으로 옮기고** 화면에서는 뺀다(중복 삭제 원칙).
  - 합동 목표 탭 = 큰 게이지(차오르는 애니메이션 · 단계 60 · 85 · 100% 표시와 보상 그림) + 내 기여 + 남은 시간.
  - 주간 도전 탭 = 이번 주 변형 설명(그림 3컷 규칙) + 내 기록 · 순위 + [도전] 버튼.
  - 일일 · 주간 = 줄마다 진행 게이지(차오르는 애니메이션) + 보상 그림 + 받기 버튼(크게).
- 오늘의 목표 칸(09 문서 B-4)은 메인 퀘스트 지금 단계를 1순위로 보여 준다.

## 4. 지도 · 미니맵 · 핀 · 구역 선택 키 이동
- 지금의 "맵 선택"(구역 · 스테이지 이동 창) = **N 키**로 옮긴다.
- **미니맵**: 화면 오른쪽 위(재화 · 레벨 표시 아래) 작은 원형. 내 위치 · 방향 · 파티원 · 퀘스트 목적지 · 관문 · 대장간 표시. 보스 아레나에서는 숨김. 폰 = 작게 · 누르면 전체 지도.
- **M = 전체 지도**: 6구역 + 허브 · 발견한 장소만 표시(못 찾은 둥지 · 탐험 지점 = 표시 안 함). 확대/축소 · 끌기.
  - **핀 찍기**: 지도 아무 곳이나 눌러 핀(최대 3개 · 다시 누르면 지움). 핀 = 미니맵과 월드에 표시.
  - **핀으로 이동**: 핀 · 장소를 누르고 [자동 이동] = 자동 이동 기능(대상 제한 규칙 그대로 - 둥지 · 탐험 지점 자체를 자동 이동 대상 목록에 올리지는 않되, 플레이어가 직접 찍은 핀은 허용) · [길 안내] = 안내선만.
  - 지도 그림 = 위에서 본 카툰 지도(게임 안 위에서 촬영 + 색 보정 또는 지형 데이터로 그림) · 구역 경계 · 이름 · 아이콘(관문 · 대장간 · 허브 · 체크포인트).
- 성능: 미니맵 = 정적 지도 그림 + 아이콘만(3D 다시 그리기 없음).

## 5. 체크포인트 순간이동 (사용자 "아직 고민 중" → 시험판으로 만들고 스위치)
- 사용자 구상: 큰 구역만 몇 곳 저장해 두고 순간이동. 정신 집중(시전 시간) 있음 · 귀환과 달리 **돌아오기 없음**(편도). 마을 NPC 배치도 이에 맞게.
- 구현(시험판 · 스위치 `CheckpointTeleport` 기본 **켬(개발)** - 사용자가 해 보고 결정):
  - 체크포인트 = 허브 1 + 구역마다 입구 1(총 7). 처음 가까이 가면 발견(빛 · 소리 · 도감 탐험과 별개).
  - 사용 = 지도(M)에서 발견한 체크포인트 누르기 → **정신 집중 3초**(이동 입력 · 피격 = 취소, 귀환과 같은 규칙) → 순간이동. 돌아오기 없음. 쿨 = 없음 또는 짧게(추천 30초 - 연속 남용 방지).
  - 보스 아레나 · 전투 중 사용 불가. 게임패스 "귀환 쿨 ×0.5"의 가치를 해치지 않게 귀환과 역할을 구분(귀환 = 허브로 + 돌아오기 있음 / 체크포인트 = 발견한 곳으로 편도).
- **마을(허브) NPC 배치**: 허브 체크포인트 둘레에 자주 쓰는 NPC(대장간 · 상점 · 수련 · 알 부화 · 퀘스트 게시판 · 업데이트 게시판)를 걸어서 10초 안에 모이게 재배치 **안 3개를 캡처로 제안하고, 가장 추천하는 1안만 적용**(나머지는 보고서에 그림으로). H1 미결 항목(NPC 배열 · 마을 배치)의 초안.

## 6. 귀환 — B 키 · 취소
- 단축키 **B**(리그 오브 레전드 귀환 키와 같음). 누르면 정신 집중(지금 귀환 시간 그대로) → 허브.
- **취소**: 집중 중 **B를 다시 누름 · 이동 입력(WASD · 조이스틱 · 점프 · 대시) · 피격** = 즉시 취소(쿨 소모 없음). 폰 = 귀환 버튼 다시 누르면 취소.
- 집중 표시 = 캐릭터 발밑 원형 진행 + 머리 위 작은 진행 막대 + 효과음(사운드 블록과 연결) · 취소 시 짧은 "취소" 토스트.

## 7. 지형 · 건물 모서리 다듬기
- 석조 건물 · 직각 기둥 · 바위처럼 **너무 뾰족 · 각져 보이는 것**을 약간 깎는다(모서리 베벨 · 둥근 모서리 = 카툰 느낌).
- 대상 찾기: 소품 틀(PropData · PropLibrary) · 아레나 소품(ArenaPropData) · 월드 구조물(WorldStructureData) · 관문 · 허브 건물 중 기본 도형(Block · Wedge)으로 된 것 목록 → 자주 보이는 것부터.
- 방법: Blender 베벨 메시(모서리 반경 = 짧은 변의 약 8~12%)로 교체 · **충돌 크기 · 위치 불변**(겉모습만) · 같은 메시 재사용 · 삼각형 예산 · ArtStyleV1 뒤.
- 전후 캡처(허브 · 구역 2곳 · 아레나 1곳).

## 8. 몬스터 이름표 · 대상 확인
- 문제: 맵(배경 색 · 밝기)에 따라 몬스터 이름표가 잘 안 보여서 내가 무엇을 때리는지 모르겠다.
- 해결:
  - 이름표 = 반투명 어두운 알약 배경 + 흰 굵은 글씨 + 외곽선 → 어떤 배경에서도 읽힘. 이름 · 레벨 · 작은 체력바. 거리에 따라 크기 · 투명도 조절, 멀면 숨김.
  - **내가 때리고 있는 대상 강조**: 마지막으로 내가 친 몬스터(3초 유지) = 이름표 조금 크게 + 밝은 테두리 + 발밑 얇은 원(바닥 전조와 헷갈리지 않게 흰색 · 얇게 · 테두리 번짐 없이) · 체력바가 늦게 줄어드는 잔상.
  - 반짝이 · 희귀 몬스터 = 이름 색 · 아이콘 구분(색 + 모양).
  - 파티원이 때리는 대상 = 작은 파티원 색 점(보스 파티원 색 규칙과 같음).
- 6구역 × 낮 · 밤 · 균열 날씨 캡처로 가독성 확인.
