# 01 수정 대기열 — 버그 · GUI · 보스 피드백 (사용자 실플레이 09-30)

## ★0. 길 안내 (P1 맨 앞 · 사용자: "첫 안내로 관문을 못 찾아가면 유저는 반드시 게임을 접는다")
- 버그: 길 안내가 높낮이를 고려하지 않아, 언덕 위에서 안내를 누르면 안내선이 땅속으로 파고들어 사라진다.
- 수정:
  1. 경로 = PathfindingService 경유점(지형 · 장애물 · 높이를 따라감). 실패하면 직선 경로를 일정 간격(약 4 stud)으로 나눠 **위에서 아래로 레이캐스트해 지면 높이 + 1~2 stud**에 점을 놓는다. 어떤 점도 지면 아래로 가지 않는다.
  2. 안내 표시(빔 · 화살표)는 지면 위에 뜨고, 가까운 구간만 그린다(성능). 플레이어가 경로에서 일정 거리 벗어나면 다시 계산(약 1초 간격 상한).
  3. **보조 수단(경로가 실패해도 절대 길을 잃지 않게)**: 목표(관문) 위에 멀리서도 보이는 빛기둥 + 거리 표시(지형에 가려도 보이는 표시), 목표가 화면 밖이면 화면 가장자리 방향 화살표.
  4. 첫 안내(견습 → 첫 관문)는 자동으로 켜짐. 도착하면 꺼짐.
- 검사: 언덕 위 · 골짜기 · 절벽 아래 · 물가 · 순간이동 직후 · 6구역 관문 전부 · 폰. 다른 안내 대상(대장간 · NPC)도 같은 방식. 캡처 전후.
- ★자동 검사(사용자: "이번엔 길찾기만 반드시 잘 되면 된다"): 6구역 × 무작위 시작점 50곳 이상(언덕 꼭대기 · 절벽 · 나무 옆 · 물가 포함)에서 안내 → ① 모든 표시 점이 지면 위(아래 0) ② 경로가 관문까지 이어짐(실패 시 보조 수단 표시) ③ 걸어서 실제 도착(봇 이동 또는 경로 길이 검사). 결과 표 + 실패 0 목표. 신규 계정으로 견습 → 첫 관문 도착까지 처음부터 끝까지 Play 1회(캡처 연속).

## ★0-1. 구간 수호자 붕괴 구멍이 안 보임 (사용자 09-30)
- 증상: 붕괴 패턴에서 조각이 무너져 떨어지는데(판정 = 구멍) 바닥 모습은 그대로라 구멍이 안 보임 → 모르고 떨어짐.
- 수정: 무너진 조각 자리는 **아래로 뻥 뚫린 게 보이게**(조각이 금 → 흔들림 → 아래로 떨어지며 사라짐 → 아래 = 깊은 허공 · 구름/안개, 구멍 가장자리 부서진 돌). 아트 바닥 메시(ArtStyleV1 겉모습)도 조각별로 나뉘어 판정 조각과 같은 순간 사라지고 같은 순간 돌아와야 한다(겉모습과 판정 불일치 0). 03 아레나 바닥 v2의 "석판 이음매 = 붕괴 조각 경계"와 함께.
- 검사: 붕괴 → 구멍 보임 → 복구까지 연속 캡처, 아트 켬 · 끔 둘 다, 겉모습과 판정 조각 시각 차 0.

## ★0-2. 나무 퀄리티 (필드 · 마을 공통 - 사용자 09-30)
- 지금: 공 몇 개를 쌓은 잎 + 원기둥 줄기 = 싸 보임. 배경의 거대한 층층 나무도 같은 문제.
- 수정: Blender 카툰 나무 세트로 교체 - 잎 = 여러 덩어리 + 명암 2~3단 + 가장자리 들쭉날쭉한 실루엣, 줄기 = 뿌리 벌어짐 + 갈라진 가지 + 살짝 휨. 구역 색에 맞춘 변형 4~6종(크기 · 모양 무작위 회전 · 배율)으로 반복 티 줄임. 배경 거대 나무 = 랜드마크급 1종 새로. 마을 나무(E절)도 이 세트로.
- 규칙: 같은 메시 재사용(묶음 그리기) · 나무당 삼각형 ≤ 1,500(랜드마크 별도 예산) · 충돌 = 줄기만 · 그림자 · LOD · 바람 흔들림은 클라 · 약하게(폰 품질에서 끔). 필드 12인 성능 전후.

## A. GUI (기준 = docs/art/ref/16_ui_hud.png · 17_ui_equipment.png · 18_ui_notice.png)
1. **보스 체력바 = 화면 하단 가운데**(소울류). "메이플식 맨 위"와 A2-N4의 "로블록스 버튼 오른쪽 상단 줄"은 폐기(3인칭에서 보스 머리를 가림).
   - 자리 = 스킬 줄 · 내 체력바 바로 위, 폭 = 스킬 줄 폭(약 45%), 두께 PC 14px · 폰 12px. 폰에서 조이스틱(왼쪽 아래) · 버튼(오른쪽 아래)과 안 겹침.
   - 이름 = 바 위 왼쪽 작은 외곽선 글씨, 남은 % = 오른쪽. 맞은 만큼 흰 잔상이 늦게 줄어듦.
   - 색: 보스 바 = 진홍 + 금 테두리, **내 체력바 = 초록**(둘 다 빨강이면 헷갈림).
   - 기믹 안내 = 보스 바 바로 위 가운데 한 줄(2초 뒤 흐려짐). 보스전 중 화면 위쪽은 비움(클리어 시간만 오른쪽 위 작게).
   - 로블록스 채팅 창 = 보스전 동안 작고 투명하게(끄지 않음).
   - 아트 스위치 끔 = 옛 자리 그대로(스위치 규칙).
2. **가방 창 상단 버튼**(STATUS ⑫): ▼ 두부(GothamBold에 없는 글자) · "등급…" 잘림 · UIStroke Contextual 회색 판.
   - 기호는 그림 아이콘(ImageLabel)으로 · 글자 잘림 없게 폭 · 버튼 테두리는 Border 모드.
   - 문구: "정렬: 등급 ▾"(등급 → 레벨 → 부위) · "자동 처리: 영웅 이하 ▾" · "일괄 판매". 일괄 판매는 **스킬 변형 장비 · 잠금 · 착용 중 제외**.
   - 같은 테두리 문제가 다른 탭 버튼에 있는지 전수 확인.
3. **가방 버튼 중복**: 오른쪽 "가방"(Shell.lua) 제거. 메뉴는 왼쪽 세로 줄 한 곳.
4. **왼쪽 메뉴 = 레퍼런스 순서 · 기능별 색 아이콘**(3톤 + 굵은 외곽선 + 모서리 단축키 칩). 자주 쓰는 가방 · 성장 · 지도 상시, 7개 넘으면 "더보기". 오른쪽 파티 · 순위 · 귀환 글자 버튼 → 같은 스타일 아이콘. 단축키 = 기존 키 우선(퀘스트 J 유지 → 펫 등 겹치면 빈 키로, 보고).
   - 아이콘 = PNG(256, 투명) 제작 → Open Cloud Decal 업로드(upload.py) → HudIcons 표. 코드로 그린 도형 대체.
   - **퀘스트 아이콘** = 두루마리 + 체크, 받을 보상 있으면 빨간 점.
5. "최고 기록 n" 등 작은 글씨 대비 부족 → 외곽선 · 크기 단계.
6. 한글 = 굵은 기본 폰트 + 외곽선(카툰 영문 폰트는 한글 없음). 기호 글자(▼ ☐ ✓ ≈ 등) 전수 검색 → 폰트에 없으면 아이콘으로.

## B. 이동 게이지 (활강 GlideController · 점프 AirChargeDots · 대시 SkillSlots SHIFT)
- 쓸 때만 보이고 가득 차면 사라짐 · 레퍼런스 스타일.
- 대시 = Shift 칸 원형 쿨 + 칸 아래 점(충전 수). 따로 떠 있는 게이지 없음.
- 점프 스택 = 공중에서만 발밑 옆 점 n개, 착지하면 사라짐.
- 활강 = 활강 중에만 캐릭터 오른쪽 옆 원형 링(점 16개 고리 → 매끈한 링), 적으면 노랑 → 빨강 깜빡.

## C. 보스 공통
1. **평타 = 바닥 전조 없음**(6종 확인됨 - 유지). 바닥 표시 = 강공격(기절 등 큰 효과) · 큰 패턴 · 기믹만. 예외 = 심해 군주 삼지창.
   - 평타 읽기 = 몸짓: 0.25초 예비 동작 + 휘두름 궤적. 예비 번쩍임 · 궤적이 **아트 끔에서도** 나오게(전투 가독성 - 스위치 예외). 빨간 궤적이 맞은 뒤에 그려지는 것 → 휘두르는 동안 그려지게, 6종 모두.
   - 평타 피해는 낮게 유지(전조 없는 공격으로 난이도를 올리지 않는다).
   - 평타 변형 2~3가지(좌→우 · 우→좌 · 내려찍기) 불규칙(같은 변형 연속 2회까지). 피해 · 간격 불변.
2. **판정 vs 모션 도달 일치**(STATUS ⑥ 표 기준, 목표 비율 0.9~1.1):
   - 판정 > 모션(평타 반경 26 vs 모션 11~24 = 0.48~0.93, 심해 꼬리 0.65~0.73): **판정 그대로, 모션 · 무기 궤적 · 바람/충격 이펙트를 판정 끝까지 키움**(평타 = 판정 끝까지 닿는 큰 쓸기 궤적).
   - 모션 > 판정(서리 강화 평타 1.83 · 전갈 모래 잠복 1.84 등): 보이는 것이 판정보다 크면 "맞은 줄 알았는데" 혼란 → **판정 그대로, 이펙트 · 모션을 판정 크기로 줄임**.
   - 심해 꼬리 공격: 대상 쪽으로 휘두르게 방향 수정.
   - 수정 뒤 같은 하네스로 표 다시(전후).
3. 원 안 강공격 원 크기 · 평타 타이밍(STATUS ⑩ 새 버그) 수정.

## D. 보스별
- **전갈 여왕**
  - 모래 찾기 야바위: 공개(진짜 꼬리 전구처럼 깜빡) → **마지막 약 3초 불 꺼짐 + 빠르고 불규칙한 섞기**(멈춤 길이 · 방향 전환 · 교차 경로 무작위) → 멈춤 → 때리기. 공정성: 두 둔덕이 0.8초 넘게 완전히 겹치지 않기 · 최고 속도 상한(추적 가능) · 멈춘 뒤 가장 먼 둔덕까지 도달 시간 보장(limitSeconds 안). 이 기믹으로 전멸 1회 뒤(힌트 단계) 불 꺼짐 3 → 2초.
  - 둔덕 외형: "네모 웨하스 + 랜턴" → 둥근 모래 언덕 메시 + 모래에서 튀어나온 휘어진 꼬리 끝(모든 둔덕에 꼬리, 진짜만 빛남) + 이동 시 모래 먼지 줄.
  - 돌진 중 꼬리가 몸에서 떠 있음 → 수정, 전갈 전 동작에서 파트 뜸 검사.
- **심해 군주**: 삼지창 던지기(원거리 · 유저 대상 · 인당 조준) = 대상 쪽 직선 전조(약 1초, **바닥 표시 있음**) → 박힘 → 약 1초 뒤 같은 선으로 되돌아오며 다시 판정. 강공격 줄 규칙 안(원거리 직업 이중 부담 금지). 피해 = BossSim으로. 판 털기 낙사 없앰(00 문서 결정 5).
- **폭풍 군주**: "내가 표적!" 글자 삭제 → 표적인 사람 머리 위 노란 "!"(두근거림) → 번개 떨어지면 사라짐. 여러 명이면 표적만, 파티원에게도 보임. 바닥 원 유지. 근접 공격 범위 · 모션 일치(C-2). 첫 근접 뒤 패턴까지 오래 걸리는 문제 = 00 결정 1 적용 뒤 재측정.
