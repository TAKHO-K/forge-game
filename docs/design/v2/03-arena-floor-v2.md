# 03 보스 아레나 바닥 · 배경 v2 (사용자 09-30: "보스전 바닥이 구리다" · "맵 뒤로 초록 맵이 보인다")

## 문제
- 남색 단색 평면(거리감 없음) · 원이 다각형 모서리로 보임 · 바깥 무채색 회색 평면 · 원판 소품이 바닥과 같은 색 · 평평한 조명.

## 원칙
- 전조(빨강 · 주황 장판)가 가장 잘 보여야 한다 → 바닥 = 중간 밝기 · 낮은 채도 · 잔무늬 적게. 바닥에 빨강 · 주황 · 흰+자홍 · 검정+금 금지.
- 텍스처 없이 모델링(석판 · 이음매 · 턱 · 베벨) + 색 3~4단계로 카툰 질감.
- 성능: 바닥 메시 파트 ≤ 10 · 삼각형 ≤ 5,000 · 광원 ≤ 6(폰 = 광원 대신 발광 재질).

## 공통 틀
1. 진짜 원형 바닥 메시(다각형 모서리 제거). 판정 파트(바닥 충돌 · 붕괴 조각)는 크기 · 충돌 불변, 겉모습만.
2. 동심원 석판 무늬: 안쪽 원(12 stud) 경계 = 석판 고리 경계 · 구간 수호자 붕괴 조각 경계 = 석판 이음매(어디가 무너질지 바닥이 말해 줌).
3. 석판마다 명도 ±5~8% · 이음매 어두운 선 · 모서리 베벨.
4. 가장자리: 한 단 올라온 턱 + 부서진 기둥 · 화로(보스 테마 색 불빛). 바깥 = 아레나가 떠 있는 절벽, 아래 구름 · 안개 바다 → 아레나 밖 사냥터 · 다른 아레나가 안 보이게(A2-N4 배경 링과 합침). 6아레나 × 4방위 캡처로 초록 0.
5. 조명: 가운데 약간 밝고 가장자리 어두움.
6. 지진 구덩이 · 균열 시간 날씨가 겹쳐도 전조 가독성 불변.

## 보스별
| 보스 | 바닥 | 가장자리 · 바깥 |
|---|---|---|
| 구간 수호자 | 오래된 원형 석판 광장 + 룬 새김(옅은 청록 선) | 무너진 기둥 · 절벽 아래 구름 |
| 서리 거인 | 두꺼운 얼음 판 + 눈 쌓인 이음매 | 고드름 · 눈보라 안개 |
| 심해 군주 | 젖은 산호석 + 얕은 물웅덩이 반사 | 산호 기둥 · 해무 |
| 수정 여왕 | 자수정 결정 판 + 옅은 보라 결정 맥 | 솟은 수정 · 동굴 천장 반짝임 |
| 전갈 여왕 | 모래가 이음매를 메운 유적 타일 | 반쯤 묻힌 기둥 · 모래 폭풍 벽 |
| 폭풍 군주 | 떠 있는 섬 바위 + 번개 문양 동심원 | 구름 소용돌이 · 먼 번개 |

## 순서
- 구간 수호자 먼저(세로 절단) → 전조 대비 · 성능 확인 → 나머지 5종.
