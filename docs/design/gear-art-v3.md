## 4. 메시 구조 (세트마다 메시를 만들지 않음)
- 모양 단계 5개: S1 일반 / S2 희귀·영웅 / S3 전설 / S4 유물·고대 / S5 태초·초월.
  같은 단계 안 등급 차이 = 색 + 작은 부품 켜기/끄기(영웅 = 희귀 + 보석 2 · 이중 테두리 / 고대 = 유물 + 관·깃 층 / 초월 = 태초 + 균열 선).
- 메시 수 = 4직업 × 3부위 × 5단계 = 60 + 무기 4 × 5 = 20 → 80.
