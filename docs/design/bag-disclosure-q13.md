# 가방 · 일괄 분해 · 확률 공개 (QUEUE-10h Q13 · 2026-09-29)

## 1. 가방 30칸(실험 스위치 30 ~ 40)
- `SaveConfig.bagBaseSlots = 30` · 칸 수 = 저장값(inventorySlots = 옛 기본 20 + 마일스톤 +5) + (스위치 − 20) - 식 한 곳 `InventorySync.capacity`(서버 판정 · 클라 스냅샷 slots 같은 값).
- 저장값을 안 바꾼다 → 스위치를 20으로 내리면 그대로 옛 칸 수(이관 없음 · 넘친 장비는 가방에 남고 판매 · 분해로 풀림 - 태초와 같은 규칙).

## 2. 등급 선택 일괄 분해(무료)
- 가방 [일괄판매] 확인 창에 [분해 N] 버튼 - 같은 기준 등급 드롭다운. 대상 = `Loot.isBulkDismantleTarget`(서버 판정 · 클라 개수 같은 함수): 잠금 X · 영웅(분해 최소) ~ 기준 등급(일괄판매 상한 전설 이하) · **초월 · 태초 제외**(태초는 풀어도 한 개씩만).
- 결과 = 한 개 분해와 같음(같은 등급 · 레벨 · 옵션의 보석) · 즉시 저장 · 로그 `[Q13] 일괄 분해`.
- 전리품 필터 = G1-2 자동 처리(등급별 줍는 순간 판매 · 분해) 이미 있음 - 확인만.

## 3. 확률 공개(한 소스 `shared/Disclosure.lua`)
| 표 | 소스(서버 굴림과 같은 것) |
|---|---|
| 잡몹 장비 등급(티어 1 ~ 6) | `DropTable.disclosure().field` |
| 보스 첫 클리어 · 토벌(재도전) · 반짝이 | `DropTable.disclosure()` |
| 강화 +0 ~ +29(성공 · 유지 · −1 · −2 · 초기화) | `Enhance.getOutcomeTable` |
| 옵션 리롤 · 드랍 옵션(직업 풀 균등) | `Option.poolFor` - `OptionData.disabled` 스위치 즉시 반영 |
| 스킬 변형(출현 10% · 칸 · 변형) | `SkillVariant.disclosure` |
| 부화(부화 레벨 × 알 등급) | `Pet.disclosure` |
- 창 = 퀘스트 창 [확률 보기] · 표 버전 = 표 전체 지문(FNV-1a 8자리) · 서버 시작 로그 `[Q13][확률표] 버전 …`(표가 바뀌면 값이 바뀜 - 비활성 스위치 켜고 끄면 바뀌었다 돌아옴 확인).

## 4. 몬테카를로 대조(10만 회 · QueueVerify Q13 · 서버 굴림 함수 그대로)
| 표 | 서버 함수 | 최대 절대 오차(%p) |
|---|---|---|
| 잡몹 등급(6티어) | 태초 따로 굴림 + `Loot.gradeForRoll` | 0.255 |
| 강화(+0 · 10 · 18 · 22 · 29) | `Enhance.rollResult` | 0.286 |
| 옵션(활 풀) | `Option.rollFor` | 0.266 |
| 스킬 변형(대검) | `SkillVariant.roll` | 0.078 |
| 부화(희귀 알 · Lv 5) | `Pet.rollHatch` | 0.126 |
- 기준 0.5%p(10만 회 표준오차 약 0.16%p의 3배) - 전부 통과.

## 5. 결정 필요
1. 가방 스위치 값 30 · 35 · 40 중 확정(성장 · 판매 빈도 영향 - 30 추천: 드랍 1시간분이 넘치지 않는 최소).
2. 확률 공개 창의 자리 - 지금 퀘스트 창 줄. 상점(P4c) 생기면 상점 안 [확률] 탭이 표준(손대지 말 것 - 상점).
