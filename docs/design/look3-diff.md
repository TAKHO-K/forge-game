## 2. 따르지 않은 것
- 아이콘의 "몸 전체 등급색" → 3-1절 색 구역 유지(등급색 = 판금 에나멜 · 장갑/신발 = 커프 띠 · 무릎 판). 파워레인저 재발 방지.
- 장갑 · 신발 수정 가시(시트 ④) → 짧은 돌기 · 박힌 보석(착용 +10% 규칙).
- 무지개 띠(태초) → 자홍 띠만(지도 색 한 가지 - 무지개 그라데이션은 지도 크기 대비 읽히지 않음).
