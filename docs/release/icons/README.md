# 출시 아이콘(QUEUE-ALL5 E)

Creator Hub에 올릴 개발자 상품 8 · 게임패스 5 아이콘과 게임 아이콘 후보 3장. 전부 512 × 512 PNG · 그림 안 글자 없음(번역 규칙). **업로드는 아직 안 했다**(사용자가 Creator Hub에서 직접).

상품 목록 기준 = `docs/phase/launch-checklist.md` §1-2(데이터 `roblox/src/shared/data/MonetizationData.lua`). 파일명 = MonetizationData 키.

| 규칙 | 출처 |

## 다시 만들기

```
# 1) Blender 원본(모양이 바뀔 때만 - 캐릭터 · 슬라임 · 드래곤 날개 · 구름 고래 · 펫 → docs/release/icons/src)
bash roblox/tools/blender/bl.sh roblox/tools/icons/store_renders_blender.py

# 2) 아이콘 16장 + _sheet.png(Pillow · numpy)
python roblox/tools/icons/make_store_icons.py
```

- 생성기는 저장 전에 크기 512 × 512 · RGBA · 상품/패스 투명 모서리를 검사한다(틀리면 멈춤).
- 원본 렌더는 리포 FBX · 메타를 건드리지 않는다(`make_cosmetics.py`는 불러오면 FBX를 다시 내보내므로 `main` 앞까지만 실행해 `parts()`만 쓴다).
