## A-1 가방 자동 정리

이미 있던 G1-2 "줍는 순간 자동 처리"(저장 `profile.autoProcess` = 켜짐 · 기준 등급 · v36)를 지시대로 넓혔다. 새 저장 구조는 없다.

- **판정(서버)**: 새 공용 함수 `Loot.isAutoProcessTarget(item, 기준 등급)` = 일괄 판매와 같은 `Loot.isBulkSellTarget`(잠금 · 스킬 변형 제외) + 기준 등급 = `ArmorData.autoProcessGradeChoices` 안(영웅 이하 - 전설 이상은 고를 수 없음) + **보스 · 토벌 출처 장비 제외** + **태초 · 초월은 어떤 값에서도 false**. `PlayerProfile.autoProcessDrop`이 이 함수만 본다(클라 값은 켜기 요청 · 방식 저장뿐 - 서버가 `setAutoProcess` · `SettingsService.sanitize`로 검사).
- **방식 [판매 / 분해]**: 설정 키 `autoProcessMode`(choice · 기본 `dismantle` = G1-2 옛 동작: 영웅은 보석, 일반 · 희귀는 판매 - 분해 불가 등급) · `sell` = 영웅도 골드(`Loot.getSellPrice` - 일괄 판매와 같은 값).
- **기본 등급 = 일반**: 끈 상태에서 켜면 "일반 이하"부터(끔 → 일반 → 희귀 → 영웅 → 끔). 기본은 꺼짐 그대로.
- **처음 가득 찼을 때 한 번만 안내**: 줍기 실패(`InventoryFull`) 때 자동 정리가 꺼져 있고 설정 `autoProcessHintSeen`이 false면 확인 창 "가방이 가득 찼어요 / 자동 정리를 켜면 낮은 등급 장비가 자동으로 정리돼요. [나중에] [켜기]"(상점 · 가방 패스 문구 없음). 띄우는 순간 본 것으로 저장.
- **알림**: 하나씩 띄우던 줄 → `ArmorData.autoProcessToastBatchSeconds`(3초) 동안 모아 한 줄 "자동 정리 n개 · +X골드 · 보석 +m".
- **화면**: 설정 → [게임] "자동 정리" · "자동 정리 방식" 두 줄 + 안내 한 줄 / 가방 판매 등급 드롭다운 맨 아래 "자동 정리: …" · "자동 정리 방식: …"(같은 값).
