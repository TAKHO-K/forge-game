## ④ D. 문서 조사 (코드 수정 없음 · 다음 단계 재료)

**1. 세트 장비 재료**
- 방어구 = **3부위(갑옷 · 장갑 · 신발)** 뿐(`EquipSlots.order`). **장신구 없음.** 무기는 드랍 없이 직업별 1개(강화 · 보석 · 환생 등급).
- → **세트는 방어구 3부위 전부 = 3세트**(한 세트 = 갑옷 + 장갑 + 신발).
- 아이템 저장 필드 = `{ grade, part, dropStage, itemLevel, tierIndex, locked, option = { id, roll, roll2 } }`. **출처(보스 · 잡몹 · 반짝이) · 세트 · 직업 태그 필드 없음**(출처는 로그에만).
- → **세트용 출처 태그 저장 필드가 새로 필요하다**(예: `source = { kind = "boss", bossId }` 또는 `setId`) - SAVE_VERSION + migrate(옛 장비 = 태그 없음). **구현은 BR**(보스 드랍 장비에만 붙인다).
- 계승(`shared/Inherit.resultItem`): B를 통째로 복사하고 옵션만 A · B 중 고른 쪽 - 등급 · itemLevel · tier · dropStage는 B. **새 태그 필드도 B를 따라가게 할지(세트 유지) · 계승을 막을지 BR에서 정한다.** 분해는 옵션 · itemLevel을 보석으로, 리롤은 옵션만.
- 보스 드랍 생성: `CombatResolution.lua:161-171`(첫 클리어 / 재도전 분기) → `Loot.rollBossFirstClearDrop`(193-198) · `Loot.rollBossRetryDrop`(202-205) · itemLevel = 보스 스테이지 + (0 / 7 / 15) · tierIndex 1 고정. 태그는 이 두 함수에서 붙이면 된다.

**2. 맵 확장 재료(M1)**
- 월드: 3 × 3 구역(한 변 256 · 복도 32 · 간격 288) · 맵 한 변 832(**원점 ±416**) · 가장자리 투명 장벽 36. 보스 아레나 **슬롯 12개**(z = −3000 − 468 × (i − 1), 반경 140).
- StreamingEnabled = 켜짐(place). 반경 600은 기록만 - `default.project.json`에 Workspace 노드가 없어 스트리밍 설정이 git에 없다(수동 설정). 코드는 몬스터 모델 `ModelStreamingMode = Atomic`만.
- 인스턴스 · 파트: 마을 1,874 · 1,046 / 사냥 1,848 · 1,039 / 보스전 1,908 · 1,067(`docs/perf/baseline.md`) · 16인 스트리밍 파트 1,456 / 상한 1,500(여유 3%).
- 몬스터: 서버가 부팅 때 54마리를 한꺼번에(플레이어 근처 생성 아님) · 전부 서버 소유 · 모든 클라에 복제 · **사람마다 다른 스테이지는 인스턴스가 아니라 수치**(때린 사람의 스테이지로 HP 비율 · 공격 · 보상 계산) → 남의 몬스터도 보인다. 보스만 개인 · 파티 전용 슬롯.
- 위치 데이터: 전부 `WorldConfig`(구역 = 중심 + 반폭 + 입구, NPC = 구역 중심 + 오프셋). 세우는 곳 = `HuntingGround.server.lua`.
- 보스 입장: `StageMoveRequest` → `StageServer`(검사 · 파티 투표) → `performMove` → `BossEncounter.spawnFor`/`spawnForParty` → `spawnEncounter`(슬롯 · `BossArenaMap.dress` · `teleportTo` = 루트 CFrame 직접 대입) → `MonsterSpawner.spawn`.
- **`RequestStreamAroundAsync` 사용 0건** → **포탈 · 보스 입장 순간이동 때 도착지를 미리 불러오는 호출이 필요하다(M1)**. 넓은 맵에서는 도착지 파트가 아직 안 와서 떨어지는 문제가 생긴다.

**3. 보스 원칙 기록** - `docs/design/boss-rules.md` §1: "모션이 클수록 피해도 크다" - 작음(짧은 전조 0.8 ~ 1.2 · 10 ~ 20%) / 중간(1.2 ~ 2.0 · 20 ~ 35%) / 큼(2.0 이상 · 35 ~ 55% · 기믹), 회피 부등식과 일치(짧은 전조 + 큰 피해 금지). 지금 데이터와의 어긋남 표 포함(돌진 1.5초 · 55% 등).
