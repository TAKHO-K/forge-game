# 로드맵 v2 - 작업 순서 초안 (D0 · 2026-09-25)

- 입력: 사용자 문서(`docs/direction/0925-user-direction.md`) + D0 조사(`D0-audit.md`) + 결정 시트(`D0-decisions.md`) + 기존 남은 일(`docs/sonnet/README.md`의 S21 · F2 ~ F6 · S02 단계 2, 사용자 목록의 P4 · V0 · P5 · P6).
- 사용자 문서 10 · 11장의 "두 번의 대규모 세션" 구분은 참고만 했다. 실제 순서는 이 문서가 정한다.
- **원칙 순서(사용자 결정 2026-09-25 - 큰 그림 먼저)**: G1 코어 루프 → **G2a 이동 수치 확정** → **M1 맵 그레이박스(방대한 맵)** → **G2b 보스 난이도 · 몬스터 모션** → A1 카툰 시범(새 맵 한 구역 + 보스맵 1) → BR 보스 개편 → K(T) → A2 카툰 본 제작(그레이박스 채우기) → 펫 → P4 → 번역 → V0 → P6. 이동 수치(점프 · 속도 · 카메라)가 맵 크기 · 지형 높이를 정하므로 맵보다 먼저, 맵이 보스 입구 · 몬스터 구역 · 성능 예산을 정하므로 보스 난이도 · 카툰보다 먼저 한다. **"오픈월드 출시 전 유지"(D0 결정 9 가)는 폐기.**
- **단계** = 지금까지의 자율 단계 하나 크기(코드 + 로컬 검사 + Play 최대 3회 + 보고서). **단계당 1 ~ 2시간**(실측 - 첫 커밋 → 보고서 커밋: P3d-F 51분 · D0 46분 · P0 46분 · P2 1시간 20분 · P2.5a 1시간 55분. 초안의 4 ~ 6시간 추정은 버렸다). 사용자 확인(체감 · 폰 실기 · 승인)과 외부 검수는 시간에 넣지 않았다.
- 표의 "결정"은 `D0-decisions.md` 번호. 결정이 안 나면 그 단계는 추천안으로 진행하고 보고서에 적는다(CLAUDE.md "가정을 말하고 진행").
