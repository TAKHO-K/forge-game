## ⑩ 알려진 문제(재조사 안 함)

- 먼 설산 윤곽이 뭉개져 보인다(스트리밍 저해상도 먼 지형 표시 - 클라에 r 2,700 밖 복셀이 아직 없을 때). 가까이 가면 봉우리가 제대로 나온다(t1-peak-gate). Persistent가 없는 Terrain 특성 - 필요하면 산맥 실루엣 imposter(M1-2b 방식)를 A1에서.
- 급경사 지형을 연타로 약 30 오를 수 있다(엔진이 가파른 면도 "바닥"으로 읽는다 - MaxSlopeAngle 45는 걷기만 막는다). 설계한 오를 곳(파트)에는 영향 없음.
- 실제 키보드 · `Humanoid:Move`가 이 Studio 창에서 반영되지 않아(스페이스 · 이동) 급경사 오르기는 속도 대입으로 흉내 냈다(물속 대시 · 알 줍기 F는 실제 키 입력으로 확인).
- 클라 지형 메모리 몫은 Studio에서 못 가른다(서버 · 클라 한 프로세스) - 실기 폰 실측 필요.
- 번개 문은 열고 닫히기만 한다(번개 빛 연출 없음 - 새 파티클 금지 · A1).
- 옛 M1 파트 지형(탑 · 굴 · 폭포 · 기둥 상자)은 그레이박스 그대로(돌 재질만 바꿈).
- 몬스터가 추격하다 강 · 호수로 들어가는 경우는 안 쟀다(스폰 지점은 물을 피한다 · 지면 광선은 물을 무시).
- 흔들다리 흔들림 · 반딧불 · 발견 연출은 스크린샷 · 체감 확인 전(사람 확인).
