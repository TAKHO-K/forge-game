B. 캐릭터 칸(슬롯) 저장 구조 — 사용자 확정
B1. 공유 범위(사용자: "도감과 치장만 공유")
- 캐릭터별: 가방 · 골드 · 장비 · 보석 · 강화 · 레벨 · 경험치 · 환생 · 수련(공용/고급/방어) · 계승/초월 · 스테이지 · 메인 퀘스트 · 직업 옵션 · 쿨 · 궁 게이지 · 위치.
- 계정 공유(치장 계열): 도감 진행도 · 점수 · 줄 칭호 · 치장 아이템 · 꾸미기 토큰 · 칭호 전체 · +30 증표 · 펫(전투 없음 = 동행 치장으로 분류).
- 계정 단위(결제 · 운영상 필수): 게임패스/개발자 상품 권리와 구매 기록(PurchaseId) · 가방 확장 권리(모든 캐릭터와 이후 새 캐릭터에 적용) · 시즌 패스 진행 · 시즌 출석판 · 7일 출석 · 일간/주간 퀘스트(계정 1세트, 보상은 받는 캐릭터에게 → 칸 수만큼 보상 불어남 방지) · 설정 · HUD 배치 · 우편함(치장만) · 명예의 전당.
B2. 도감 보상 몰아주기 차단
- 칸 보상(골드 · 재료)은 그 칸을 완료한 캐릭터만 받기 가능 · 골드 양 = 완료 순간 "그 캐릭터"의 최고 스테이지로 고정(옛 "계정 최고 스테이지" 기준 변경).
- 점수 보상판의 골드/재료 = 계정 1회 · 받는 캐릭터에게.
- 7일 출석의 성장 보상(환생 무료권 등) = 계정 1회 · 받는 캐릭터에게.
B3. 칸 규칙
- 칸 수 = 출시된 직업 수(출시 4 · 신직업 데이터 추가 시 자동 +1) · 어느 칸이든 아무 직업 · 같은 직업 중복 허용.
- 캐릭터 = 직업 고정(직업 바꾸기 = 새 캐릭터).
- 캐릭터 삭제 없음 → "보관": 확인 창 → 칸에서 빠지고 보관함으로(데이터 그대로 · 언제든 복구 · 보관 최대 10 · 복구하려면 빈 칸 필요).
- 캐릭터 이름 직접 입력 없음 → 직업명 + 번호(전사 ① · 전사 ②).
B4. DataStore
- 계정 키 1개(공유 + 칸 목록 + 보관 목록) + 캐릭터 키 칸당 1개(키 이름 50자 이하).
- 값 상한 4,194,304자 → 가방 80 · 최대 데이터 기준 최악 크기 측정해 보고(목표 상한의 25% 이하).
- 세션 잠금 = 계정 키 기준으로 그 계정의 모든 캐릭터 키 보호(두 서버 동시 접속 · 빠른 재접속에서 복제 0).
- 캐릭터 전환 시 이전 캐릭터 저장 완료 확인 후 다음 캐릭터 로드(UpdateAsync는 읽기+쓰기 예산 둘 다 소모 → 메뉴 왕복 최소 간격 5초).
B5. 마이그레이션(저장 버전 현재 +1)
- 기존 단일 프로필 → 1번 칸 캐릭터(현재 직업) · 공유 대상은 계정 키로 복사 후 검증.
- 옛 저장 원본은 지우지 않고 legacy로 보존(읽기 전용) · 다른 직업의 직업별 데이터도 legacy에 그대로.
- 기능 스위치 SlotSave(켬 = 새 구조 · 끔 = 옛 경로) · 끔으로 되돌려도 데이터 손실 0 확인.
B6. 순위 · 기록
- 개인 순위 = 유저당 가장 높은 캐릭터 1줄 · 직업별 순위 = 유저당 그 직업 최고 캐릭터 1줄 · 파티 기록 = 캐릭터 기준 · 전 서버 최초(초월 +10/+15/+20) = 유저 기준.
- 히든 칭호 "환생 없는 초월자" 조건 = 그 캐릭터의 환생 0회 · 칭호는 공유.
B7. 새 캐릭터
- 두 번째 캐릭터부터 FTUE(첫 5분 튜토리얼)는 "건너뛰기" 선택 가능(계정에서 한 번 완료했으면) · 메인 퀘스트는 캐릭터별로 처음부터.
B8. 검증
- 결제 하네스 60건 재실행 + 추가: 구매 중 캐릭터 전환 · 다른 캐릭터에서 산 가방 확장이 모든 캐릭터에 적용 · 새 캐릭터 생성 후 적용.
- EconSim 4프로필: 공유 범위 변경 영향(캐주얼 1,000 · 상위 1% 25,300 시간) ±2% 이내면 통과, 넘으면 원인과 함께 보고.

C. 메뉴 건너뛰기 제거 · 직업 선택은 메뉴에서만
- "다음부터 메뉴 건너뛰고 바로 시작" 옵션 UI 제거 · 저장 필드는 남기고 무시(켬이던 유저도 메뉴 표시).
- 게임 안 직업 변경 입구 숨김(코드 경로 · 데이터 id 삭제 금지). 그 자리 안내: "다른 직업은 메인 메뉴에서 새 캐릭터로 시작할 수 있습니다." + [메인 메뉴로] (ko/en).
- 서버: 직업 지정은 새 캐릭터 생성 때만 허용 · 기존 캐릭터 직업 변경 요청은 거부(클라 값 신뢰 금지).

D. 설정 → [메인 메뉴로] · 쿨/게이지 유지
- ...더보기 → 설정 → [메인 메뉴로] → 확인 창 "메인 메뉴로 이동합니다. 진행 상황은 저장되고 파티에서 나가게 됩니다."
- 금지 상태(버튼 회색 + 이유 1줄): 보스전 · 토벌 · 보스 관문 대기 · 거래/선물 진행 · 강화/합성/계승 연출 중. 기존 "보스전 직업 변경 막기" 판정 재사용.
- 메뉴로 갈 때: 즉시 저장 · 캐릭터를 월드에서 뺌 · **파티 해제**(사용자 확정).
- 이어하기로 돌아올 때: 그 캐릭터의 마지막 위치(보스방 안이었으면 관문 앞).
- ★쿨 · 궁 게이지 유지(사용자 확정): 쿨은 "남은 시간"이 아니라 서버 시각(os.time) 기준 종료 시각으로, 게이지는 값 그대로 캐릭터 저장에 기록. 메뉴 왕복 · 강제 종료 · 튕김 · 재접속 · 다른 서버 접속 모두 같은 값으로 복원. 보스 진입 시 게이지 초기화 등 기존 규칙은 그대로. 기존 튕김 규칙(보스전 관전 복귀 · 보상 자격) 유지.

E. 이어하기 → 오른쪽으로 펼쳐지는 창
- 이어하기 누르면 오른쪽으로 창이 미끄러지며 펼쳐짐(약 0.25초 · 폰 = 화면 오른쪽 절반 이상 · 엄지 크기 버튼).
- 카드(진행도가 한눈에): 직업 그림 + 직업색 · "전사 ①" 번호 · 레벨 · 최고 스테이지 · 환생 횟수 · 대표 무기(등급색 테두리 + 강화 단계 · 초월이면 초월 표시) · 총 플레이 시간 · 마지막 플레이.
- 같은 직업 여러 개 = 번호 + 위 숫자로 구분되는지 캡처로 확인.
- 마지막 플레이 캐릭터가 맨 위 + 선택된 상태 · 같은 카드 한 번 더 누르면 시작(반복 유저 = 탭 2번).
- 빈 칸 = "+ 새 캐릭터" → 직업 선택 화면(F).
- 다음 직업 출시 때 열릴 칸 = 잠긴 칸 "새 직업 출시 때 열림"(날짜 약속 없음).
- 카드 ⋯ 메뉴 = [보관] (확인 창) · 창 아래 [보관함](복구).
- 시작 연타 · 중복 요청 1회 처리.

[버그 · 우선 처리 — 지금 하는 항목 끝나면 바로] 사용자 확인(10-05, Play 검증마다): 로딩 후 메인 메뉴(첫 화면)가 뜨지 않고 항상 바로 게임으로 들어감. 지시 = "메뉴 건너뛰기 옵션 제거 · 저장 필드는 무시 · 메뉴는 항상 표시".
1. 원인부터 찾아서 보고(코드 위치 포함). 의심 순서:
   ① Studio/자동 검증용 메뉴 건너뛰기(RunService:IsStudio() · 테스트 속성 · MCP Play 스크립트 등)
   ② 옛 "메뉴 건너뛰기" 저장값을 아직 읽음
   ③ MENU2의 마지막 캐릭터 자동 이어하기
   ④ 메인 메뉴 화면이 기능 스위치로 꺼짐 · 로딩 화면이 끝나면 바로 스폰
2. 고칠 것:
   - 메인 메뉴는 모든 접속에서 표시(Studio Play 포함). 캐릭터 선택 전에는 캐릭터를 월드에 스폰하지 않음(메뉴 → 이어하기/시작하기 → 그때 스폰).
   - 옛 건너뛰기 저장값은 읽지 않음(필드는 삭제하지 않고 남김).
   - 자동 검증용 건너뛰기가 필요하면 "검증 스크립트가 명시적으로 켜는 테스트 플래그"로만(기본 꺼짐 · Studio라는 이유만으로 켜지면 안 됨). 플래그 이름과 켜는 방법을 보고서에 기록. 기존 검증 체인은 이 플래그를 켜서 돌도록 수정.
   - 자동 이어하기 없음: 이어하기 창에서 같은 카드를 두 번 눌러야 시작(01 메인 메뉴 spec 그대로).
3. 확인:
   - 하네스: 접속 → 메인 메뉴 표시 · 캐릭터 미스폰 / 테스트 플래그 꺼짐 상태에서 건너뛰기 0회 / 옛 저장값 켬인 계정도 메뉴 표시 / 설정 [메인 메뉴로] → 메뉴 → 이어하기 정상.
   - Studio Play 캡처(PC · 폰 800×360): 접속 직후 메인 메뉴 화면 · 캐릭터 0개면 [시작하기] · 있으면 [이어하기].
