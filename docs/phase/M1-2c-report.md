## ② 수정

### 1 발사 허가(공용 - `server/LaunchPermit.lua` · `HeightGuard.grant / grantLaunch` · 수치 `MovementConfig.permit`)

- **허가** = "발 최고 높이" 한 장. 허용 = max(평소 22.38, 허가). **겹쳐 쌓지 않는다**(가장 최근 것만).
- **만료**: 착지(허가 뒤 공중을 한 번 봤고 0.2초 지나 서 있으면) · 안 쓴 허가(공중 없이 1초 서 있으면). 시간 상한(점프대 **4초** · 보스 = **설계 체공 + 2초**)이 지나면 바로 끊지 않고 **"내려가기만"**(상한 뒤 가장 낮았던 발 + 22.38까지) → 20초 뒤 끝 - 대시 · 활공(예정)처럼 오래 떠서 천천히 내려오면 안 잡고, 다시 오르면 잡는다.
- **점프대 · 통통 열매 · 수정 부수기 도움 발판**(클라가 스스로 튄다): 클라가 `LaunchPermitRequest(발판 파트)` → 서버는 **자기가 본 최근 0.5초 루트 위치 기록** 중 하나가 발판 기둥(반경 + 4 · 윗면 − 8 ~ 설계 정점) 안이면 허가. 요청이 위치보다 먼저 오면 0.5초 동안 새 기록으로 다시 본다(실측: 54장 중 1장이 이 경로). 사람마다 0.25초 쿨다운.
- **설계 정점 명시**: `WorldMapLayout.treeLaunch(i)`(클라 발사 식과 같은 `JumpMath.arcLaunch`) = 비행 정점 + **공중 점프 전부(2회 × 6.73 = 13.46 - 점프력 상한 포함)** → 허가 = + 여유 4. 나무 발판 파트에 Attribute `DesignApexFeetY`. 수정 부수기 발판 = `BossJumpCourse.padLaunchSpec`.
- **보스 발사**(서버가 보낸다 - 서버가 사실을 안다): 옛 `HeightGuard.exempt`(통째 예외 · 무제한) → `grantLaunch(높이, 체공)` = 출발 발 + 발사 높이(잘리기 전 값) + 공중 점프 몫 + 4. **출발 발**: 서 있으면 지금 발 · **공중이면 "마지막 지면 + 22.38"**(서버가 본 발은 늦으니 가능한 최고) · 이미 허가로 떠 있으면 그 허가 높이 위에서(연속 피격).
- **수평 검사**: 따로 있는 속도 · 수평 검사는 없다(Travel의 세계 밖 · 잠긴 구역은 자리 규칙 · 보스전 중엔 안 돈다). 유일한 수평 규칙 = HeightGuard "한 폴링에 50 넘게 움직임 = 순간이동으로 보고 기준을 새로" - 던지기(초속 355) · 판 털기(118)가 여기 걸려 기준이 공중으로 옮겨졌다 → **허가 비행 중엔 순간이동으로 안 본다**. 맵 밖으로 날아가면 보스맵 안 리스폰(`BossArenaContainment` - 기존) 그대로 · 서버 순간이동은 허가를 지운다.
- **치트 방지 유지**: 허가 없이 같은 높이 = 되돌림(허브 +36 → 0.90 · 1.10초, 지연 0.25 → 1.08초).
