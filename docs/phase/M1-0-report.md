## ④ 필드 몬스터 - 공중에서 일방적으로 때리기

- **일방 타격은 지금 규칙으로 불가**: 몬스터 평타 · 어그로와 플레이어 스킬이 같은 높이차 상한(루트끼리 ≤ 8 - `Reach.sameLayer`)을 쓴다 - 서로 닿거나 서로 안 닿는다. 평타는 공중에서 안 나간다(착지 버퍼 19-2). 스킬(Q/E)은 공중에서 나간다.
- **틈 1 - 타이밍 회피**: 스킬을 쏘고(높이차 ≤ 8) 몬스터 평타가 닿는 순간 공중 점프로 8 위로 올라가면 안 맞는다. 충전은 착지해야 차므로 연속은 안 되지만 1.4초마다 한 번 가능하다.
- **틈 2 - 지붕 대피**: 오두막 지붕(10)에 공중 점프 1회로 오른다 → 높이차 > 8이라 어그로가 풀린다(도망은 되지만 공격도 안 닿는다).
- 제안(결정 필요 ④): 가 = 그대로(보스만 공중 전제로 강화) **(추천 - 필드는 빨리 잡는 곳이라 공중 회피가 재미 요소)** / 나 = 몬스터 평타 판정을 휘두르기 시작 때 대상 기준으로 고정(판정 순간 높이 무시) / 다 = 필드 몬스터 판정 높이만 12로.

## ⑤ 카메라 · 키 - 결정 필요

**Shift Lock 두 방식 비교(결정 = 자체 구현 - 구현함)**

| 방식 | 장점 | 단점 |
|---|---|---|
| **자체 구현(채택)** | 로블록스 카메라 · 조작 업데이트를 계속 받는다 · 코드 130줄 · 폰 버튼 · 창 열림 자동 해제를 우리 규칙으로 | 기본 Shift Lock의 마우스 아이콘 · 부드러운 전환은 없다 |
| 기본 PlayerModule 복제 · 키만 바꿈 | 기본과 똑같은 느낌 | 복제본은 업데이트를 못 받는다(수천 줄 동결) · 폰 버튼은 어차피 따로 |

**① 공격 조준 - 자유 카메라에서**
- 지금: 마우스 방향 기반(`AimTarget` - 화면 → 광선 → 지면점 → "조준 방향에 가장 가까운 몬스터", 없으면 최근접). 누운 카메라에서 **커서가 수평선 위면 지면점이 없어** 방향 힌트가 사라진다(최근접으로 대체). 시점 고정 중엔 화면 가운데 = 앞쪽이라 잘 맞는다. 폰은 터치 지점 · 마지막 지점 그대로.
- 선택지: 가 = 커서가 수평선 위면 카메라 수평 방향을 조준 방향으로 **(추천 - 작은 수정, AimTarget 한 곳)** / 나 = 그대로(최근접 대체) / 다 = 자동 조준만(방향 무시).

**② 보스 아레나 장판 가독성 - 카메라 최소 각**
- 기본 카메라는 스폰 때 약 15°로 거의 눕는다 - 장판(원 · 직선)이 납작하게 보이고 앞 장판이 뒤를 가린다. 줌 22 · 55°면 앞 49 · 좌우 68.
- 선택지: 가 = **보스전 중에만 최소 각 30°**(필드는 자유 - 보스 입장 때 한 번 35°로 맞춤) **(추천)** / 나 = 어디서나 최소 25° / 다 = 제한 없음(설정의 탑다운을 권하는 안내만).

**③ 화면 중앙 금지 구역 · ScreenMap**
- 둘 다 **화면 비율 기준의 2D 배치**라 카메라 방식과 무관하게 유효하다(판단 - 유지). 다만 시점 고정 중에는 마우스가 가운데에 묶여 **HUD 버튼을 누를 수 없다**(로블록스 기본 Shift Lock과 같다 - 창이 열리면 자동 해제). 선택지: 가 = 그대로 **(추천)** / 나 = Alt를 누르는 동안 커서 풀기.

**④ 키 재설정 UI** - P4-4(설정창)로 미룸(기록). 설정 값 저장(탑다운 · 시점 고정)도 P4-4에서 설정 묶음으로(지금은 이번 접속 동안만).
