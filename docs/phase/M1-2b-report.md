## ⑨ 결정 필요

1. **먼 나무(저품질)**: imposter는 동작하지만 저품질 그리기 거리(200 ~ 450 사이에서 잘림)는 못 넘는다. 선택: (A) 지금 유지(저품질 폰은 먼 나무가 안 보인다) / (B) 품질과 무관한 **빌보드 실루엣**(스터드 크기 BillboardGui + 나무 그림 1장 - 이미지 에셋 업로드 필요 · 멀리서만 켠다) / (C) 그래도 imposter 적용(중 · 고품질의 스트리밍 아웃 구간만 이득 · 나무를 .rbxmx 고정 자산으로 옮기는 비용). 추천 B.
2. **스폰 밀도**: 걷는 사람 1명당 동시 몬스터 약 13(지점 4 ~ 5곳 × 3 · 20초 유지). 서버 시간은 20명 p95 1.15 ms로 여유 · 몬스터 수는 옛 방식의 4배. 유지 / 활성 반경 140 → 110 · 유지 20 → 12초로 줄이기(약 절반 추정) 중 선택.
3. **수동 Play 저장**(0-6 제안): (A 추천) Studio에서 검증 모드가 아닌 Play도 저장 키를 `_manual`로 분리하고 시작할 때 실제 프로필을 복사해 읽기 - 실제 프로필은 안 바뀐다(검증 모드의 `_verify` 분리와 같은 장치) / (B) 개발 명령 `/gg save revert`(Play 시작 때 스냅샷으로 되돌림 - 잊으면 오염). A는 수동 Play에서 얻은 진행이 다음 Play에 안 남는다(원하면 `/gg save keep`로 실제 키에 복사).
