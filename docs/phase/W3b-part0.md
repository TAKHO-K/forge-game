## 3. 구현

- `CombatFormulaData.lateWall = { lift = { {5000,1}, {7500,1.2} }, flatLow = { {5000,0.7}, {7500,0.95} } }`(로그 보간 · 끝값 유지).
  - 권장 전투력(판정 · 표시 둘 다) × lift. 주는 피해 곡선의 평탄 하한만 스테이지별로 0.7 → 0.95(곡선 모양 · 다른 계수 · 받는 피해 · 보스 제외 그대로 - `CombatFormula.curve(c, r, flatLow)` 선택 인자).
  - 이유: 평탄 0.7 ~ 1.3이면 비율 0.85가 벌칙 없이 통과해 벽이 안 문다.
- `weaponGrowthSegments` 17,000 몫 0.9975 → **0.9941**(천장 감속 - §결정 2).
- EconSim: 장비 옵션(영웅 이상 1개)을 위력 환산 roll로 loadout에 붙인다(`BalanceSim` 합성 아이템이 `option`을 넘기게 한 줄). 평균 = 무작위 축(DPS 축 3/10) · roll 1.0. 보석 롤 × `optionRoll`(상한 1.125).
