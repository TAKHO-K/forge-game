## 2. 0 ~ 3 상세

### 0. 결정 반영
- **0-1**: 직업 이름이 데이터(`ClassData.displayName` 한국어)에서만 나와 영어를 켜도 한국어였다 → 화면이 읽는 곳(직업 선택 4 · 준비 중 칸 · 캐릭터 2 · 파티 · 파티 목록 · 파티 게시판 · 순위 칩 · 살펴보기 · 도감 · 스킬 변형 줄)을 `Text.get("class.name." .. id)`로. ko 키 = displayName과 같은 값(서버 로그 · 개발 도구는 displayName 그대로). 하드코딩 검사: 남은 직업 이름 = 자체 점검 고정 문장(BossBarCheck · PartyHudCheck - 개발 전용) · 수련 이름 "치유사 숙련"(데이터 이름 묶음 - 아래 알려진 한계).
- **0-2**: 게시판에서 코드 설명 · 소식 · 제목이 한국어 완성 문장이었다 → `update.board.*` 키(ko/en). 좋아요 목표 코드는 목표 달성 전에 미리 보이지 않게 `hidden`(입력은 됨) - 공지 때 지우고 업데이트.
- **0-3**: `PetService`가 이미 `getCharacterLevel`(지금 직업 · 환생하면 1로)을 쓴다 = 정해져 있음 → 레벨만 낮춤. EconSim 캐주얼(로컬 · 시드 20260923): Lv25 0.91h · **Lv30 1.85h** · Lv35 3.04h · 3h 안 최고 Lv34 · Lv200 19.53h(환생 5회 19.48h 직후).
- **0-4**: `make_store_icons.py` 이름표 두 장 다시 그림(같은 머리 + 이름표 구도 → 가로 띠 vs 세로 방패 · 타일 보라 vs 남색) · `store_renders_blender.py hero_raise`(검사 전설 외형 + 초월 대검을 오른손으로 치켜듦 - `--only hero_raise`) · D안 합성(얼굴 근접 + 뒤 빛기둥 · 방사 빛살) · 게임 안 D판 = 흑금 초월 쌍검 + 초월 드랍 빛기둥(대검으로 바꾸면 자세 고정 훅이 사라져 지금 직업으로 촬영).
