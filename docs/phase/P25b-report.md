결정 · 가정 전체 = `docs/phase/P25b-log.md`(26건 + 결정 필요 6건). 경제 = `docs/econ/P25b-after.md`(Studio Play 3회차 P0(가)의 `/gg econ all`) + 하네스 what-if `P25b-noMilestone.md` · `P25b-m02.md` · `P25b-milestoneSurvival.md`. 스크린샷 = `Claude outputs/P25b/`(PC 11장 · 폰 10장, 전부 실제 클릭으로 연 화면).

**한 줄 요약**: 네 기능 모두 서버 판정 · 확인창 · 저장(SAVE_VERSION 30 → 32)까지 들어갔고 Studio 자동 검증 41블록 중 40블록이 통과했다. 남은 X 1개(P0(가) 9 - 상위 1% 설계 최대 도달 시간)는 **마일스톤이 곡선의 천장을 없앤 결과**라 수치를 맞추지 않고 결정 필요 5로 올렸다. 장비에는 강화 · 보석 칸이 없어(무기만 갖는다) 계승은 **옵션 세트만** 옮긴다(결정 필요 1).

## ① 장비 계승

| 규칙(지시) | 구현 · 동작 확인 |
|---|---|
| A1 강화 · 보석 이전, 비용 = GoldCost, 손실 없음 | 장비(갑옷 · 장갑 · 신발)에 강화 · 보석 칸이 없다 → 옮길 값 0(결정 필요 1). 비용 `GoldCost(tier1 골드 × 등급별 처치 몫, 계정 최고 스테이지, "inherit")`. 실제 클릭: 골드 8,975 → 7,213(= 비용 1,762) |
| A2 옵션 선택(종류 + 굴림 위치, 수치는 B 레벨로 재계산) | 옵션 `{id, roll, roll2}`를 복사 - 값은 `Option.valueOf`가 B 등급 · 레벨로 다시 계산. (가) A2: A에서 위력 0.1270 → B(유물 Lv.300)에서 0.1969 = 식 대조 일치 |
| A3 개수 = B 등급 한도, B 등급 낮으면 A 세트 불가 | `Option.optionSlotsFor` · `b_grade_lower`(서버 거절 + 카드 회색 + 이유) - (가) · (나) · (UI) 모두 확인 |
| A4 보석 칸 부족 → 보석 가방, 가득 차면 거절 | 장비에 보석 칸이 없고 보석 가방은 칸 상한이 없어 해당 없음(로그 1) |
| A5 A는 분해 재료로 환급 | 영웅 이상 = 보석 1개(A 등급 · 레벨 + **고르지 않은 쪽 옵션** - 옵션 복제 방지) · 그 아래 = 판매가 골드. 실제 클릭: 보석 가방에 "전설 재생 보석 Lv.120" 도착 |
| A6 전후 최종 능력치(세트별) · 되돌릴 수 없음 확인창 · 잠금 불가 | 서버 RemoteFunction이 계산(착용 칸을 잠깐 바꿔 실제 능력치 함수로 잰 뒤 되돌림). 세트를 바꾸면 표가 바뀐다(B 세트 공격력 −4.9% ↔ A 세트 +2.7%). 확인창 = 제목 "되돌릴 수 없습니다" + 환급 + 비용. 잠금: B = `locked` · 착용 A = `a_locked`(해제 → 잠금 해제 → 재착용 안내) |
| A7 비교 화면에서 B가 좋으면 [계승] | 비교 화면이 없어 **가방 상세 바**에 "착용 대비 방어력 +14.5K" 줄 + [계승](부위 기본 효과가 클 때만) |

스크린샷: `pc-1-detail-compare` · `pc-2-inherit-keepB` · `pc-3-inherit-keepA` · `pc-4-inherit-confirm` · `pc-5-inherit-done` / `phone-1` ~ `phone-4`(폰 = 창 842 × 592 + 터치 배치 강제 + 가방 800 × 302 배치 강제 - 800 × 360 실기는 사람 확인).

## ② 재련 · 분해

| 기능 | 규칙 · 확인 |
|---|---|
| B1 재련 | 대상(홈 · 가방) ← 레벨이 더 높은 가방 보석. 레벨만 오르고 등급 · 옵션(종류 · 굴림) 그대로, 먹이 소멸. 같은 레벨 · 같은 보석 거절. (나): 장착 중 1번 홈 태초 Lv.40 → 2500(해제 없이) · 최대 체력이 새 옵션 수치로 오름 |
| B2 비용 · 장착 중 가능 | 골드(GoldCost "refine") + 가루. 가루를 먼저 확인(골드만 빠지는 실패 없음). 거절 5종(가루 · 골드 · 낮은 먹이 · 같은 보석 · 모양) 상태 불변 |
| B3 미리보기 · 확인창 · 합성 불가 유지 | "재련 뒤: Lv.11 → Lv.120 · 옵션 전후" + 확인창. 등급은 안 바뀐다(합성 없음) |
| C1 분해 → 가루 | 가루 = max(1, 반올림(등급 기준량 × 옵션 레벨 곡선)). 한 개 분해(상세 바 [분해] → 확인창) |
| C2 일괄 분해 | 기준 등급 이하 가방 보석 전부(홈 제외) - 보석은 전부 영웅 이상이라 **항상 확인창**. 실제 클릭: 영웅 이하 2개 → 가루 0 → 2 |
| C3 판매 | 보석 판매 경로는 원래 없다 - 장비 판매 규칙 그대로 |
| 가루 소모처 | 재련 · **변환권 구매(골드 + 가루)** - 리롤 · 변환 1회 = 변환권 1장이라 한 곳에만 부과 |

| 비용 표(등급) | 영웅 | 전설 | 유물 | 고대 | 태초 |
|---|---|---|---|---|---|
| 분해 가루(Lv.100 · Lv.20,000) | 3 · 4 | 5 · 7 | 8 · 12 | 12 · 17 | 20 · 29 |
| 재련 골드(처치 몫) + 가루 | 40 + 4 | 80 + 6 | 160 + 10 | 320 + 15 | 640 + 25 |
| 계승 골드(처치 몫, B 등급) | 80 | 160 | 320 | 640 | 1,280(일반 20 · 희귀 40) |
| 변환권 가루 | - | - | - | 6 | 10 |

골드 흐름(`P25b-after` ②, 일반 프로필이 그 스테이지에 처음 섰을 때 골드/분 대비): 계승 영웅 · 유물 · 태초 = 0.6 · 2.4 · 9.8분 · 재련 = 0.3 · 1.2 · 4.9분(스테이지 1,000 ~ 20,000 거의 일정 - GoldCost가 수입과 같은 율). 재련 가루 = 같은 등급 보석 약 1.2 ~ 1.3개 몫(가루 증식 루프 없음 - 리뷰 확인). 스크린샷: `pc-6` ~ `pc-9` · `phone-5` ~ `phone-8`.
