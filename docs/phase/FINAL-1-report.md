## Studio에서 사용자가 확인할 것
1. 대시 손맛(PC): 방향키 + Shift(긴 32) · W/A/D 두 번(짧은 14) · S 두 번(백플립) - 먼지 · FOV · 미끄러지듯 멈춤이 과하거나 약하지 않은지(노브 `DashConfig.feel`).
2. 폰: 대시 버튼을 스틱 조금 / 끝까지 기울여 누르기(거리 차이) · 스틱 뒤로 두 번 튕기기 백플립(MCP로 터치 입력을 못 만들어 미확인).
3. 게임패드: ButtonB 대시(새로 붙임 - 미확인).
4. 백플립 모습(뒤로 한 바퀴 · 무기 자세) · 남이 볼 때 중계.
5. 보스 밀어내기: 6보스에 몸으로 붙어 떨림 · 벽 사이 끼임 없는지(특히 매머드 · 전갈).
6. 무기 32종 겉모습(캡처 18장) · g7 태초 마젠타 빛(밤 · 어두운 아레나에서) · 단검 g1 크기(0.693배가 너무 작지 않은지).
7. 대검 일어나기 자루 끝 0.17 stud 가슴 겹침(0.05초)이 보이는지.

## 결정 필요
1. 매머드 크기: 상아 끝 → 꼬리 끝 59.5(§5 목표 상아 끝 45 · 길이 39보다 약 1.3배) - rig.scale 3.3을 줄일지.
2. 대검 Q 관통돌진 24 vs 긴 대시 32 관계(위 위험 표 ①/②).
3. 짧은 대시 미사일 통과 창(0.18초 그대로 / 0.3초로 맞춤).
4. 못 넘는 틈 기준 53 → 63(이동 기준 문서 · 맵 설계 기준 갱신 여부).
5. 서버 첫 16초 옛 내장 무기(활 = 원통) 표시 - 그동안 무기 숨김 여부.
6. 1단계 데이터 표의 요구와 코드가 다른 점 5(`docs/design/ui-sweep/04_data_fields.md` - 도감 4×7 vs 4×8 등).
