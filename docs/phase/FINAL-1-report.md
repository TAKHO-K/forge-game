## 0단계 — 서버 첫 순간 블록 몸

원인(확인): 메시 캐시(`ArtAssetLoader`)가 소품 → 나머지 전부(481개 · 약 50초) 순서로 받는데, 몬스터 · 보스 소환(서버 `MonsterSpawner`)만 "준비 완료" 신호를 안 기다리고 그 순간 캐시에 없으면 블록 리그로 지은 뒤 끝이었다. 무기 · 방어구 · 펫(클라)은 전체 완료(약 50초) 신호에 다시 지었다.

고친 것:

| 대상 | 전 | 후 |
|---|---|---|
| 로더 순서 | 소품 → 나머지(알파벳) | 소품 → **우선 묶음 무기 → 펫 → 보스 → 잡몹(84개 · 묶음마다 `Ready_weapons` 등 신호)** → 나머지(방어구 252 등) · `ArtImportData.priorityPrefixes` |
| 보스 소환 | 캐시에 없으면 블록 그대로 | 자기 메시를 최대 `bossMeshWaitSeconds` 12초 기다림(입장 연출 동안) → 넘으면 블록으로 뜨고 **준비 즉시 갈아입기**(이름표 · 빛 · 입자는 새 부위로 옮김 · 판정 사본 · 이름 · HP 그대로) · 클라 `BossAnimator`는 `MeshSwapped`가 바뀌면 다시 등록 |
| 잡몹 | 블록 그대로(죽을 때까지) | 같은 갈아입기 |
| 내 무기 | 전체 완료(약 45 ~ 50초)에 메시 | `Ready_weapons`(Studio 약 12초)에 메시 |
| 펫 | 전체 완료 | `Ready_pets` |
| 허브 NPC · 건물 | 전체 완료 뒤 | 소품 묶음 직후(props/만 씀 - Studio 5초) |
| 방어구 · 관문 장식 | 전체 완료 | 그대로(뒤 묶음 메시) |
