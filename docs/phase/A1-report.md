| 후보 | 수 |
|---|---|

| 몬스터 | 120 |

- **운영 상한 80**(`CartoonStyleData.outline.maxActive`) → 최악 슬롯 = 80 + 20 + 2 = **102(255의 40%)**. 넘치면 우선순위: 조준(0) → 보스(1) → 나(2) → 파티(3) → 상호작용(4 · 120) → 몬스터(5 · 90) → 다른 플레이어(6 · 90), 같은 순위는 가까운 순. 거리 밖 = 대상에서 떼고 다른 대상에 재사용 · 남는 것은 4개만 두고 삭제(슬롯 반환).
- **실측(`outline-pool-140`)**: 거리 안 후보 141 → Highlight 정확히 80(3초간 최대 80) · 조준 몹 = 노란 `#FFE65A` 외곽선 · 몹 안 Highlight 0.
- **Inverted Hull**: 파트로는 법선을 뒤집을 수 없어 **전용 메시(본체 복제 + 법선 반전) 업로드가 필요** - A1에서 시험 불가. 보스 1종(수호자 - A2-5)에서 메시 받으면 시험. 지형 · 먼 배경 = 외곽선 없음.

## 11. 번역 방침(18번 시트 기준 · 1쪽)

1. **문장 규칙(이미 COMMON §2 - 유지)**: 원문은 `TextData`에 키 하나 = 한 문장 전체 · 인자는 이름 · 숫자는 부르는 쪽. 여기에 시트 규칙을 더한다: 한 문장 40자 이하 · 한 문장 = 한 행동 · 관용구 · 말장난 금지 · 숫자 · 키는 문장 밖 칩(Q · −45%) · 색만 쓰지 말고 색 + 모양(●▲).
2. **자동 번역 위험**: 로블록스 자동 번역은 긴 문장 · 게임 용어에서 뜻이 바뀐다(예상 오역: 환생 → reincarnation · 태초 → the beginning · 토벌 → subjugation · 관문 → checkpoint · 강화 → reinforcement). 짧고 한 행동인 문장일수록 덜 틀린다 → 규칙 1이 1차 방어.
3. **용어집 고정**: 현지화 표(Localization Table)에 **수동 번역 항목을 넣은 문자열은 자동 번역보다 우선**한다. 게임 용어는 `TextData` 키로만 쓰고(문장 안에 직접 쓰지 않음 - 인자 `{grade}`로), 그 키들의 영문을 표에 고정한다. 제안값(18번 시트): 환생 Rebirth · 강화 Enhance · 태초 Primordial · 고대 Ancient · 유물 Relic · 전설 Legendary · 영웅 Heroic · 희귀 Rare · 토벌 Boss Hunt · 관문 Gate · 둥지 Nest · 각성 Awaken.
4. **흐름**: `TextData`(ko) → CSV 내보내기 → 영문 수동 입력(용어집 먼저) → 현지화 표 업로드(사용자) → 이름 라벨 · 숫자 칩은 `AutoLocalize = false`(로드맵 L 단계 계획과 같음).
5. **U1 · P4와의 순서**: 도움말 · 튜토리얼 문구를 줄인 뒤(P4) 번역(L). 이번 도움말 스틸 항목(`codex.stealLock.*`)은 이미 규칙 1 형식.
