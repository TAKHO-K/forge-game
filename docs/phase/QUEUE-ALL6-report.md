- 개발 계정 아바타 애니메이션 에셋 권한 오류(게임 코드 아님).
- 할로윈 대시 박쥐 · 남 시점 효과 · L 진입 배너 캡처 못 함(아래 사용자 확인).

## 12. 사용자 확인 목록

1. **L 진입 배너**: 세부 지역 경계를 걸어서 넘을 때 위 가운데 2초 배너(서버 순간이동이 클라에서 되돌려져 캡처 실패).
2. **할로윈 박쥐**: 테마 장착 후 대시 · 활강에 박쥐가 보이는지.
3. **남 시점**: 두 계정으로 로켓 · 풍선 · 화로 · 하이파이브(수락 → 짝) 보기.
4. **활강 거품(젤리)**: 거품이 작고 옅다 - 키울지(`B7_glide_jelly_bubbles.png`).
5. **D-3 고래 · 흙더미 연출** 체감.
6. **효과음 rocket_twinkle** 심사 통과 후 소리.
7. 장비창 3D 미리보기 체감(돌리기 · 크기) - 폰 장비 탭 실제 기기.
8. 판 털기 로켓 실제 아레나 장면(꼭대기 반짝 + 소리).
