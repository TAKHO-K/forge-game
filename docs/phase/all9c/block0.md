## 0-2 bignum 알려진 문제

`bignum_test.luau`의 `KNOWN` 표(라벨 이름 고정 · 사유 · 관련 결정). 라벨이 다른 X는 통과 수에 그대로 들어가 숨지 않는다. 고쳐져 O가 되면 "(알려진 문제 해결됨 - KNOWN 표에서 빼기)"로 찍힌다. run_all 표시 = `[BIG] 끝 44/44 · 알려진 문제 4`.

| 라벨 | 사유 | 관련 결정 |
|---|---|---|
| addGold 2^53 - 1 + 2 = 2^53 + 1 정확 | 2^53 넘는 정수는 double로 정확히 못 담음 | ALL9B 결정 필요 8 → ALL9C 0-11 · 0-12 |
| addGold 1.09e18 보유에 처치당 9.6e11 × 1,000회 정확 | ulp 128 · 누적 오차 27,000골드(상대 3e-11) | 같음 |
| trySpendGold 1.09e18 - 12,345 정확 | 작은 비용이 128 단위로 깎임 | 같음 |
| addGold 1e18 + 50 정확(작은 보상) | 64 미만 보상 사라짐 | 같음(0-11 목록) |
