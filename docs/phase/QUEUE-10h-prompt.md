1. 방어구 세트 = 갑옷·장갑·신발 3부위, 세트 계열 = 구역(그 구역 보스 드랍과 그 구역 일반 몹 드랍이 같은 계열). 세대 세트(C5)와 규칙 충돌 없게 통합. 세트 이름은 구역·종 이름 규칙과 일관되게.
2. 보스 출처 태그 필드(Loot.rollBossFirstClearDrop / RetryDrop, SAVE_VERSION↑, 옛 저장 마이그레이션 + 왕복 테스트). 보스 출처 비중 측정에 사용.
3. 토벌 입장 경로(RaidRules·BossGate.raidCheck 자리 채우기): 토벌 스테이지 = min(현재 선택 스테이지, 가장 최근 클리어한 보스 스테이지), 보스 스테이지(미클리어) 중엔 불가, 관문 등록 규칙 재사용.
4. 토벌 빛기둥·길 안내(기존 길 안내 재사용).
5. F2에서 끝난 것(보상 표시 불일치, 토벌표 정수화)은 확인만.
## ★Play B (BR2, 10분 이내): 저장 왕복(옛 저장 → 새 버전), 세트 3부위 효과, 토벌 입장·거부 조건, 보스 출처 태그 기록.

## Q6 — G3: 수련 · 직업 능력 · 퀘스트 · 메인 퀘스트
1. 공용 수련: 공격·체력·방어(골드, GoldCost 스테이지 연동 가격, 상한 = 최고 스테이지 연동, 합연산 버킷).
2. 직업 고유 능력: 직업마다 수치형 패시브 2~3개(골드), 직업 DPS 최저 대비 ≤ 1.32배 유지.
3. 일간 3~4개 + 주간 5개 퀘스트 + 일일 첫 접속 보상 + 일일 퀘 완료 상자. 보상 = 골드·강화석·알·반짝 조각·시즌 패스 경험치. ★기존 출석·의뢰판·시즌 미션 코드를 먼저 찾아 한 시스템으로 통합(§7-6).
4. 메인 퀘스트 = 마지막 환생까지: FTUE → 첫 보스 → 첫 강화·보석 → 둥지·알 → 환생 1(E) → 2(R) → 3(T·공중 점프) → 4 → 5(태초 무기). 환생마다 새로 열리는 것 하나씩 안내. 길 안내는 기존 방식 재사용(걷는 길 최단 경로 개편은 H1 뒤 — 이번엔 안 함).
5. 저장: 퀘스트·수련 진행 필드(SAVE_VERSION↑, 마이그레이션 + 왕복 테스트).
6. ★골드 예산표 EconSim: 구간별 골드 사용처 비율 목표 강화 ~45% / 수련 ~25% / 직업 능력·각성·계승·재련·옵션 리롤 ~20% / 상점·부화 ~10%. "다 하고 싶은데 골드가 모자라다" 상태인지. 새 성장원을 넣은 뒤 성장 예산(위 규칙) 재측정 → 벗어나면 수련 상한·가격으로만 맞춤.
## ★Play C (G3, 12분 이내): 저장 왕복, 수련 구매·상한, 직업 능력 1개씩, 일간 퀘 1개 완료·보상, 접속 보상, 메인 퀘스트 첫 3단계 진행.
