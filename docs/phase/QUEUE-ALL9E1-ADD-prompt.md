B. 홈(소켓) 규칙 구현 — 사용자 지정, 그대로
- 먼저 기존 소켓/보석 데이터 구조와 장비가 사라지는 모든 경로를 조사해 표로 기록: 판매 · 분해 · 자동 정리 · 강화/계승 재료 소모 · 기타.
B1. 계승: 계승하는 무기의 태초 홈 → 초월 홈으로 전부 전환. 박힌 보석은 그대로.
B2. 자동 반환: 장비가 사라지는 모든 경로에서 박힌 보석을 보석함으로 자동 반환.
  - 자리가 없으면 넘침 보관함(없으면 저장 필드 추가로 신설)으로 · 절대 소멸 금지.
  - 반환과 장비 제거는 한 번의 프로필 변경 안에서 처리(중간 실패 시 전부 되돌림).
  - 같은 요청 연타 · 중복 요청에도 보석 복제 0(작업 id로 멱등 처리).
  - 판매 확인 창에 "박힌 보석 N개는 보석함으로 돌아갑니다" 1줄(ko/en).
B3. 환생 0회 계승자: 초월 홈 1개 지급.
  - 계승 화면에서 어떤 홈을 초월 홈으로 할지 직접 선택 + 확인 창.
  - 홈이 하나도 없으면 새 홈 1개를 열어 초월 홈으로.
  - 선택은 서버 검증(클라이언트 값 신뢰 금지).
B4. 홈 등급 상승: 기능(넣을 수 있는 보석 등급 · 홈 효과)과 테두리 색만 바뀜 · 박힌 보석은 빠지지 않음.
B5. 보석 등급 상승(승급 등): 박힌 채로 등급만 오름 · 뺐다 넣기 없음 · 홈 효과는 즉시 다시 계산.
B6. 테두리 색 = 등급 8색(태초 #F7F5EF · 초월 #202127). 초월 #202127은 어두운 패널에서 안 보일 수 있음 → 1px 밝은 바깥 선 또는 약한 안쪽 광채로 대비 확보 · 실제 Play 캡처로 확인.
B7. 저장: 필드 추가만 · 필요하면 v70→v71 마이그레이션 · v70 저장 샘플이 그대로 읽히는지 하네스로 확인.
B8. 하네스(최소 14개):
  - 보석 3개 박힌 장비 판매 · 분해 · 자동 정리
  - 보석함 가득 찬 상태에서 판매(넘침 보관함 이동)
  - 판매 연타/중복 요청(복제 0)
  - 중간 실패 시 되돌림
  - 환생 계승(태초 홈 2개 → 초월 홈 2개, 보석 유지)
  - 환생 0회 계승(홈 0개 → 새 초월 홈 1개 · 홈 2개 중 두 번째 선택)
  - 잘못된 홈 선택 값 거부
  - 홈 등급 상승 뒤 보석 유지
  - 보석 등급 상승 박힌 채 반영
  - v70 저장 읽기
  - 자동 정리 필터가 보석 박힌 태초/초월 장비를 건드리지 않음(기존 규칙 유지)
  - 홈 효과가 서버 = UI 같은 값
- 실제 Play 캡처: 계승 화면 홈 선택 · 판매 확인 창 · 초월 테두리(폰 해상도 포함).

E. P3 EconSim 정밀 재실행 · 판정 표 (근사 모델 EconSimAll10 말고 실제 EconSim으로)
- 4프로필(캐주얼 · 일반 · 상위 1% · 운 나쁜 P90)별로 표 1장:
  - 중앙값 계승 스테이지 · 돌파 배수(#1, #3) · 마지막 구간 잉여율(#4) · 계승 뒤 잉여율과 보유 시간(#7)
  - 1,000 / 15,000 / 25,300 도달 시간(#5) · 2^53 도달 시간 ON/OFF(#10)
  - 강화 초기화 −4 경험 비율 · 방지 배수 k(항상 켬 경로 1.1~1.3배)
- 각 항목 옆에 A절 기준 통과/초과 표시. 기준 밖이면 값을 자동으로 바꾸지 말고 후보 2~3개와 예상 효과만 보고(단, 이미 정해진 범위 안의 k 재탐색은 진행).
- #4는 "천장 도달 시 예상 보유 골드(프로필별)"도 기록 — 천장 확장 업데이트 첫 진입 비용 설계용.

F. 전갈 여왕 외형 개선 (ALL9E1 장비 v3 뒤)
- 목표: 9세가 무서워하지 않는 카툰 인상 + "맛있어 보이는" 큰 집게.
- 얼굴/몸: 둥근 몸통 · 크고 반짝이는 눈(흰자 + 하이라이트) · 살짝 웃는 입 또는 볼 · 날카로운 이빨/가시 금지 · 짧고 통통한 다리 · 꼬리 끝 독침 = 둥근 전구 모양(기존 "진짜 꼬리 빛남" 기믹과 연결).
- 앞 집게(촉지): 몸 대비 크게 하되 길이가 아니라 굵기로 키움 · 킹크랩 다리 질감(굵은 마디 · 둥근 작은 돌기 · 익은 게 주황 껍데기 + 마디 사이 크림색 속살 하이라이트 · 광택). 빨간 발광 금지(보스 경고색과 혼동).
- 색: 몸통은 기존 사막 계열 유지 · 집게 주황이 바닥 전조(빨강)와 구분되는지 실제 Play 캡처로 확인.
- 판정 불변: 모든 공격의 판정 범위 · 피해 · 쿨 그대로. 판정/모션 비(무기 · 집게 · 꼬리 끝 최대 도달 거리 ÷ 판정 반경) 0.9~1.1을 공격별 표로 보고 · 벗어나면 모션을 맞춤(판정은 건드리지 않음).
- 기믹 읽힘 유지: 모래 둔덕 · 꼬리 끝 빛남 · 섞기 · 돌진 시 파트 뜸 없음(전 동작 검사).
- 성능: 폰 기준 파트/메시 수 · 텍스처 예산 안 · 1/4/16인 프레임 기존 기준 유지.
- 보고: 전/후 비교 캡처(정면 · 3/4 · 공격 순간 · 섞기 기믹) + 판정/모션 표 + 성능 수치. 썸네일에는 쓰지 않음(썸네일 보스 = 폭풍 군주 확정).
