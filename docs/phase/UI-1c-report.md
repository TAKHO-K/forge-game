## 2. 최소 글자 크기 (재개 2)

- 대상 = 기준 화면(1920 × 1080 · 폰 800 × 360)을 UIScale로 줄이는 창: 명예의 전당 · 도감 v3 · 보스 관문 · 출석. 가방은 UIScale 없이 배치를 바꾸는 창이라 해당 없음.
- 규칙(`UiModel.textFloorPx` · `UiV9.textFloor`): 화면에 보이는 글자(TextSize × 창 배율)가 최소보다 작으면 TextSize를 키움 — PC 본문급 18 · 작은 글자 15 / 폰 14 · 12. RichText 안의 `<font size>`도 같이. 칸을 넘치면 ① 높이가 되면 2줄 ② 그래도 넘치면 원래 크기 쪽으로 1씩(말줄임 대신). 자동 폭 글자는 가장 가까운 고정 폭 칸 기준. 제목이 커지면 옆 글자를 다시 배치(도감 부제 · 명예의 전당 기준 상자 — 처음엔 한 번만 계산해 겹쳤음).
- 실측(창 배율을 1366×768 값 0.711로 바꿔 잼):

| 창 | 15 미만 글자(전) | 15 미만 글자(후) | 화면 최소 |
|---|---|---|---|
| 도감 v3 무기 탭 | 70 / 76 | 0 | 15.6 |
| 명예의 전당 | 13 / 21 | 0 | 15.6 |

- Studio 창(0.548 · 1366×768보다 작음)에서는 칸 높이 때문에 도감 일부(58 / 131)가 12.6 ~ 15로 남음 — 그 크기 화면은 지원 기준 밖. 출석 시즌판 "시즌 출석 개근"(좁은 칸 1개)은 원래 크기 유지.
- 하네스 `ui_v2` +3(1366×768 · 폰 0.9 · 1.3 설정에서 최소 보장 · 원래보다 작아지지 않음).

## 3. 장비 상세 고정 창 + 보석 2단 (5단계)

- 방식: 가방의 기존 상세 판(이름 · 그림 · 옵션 · 안내 · 잠금 · 버튼 [장착] [분해] [판매] [계승] [각성] [리롤] [나란히 비교] 전부)을 창 밖으로 옮겨 **누른 칸 옆에 고정**. 새로 그리지 않아 기능 손실 0. 데이터 = `UiLayoutData.bag.pin`.
- 모양: 하늘 테 3 · 머리 "고정됨 · 바깥 누르면 닫힘" + [닫기] · 칸 ↔ 창 하늘 선(PC) · 상세 무기 그림 = 가방 칸 · 도감과 같은 원본 32장.
- 동작(Play 확인): 열기 · 같은 칸 다시 = 닫힘 · 다른 칸 = 그 칸으로 바뀜 · 바깥 = 닫힘(선택 테도 지움) · [닫기] · 착용 칸(갑옷 · 무기) 같은 상세 · 가방 닫으면 같이 닫힘 · 마우스 올림 설명은 고정 중 꺼짐.
- 보석 2단(무기 상세): 홈 누름 = 보석 창(자홍 테 · 고른 홈 흰 고리 + 자홍 점선 · 효과 · 홈 줄) · 같은 홈 다시 / [×] = 보석 창만 · 바깥 = 둘 다 · 빈 홈 = 보석 탭 그 홈 · 잠긴 홈 = "곧 열려요". [보석 홈] 버튼 = 보석 탭.
- PC 오른쪽 고정 판 자리 비움 → 가방 열 7 → 최대 11. 폰 = 상세 430 + 보석 창 나란히(ph_05).
- Play에서 찾아 고친 것 4: ① 칸 누름이 바깥 판정보다 먼저 처리돼 바로 닫힘 → 누르기 시작 때 기준 ② 가방을 닫아도 고정 창이 남음(창만 숨고 ScreenGui는 켜짐) ③ 폰에서 고정 창을 눌렀는데 뒤 갑옷 칸이 눌림(Frame이 입력을 안 막음) ④ 영어에서 보석 등급 알약이 한국어.

## 5. 못 넣은 것 · 결정 필요

1. **[강화] 버튼(장비 상세)**: 강화는 강화대 근처에서만 열리는 구조라 상세에서 여는 통로가 없음 → 안 넣음(넣으려면 "어디서나 강화" 여부 결정 필요).
2. **보석 [빼기]**: 서버에 해제가 없음(항상 교체 · 원래 보석은 보석 칸으로) → 버튼은 흐린 글자 + 누르면 이유 한 줄. 빼기를 만들지는 **결정 필요**(경제 영향 없음 · 서버 요청 하나).
3. 상세 안 세부 모양(목업과 다른 점): 그림 120(지금 44 그대로) · "아이템 레벨" 줄 · 세트 판 따로(지금 = 안내 글 안) · 홈 아래 "태초까지" 글자 · 보석 "얻은 곳" 줄(보석 데이터에 없음).
4. 좁은 화면(Studio 1052)에서는 고정 창이 누른 칸을 일부 가릴 수 있음(양쪽 모두 자리가 없을 때) — 1366 이상에서는 옆에 들어감.
5. UI-1b에서 넘어온 큰 틀(구역 선택 · 알/펫 창 · 캐릭터 꾸미기 미리보기 새로 짓기)은 이번에도 못 함.
6. 1920×1080 · 1366×768 실제 창 · 실제 폰은 Studio에서 확인 못 함(2절 배율 측정으로 대신).
