## 가정 · 결정 로그
- 크기 배율 구현 = 빌드 때 배율(sizeScale × bodyScale)로 짓기. `Model:ScaleTo`는 시범 보스에서 실제로 시험해 결과만 보고(애니메이터가 루트 크기에서 S를 읽고 서버 잡기 FK가 데이터 S를 써서, 짓고 난 뒤 ScaleTo하면 두 곳이 어긋난다 - 시험으로 확인).
- 몸 피격 판정 = `BodyRadius` Attribute에 **배율로 커진 몸 반폭 증가분만** 넣는다(배율 1이면 0 = 지금과 같음).

- 파트 상한 해제(추가 지시 ③): 옛 상한 40 · 전갈 48 → 새 상한 = 성능 예산 안(폰 30fps 이상)에서 두 발 보스 ≈ 100 · 전갈 ≈ 130(측정으로 확정). 추가 = ① 움직일 곳은 새 관절(망토 · 꼬리 · 날개 · 턱 · 가슴 …) ② 디테일은 부모 부위에 붙인 장식 파트(`rig.deco` - 관절 없음 = 모션 비용 0). Blender make_boss.py 상한도 같이.
- ArtStyleV1: Studio 기본 켬(RS `ArtStyleV1Force = false`면 끔) · 라이브 = `ArtStyleV1Data.enabled`(false) 그대로.
