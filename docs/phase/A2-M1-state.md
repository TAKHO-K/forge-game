## 가정 · 결정 로그
- 크기 배율 구현 = 빌드 때 배율(sizeScale × bodyScale)로 짓기. `Model:ScaleTo`는 시범 보스에서 실제로 시험해 결과만 보고(애니메이터가 루트 크기에서 S를 읽고 서버 잡기 FK가 데이터 S를 써서, 짓고 난 뒤 ScaleTo하면 두 곳이 어긋난다 - 시험으로 확인).
- 몸 피격 판정 = `BodyRadius` Attribute에 **배율로 커진 몸 반폭 증가분만** 넣는다(배율 1이면 0 = 지금과 같음).
