━━━━━━━━ 블록 0. 긴급 수정 + 결정 반영 (≤ 3시간) ━━━━━━━━
0-1 결제 이중 지급(AUDIT1 즉시-1 · 최우선)
- 원인 재확인 후 수정 원칙: 영수증 처리는 "같은 PurchaseId는 한 번만 지급"이 저장 수준에서 보장되어야 한다.
  - 지급 내용과 PurchaseId 기록을 같은 저장 갱신(원자적)으로 묶는다. 저장이 실패하면 메모리 상태도 지급 전으로 되돌리고 NotProcessedYet을 돌려준다(로블록스가 다시 호출).
  - 다시 호출되면 PurchaseId가 이미 기록돼 있으면 지급 없이 PurchaseGranted만 돌려준다.
  - 상품 지급 + 토큰 지급처럼 여러 개를 주는 상품도 전부 한 묶음(부분 지급 금지).
- 하네스: 저장 실패 주입(1회 · 2회 · 재접속 사이) × 상품 종류(치장 · 토큰 포함 묶음 · 게임패스 · 시즌 패스 · 칸 건너뛰기 · 스타터) → 최종 지급 정확히 1회. 다른 서버 재접속 시나리오 포함.
- 리뷰어 서브에이전트 검토 + 보고서에 "결제 경로 전수 표"(상품 종류 · 지급 함수 · 멱등 보장 방법).

0-2 보스 첫 클리어 직업 변경 악용(AUDIT1 즉시-2)
- 보스 아레나 입장 순간의 직업을 그 전투의 보상 기준으로 고정(입장 기록).
- 보스전 중(입장 ~ 퇴장) 직업 변경 요청은 서버가 거절 + 안내 문구("보스전 중에는 직업을 바꿀 수 없습니다.").
- 첫 클리어 판정 = 입장 시 직업 기준. 하네스: 전투 중 변경 시도 · 막타 직전 변경 · 파티원 변경 · 재접속.

0-3 AUDIT1 높음 등급 나머지 1건 수정(즉시 2건과 같은 결함이 아닌 것) + 같은 원인으로 생기는 중간 등급이 있으면 함께. 수정 목록을 보고서에.

0-4 가방 상한(결정 3): 마일스톤 +5는 상한 밖 → 최대 80(기본 35 + 가방 패스 20 + 스타터 20 + 마일스톤 5). 유료로 산 칸이 잘리는 경우 0(하네스). 옛 저장에서 잘려 있던 사람이 있으면 다음 접속 때 복구.

0-5 자동 정리 첫 안내 기본 선택 = 희귀 이하(결정 5 · 사용자가 바꿀 수 있음). 태초 · 초월 제외 규칙 그대로.

0-6 주황 버튼 글자 대비(결정 6): 버튼 부품 한 곳에서 일괄 수정 → 게임 전체 버튼 대비 4.5:1 이상 · 자동 대비 검사에 버튼 전체 추가 · 대표 화면 캡처.

━━━━━━━━ 블록 2. ALL10-P2 기능 ━━━━━━━━
2-1 계승(D1 · D2)
- 조건: 태초 무기 +30 · 같은 직업. 결과: 같은 직업 초월 무기 +0으로 변환(무기 1개 유지) · +30 강화 이펙트는 외형으로 계속 선택 가능.
- 서버 원자 처리 · RequestGate · AuditTrail · 중복 계승 방지 · 실패 시 롤백. 확인 창 2단계(무엇이 바뀌는지 · 되돌릴 수 없음).
- 알림: 같은 서버 알림 + 칭호 "초월 계승자". 세계 번호 · 전 서버 알림 · 명예의 전당은 드랍 초월만(계승은 제외).
- 계승 보상: 초월 보석 1개(D16 보존 규칙).
2-2 초월 강화 0~20(D7 + 결정 4)
- 확정 성공 · 골드만 · 하락/초기화 없음. 무기가 초월이면 강화 창이 초월 강화 모드로.
- 분할 납입(결정 4): 한 단계 비용을 10칸으로 나눠 조금씩 낼 수 있게(낸 만큼 저장 · 10칸 다 차면 단계 상승). 진행 막대 표시.
- 공격력 상승률 = 제안서 표(공격력 1%당 골드 ∝ 그 구간 시간당 수입).
2-3 고급 수련 51~100 + 방어 수련(D5 · D6)
- 초월 무기 보유 시에만 해금(★사용자 규칙 · 스테이지만으로 열지 말 것). 같은 수련 창 · 51부터 이름 "고급 수련" · 증가율 다름.
- 결정 4 보완: 고급 수련 초반 단계(51~60) 비용을 완만하게 → 계승 직후 골드가 바로 쓰이게.
- 방어 수련 = 고급 수련 안 항목 · 개방 스테이지는 제안서 값 · 피해 공식은 서버 · UI 한 함수.
2-4 초월 보석(D9 · D16)
- 계승 뒤에만 해금(반드시). 계승 보상 1개 · 이후 고스테이지 보스 희귀 드랍(제안서 드랍률) · 태초 보석보다 강함.
- 보존: 추출 100% · 무료 · 재장착 무제한 · 판매/분해 불가 · 기본 잠금 · 계정 귀속 · 장비 판매/분해 시 박힌 초월 보석 자동 반환(가방 가득이면 우편함) · 지급 감사 기록.
2-5 수련 1~50 · 직업 특성 진화 확대(D4) — 제안서 숫자 적용. ★결정 2(강화 회복 보조)는 사용자 답 대기 → 구현하지 말고, 운 나쁜 P90의 태초 +30 도달 시간 ÷ 중앙값 배수만 측정해 보고.
2-6 몹 곡선(D3 · D11): MonsterStats 공용 함수에 기준 빌드 표 + 돌파 계수(2.4배 · 계승 직후 1,500 스테이지) 연결 · 서버 · 몹 정보 UI · EconSim 모두 같은 함수. 스위치 끄면 지금 곡선.
2-7 UI: 계승 창 · 초월 강화 모드 · 분할 납입 막대 · 고급 수련 이름/잠금 안내("초월 무기를 얻으면 열립니다") · 초월 보석 칸 · 몹 정보 줄. 문구 ko/en · 합쇼체.
