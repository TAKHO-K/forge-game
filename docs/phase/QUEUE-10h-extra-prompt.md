## Q8 — K3 영혼 상태 (추천안으로 진행, 결정 필요에 기록)
1. 범위: 보스전(아레나·토벌)에서만 영혼 상태. 일반 스테이지는 현행 즉시 리스폰 유지(편하게).
2. 영혼 = 반투명, 이동·관전 가능, 공격·피격·아이템 줍기 불가, 기믹 대상에서 제외(대공 잡기·끌림·표적 선택 포함).
3. 부활 경로: 생명의 성역 종료 시 1회 부활(성역 안 사망자) / 구원의 기도 부활(K2 자리 → 완성) / 보스전 종료 시 전원 복귀. 부활 HP 비율은 데이터(추천 30%).
4. 전멸 = 파티 전원이 영혼 → 실패 처리(기존 실패 흐름 재사용).
5. 튕김(연결 끊김): 재접속 시 같은 보스전이 진행 중이면 영혼으로 관전 복귀, 클리어 시 보상 자격 유지(기여 규칙은 기존 것 재사용).
6. 보상: 클리어 시 영혼 상태 파티원도 보상 유지. 리더보드 시간 = 클리어 시각 기준(영혼 수 무관), 이론 최소 시간 재계산 영향 기록.
7. 서버 권한 판정, 위조 요청 거부 테스트 1개.

## Q9 — K4 직업옵션 (스킬 변형)

## Q10 — K5 재조정
- 직업 DPS 최저 대비 ≤ 1.32배(K3·K4·G3 직업 능력 포함 재측정).
- 대검 관통돌진 이동 18 < 대시 22 → 돌진이 대시보다 짧지 않게 상향.
- 치유사 파티 버프 17.36% 재계산(전장의 포효 +10%와 겹칠 때 포함), 치유사 스킬 = a×공격력 + b×최대체력(힘 비율 데이터), 힐러 딜링모드 쉴드 수치(S13b) 재확인.
- 스킬 가속 옵션: 쿨 = 기본 × 100/(100+가속), 궁극기 제외 → 별도 "궁극기 충전 속도" 옵션.
- 궁극기·R 반영 리더보드 이론 최소 시간 재계산. EconSim 성장 예산 확인.
- 구간 수호자 2회차 HP ×1.3: 적용하지 말고 ×1.0 / ×1.15 / ×1.3 비교표만(클리어 시간·실패율 추정) → 결정 필요.

## Q11 — 펫 최소판 (비전투 동행, 나중에 탑승)
- 부화장 NPC 자리(커뮤니티센터, 외형은 자리만), 알 = 구역 색 6 × 등급 3(보통·좋은·희귀), 알 하나 = 2종 후보 50:50, 등급 확률 공개(단일 소스).
- 부화 레벨: 부화 누적 횟수로 레벨업 → 상위 등급 확률↑, 레벨별 확률표 공개.
- 알 = 무료 획득만(둥지·나무 꼭대기 하루 1회·출석·퀘스트). 유료 랜덤 없음.
- 둥지: 개인 둥지(뺏기 없음), 재생성 타이머 개인별, 기존 둥지 코드 재사용(§7-6).
- 펫: 크기 = 캐릭터 머리, 강아지·고양이·새끼 용(날아다님). 전투 능력 없음. 따라다니기(클라 보간, 서버 비용 최소).
- 레벨 해금 자리: 자동 줍기 200(서버 권한, 칸 확인 + 바닥 제거 한 번에, 한 아이템 한 소유자 잠금, 꽉 차면 바닥에 둠 — 복사 방지) / 부화 대기열 +1 300 / 둥지 약한 힌트 400 / 보관함·합성 추천 500. 이번엔 자동 줍기까지 구현, 나머지는 데이터 자리.
- 외형: 몬스터와 같은 도형 몸체 + 리깅 규칙(파트 ≤ 8), 아트팀 자료는 docs/art/ref에 기존 파일명·형식 규칙으로(동작: idle·따라가기·날기(용)·기쁨).
- 저장: SAVE_VERSION↑ + 마이그레이션 + 왕복 테스트.
