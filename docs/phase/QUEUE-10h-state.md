## 리뷰 5(Q8 ~ Q10) 반영
- 중요 1: 살아 있는 사람이 빠져 남은 멤버가 전부 영혼 → 보스전 멈춤 → `leaveFor`에서 생존 0이면 전멸 흐름
- 중요 2: 잔류(처치 뒤) 창 사망이 영혼이 됨 → onDied 무시 · [다시 도전] 전 영혼 풀기
- 중요 3: 전멸 리셋 전 기여가 재접속으로 되살아남 → carried에 리셋 세대(resetGen) · 사라진 보스 키 정리(기록 7)
- 중요 4: 성역 끝 부활이 리스폰 대기(5초)를 못 봄 · 다른 보스전 영혼까지 → pending 부활 예약 · 시전자 보스전만 · `UltimateData.reviveOnEnd = true`를 코드가 읽음
- 중요 5: 영혼이 잡힌 동료 구출 가능 → BossTrap.canHold에서 거부
- 중요 6: 변형 풀에 순수 이득 · 손해 · 무효 → "멀리"(범위 · 쿨) 추가 · 두 번째 축 없는 칸 비움(k5-rebalance §8)
- 기록 10: 리롤 = 변형 직업 풀 · 풀 없으면 골드 전에 거부
- 결정 필요로: 기록 8(영혼 전 설치물 기여) · 9(영혼도 인원수 - 모래 더미 · 오르골) · 11(`debugEquipment` 이름)
