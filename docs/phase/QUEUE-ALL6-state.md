## 가정 · 결정 로그
- A1: 저장 필드 `peakLevel`(v38 · 환생해도 안 내려감)이 이미 있어 재사용 → SAVE 변경 없음. 펫 창 '최고 Lv.{level}에 열림'.
- A2: 기존 "가벼움"은 실제로 먼 산만 껐다(설명 문구와 달랐음) → 풀 덤불(GrassTuftView) · 나무 바람(TreeWind)도 같은 실효값으로 끔. 기기 판별값은 저장하지 않음(auto) - 같은 계정이 PC로 오면 보통. 저사양 판별 = 로블록스 품질을 1 ~ 3으로 직접 낮춘 기기(로블록스가 기기 사양 API를 주지 않음).
- A4: 데이터 원문(한국어)을 키로 하는 이름 사전 + Text.get 인자 자동 번역(데이터 파일 무변경). 서버가 한국어로 완성해 보내는 문장(도감 줄 완성 토스트 · 월드 명판 · 몹 이름표 합성 이름)은 범위 밖(보고).
- D: EconSim은 퀘스트 · 도감 골드를 모형에 넣지 않아 결과가 글자까지 같다. 보상 하나의 반올림 폭은 1,000 ~ 2,500 구간에서 최대 약 ±25%(예 1,612 → 2,000 · 2,474 → 2,000).
