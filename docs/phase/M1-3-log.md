## 가정 · 결정 로그

- **Terrain × Rojo**: 프로젝트 `Workspace`는 `$ignoreUnknownInstances` - Rojo는 Terrain 복셀을 동기화하지 않는다(파일 형식에 Terrain 복셀이 없다 · 실측: Studio Terrain 셀 0). → 생성기 = git 코드(고정 시드 · 결정적), 굽기 = Studio edit 모드에서 `require(ServerScriptService.TerrainBake).build("tier1")`(MCP execute_luau - git 코드 실행만, 인스턴스 손편집 아님) 또는 Play 중 `/gg terrain build <구역>`(미리보기 - Play가 끝나면 사라진다). 굽고 나면 **place 저장**이 필요하다(사용자 - Studio 파일 저장/게시).
- edit 모드 `execute_luau`의 `require`는 된다(실측 `WorldMapData.worldRadiusStuds` = 3000).
- **사용자 추가 지시(작업 중)**: 현실 같은 높낮이 · 물리가 구현되기 편한 구조(세부 디자인 아님) · 웅장함 · 몰입 / 맵 외곽 진입 불가 구역 = 실제 지형과 어우러지게 / **비밀 둥지 먼저 → 그 위에 지형**(못 들어가거나 끼임 0) / 구역마다 랜드마크 1개 이상.
- **구조 원칙**: 큰 모양(언덕 · 능선 · 산 · 계곡 · 물 · 동굴) = Terrain 높이 함수 + 깎기/메우기 부피 / 정밀하게 밟는 곳(둥지 오르기 · 점프맵 · 다리 · 신전) = 파트(이동 기준표가 정확히 맞는다). 둥지 · 구조물 · 길 · 캠프 · 관문이 **지형의 입력**(평탄 · 비움 마스크) - 생성기가 그 자리를 먼저 비우고 그 둘레에 지형을 쌓는다.
- 지형 형상: 구역 원 가장자리 = 능선(테두리 언덕 - 이웃 원이 맞닿는 r 1,472에서 두 테두리가 합쳐져 경계 능선) · 꽃잎 사이 = 골짜기(허브 → 바깥 고리 봉인 입구로 이어진다) · r 2,600 밖 = 외곽 설산(높이 240 ~ 400 · 170 위 눈 · 투명 벽 2,960은 산 속에 묻힌다 · 산은 3,200까지 이어져 끝이 안 보인다).
- 평지 높이 = 바닥 윗면(1) 조금 아래(값은 굽기 실측으로 맞춤) - 도로 · 캠프 · 관문 판이 지형 위에 얹힌다. 옛 바닥 타일 · 구역 색 원판 · 스폰 범위 원판/고리는 지형이 대신한다(삭제).
- **사용자 보강(작업 중)**: ① 비밀 둥지 · 동굴 · 통로 = "보호 부피"로 먼저 정의 → 지형 굽기 → 보호 부피 다시 비우기(Air) → 굽기 뒤 **캐릭터 캡슐로 입구 → 둥지 통과 검사**(복셀 · 매끄럽게 처리로 좁은 틈이 막힐 수 있다 - 통로 폭 여유 ≥ 8) ② 외곽 산맥 · 절벽 · 바다 = 보이는 경계 · 실제 차단 = **서버 경계 밀어내기 백업 필수**(공중 점프 연속 경사 오르기 시험 포함 · MaxSlopeAngle 현재 값 확인 · 보고) ③ standMaxY 160이 200+ 봉우리 · 높은 둥지와 충돌하면 조정안 보고.
- 보호 부피 구현: 생성기 밀도 함수에서 보호 부피 안 = 공기(1차) + 굽기 끝에 보호 부피를 `FillBlock/FillBall(Air)`로 한 번 더(2차 - 매끄럽게 처리 · 이웃 복셀 번짐 대비) + 부피 표면에서 **여유 4(= 폭 8)** 더 깎는다.
- 서버 경계 백업: 각도마다 "걸어 들어갈 수 있는 반경"(기본 2,600 · 봉인 입구 골짜기 · 바다 만 안은 더 넓게)을 넘어 서 있으면 안쪽으로 밀어낸다(`Travel` 잠긴 구역 밀어내기와 같은 모양). 투명 벽 2,960 · 세계 밖 복귀 · 높은 곳 복귀는 그대로.
- 높은 곳 착지 복귀(`standMaxY` 160) 유지: 설계한 올라갈 수 있는 곳은 전부 150 이하 · 봉우리(200+)는 경치 - 기어오르면 기존 규칙대로 허브.
- edit 모드 require 캐시: Studio를 닫을 때까지 옛 모듈이 돈다 → 굽기는 `require(game.ServerScriptService.TerrainBakeRun)("tier1")`(소스를 매번 새로 불러온다 · loadstring).
- 표면 식(실측): 표면 = 가장 위 칸 바닥 + 2 + 4 × 점유율 → 점유율 = (h − 2 − 칸 바닥) / 4. 평지 목표 0.6 → 실측 0.594.
- 둥지 받침 = 자연 높이(굽기 전 식) 기준 · 가장자리 34(원형 분화구 방지). 외곽 = 봉우리 줄(5°마다 · 170 ~ 400) + 능선 결 · 끝 뒤 채움도 결(평평한 띠 방지).
- 물속 대시 = 불가(결정: 물살을 대시로 무력화하지 않게 · 대시 도착점이 물을 구분 못 함) · 물속 공중 점프 충전 = 안 찬다(물 밖 착지만).
- C-마을 · C-필드 재생성 = B와 같게 2 ~ 4시간(지시에 없음). 허브 알 구역 = 굴뚝 T1 · 다락 T2 · 줄기 T3 · 아치 T4.
- [알] 버튼 = 설정 버튼 왼쪽 옆(자식 - 칩 스택 높이 그대로: 폰 302에서 넘치지 않게).
- 옛 M1-3(가) 저장 기대값(= 40) → "최신까지 이관"(v41).
