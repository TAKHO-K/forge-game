## ③ 중력 반전 시범 → 대체

`ControllerManager`(UpDirection 아래) + 거꾸로 중력 격리 시범(수동 Play 1회): 지면 센서가 천장을 못 잡아 활성 컨트롤러 없음 · 떠오른 캐릭터를 **서버 높이 검증이 1.3 · 3.0초에 바닥으로 되돌림** · 모든 바닥 판정(발 = 루트 − 엉덩이 높이 · 층 8)이 "아래 = −Y" 전제 · 폰 조이스틱 · 카메라 뒤집힘. → **대체 = 수정 공중 정원**(설계 §9-1). 발판은 `Workspace.Ground`에 두어 서버 지면 탐지 · 높이 검증이 그대로 받는다(점프대 높이 19 < 허용 22.38).

## ⑦ 결정 필요

1. **근접 솔로 전멸 74 ~ 98%**: 평타(피할 수 없음) 노출 가정 탓. 근접 받는 평타 ×0.5 추가 감소 / 근접 전용 흡혈 · 막기 / 그대로(근접은 파티 권장) 중 선택.
2. **서리 거인 전멸 57%**(상한 50 약간 위): 포효 실패 85% → 75%로 낮출지.
3. **파티 배율**: 2인 전멸 1 ~ 18% · 4인 0 ~ 2%로 너무 쉬움 - 보스 HP 인원 배율 p 상향 여부.
4. 모형 가정(적중률 · 학습 배율 0.4 · 정원 성공률)은 추정 - 실제 플레이 체감 확인 필요.
5. 다음 세션 첫 Play: BR1(나) 눈덩이 대기 시간 수정 후 재확인 + 보스별 새 패턴 스크린샷 · 사슬 4인 실제 화면(다중 클라 불가 → 스탠드인).
