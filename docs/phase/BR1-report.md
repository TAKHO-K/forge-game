## ② 대공 잡기(공통 규칙 - 설계 §2)

| 항목 | 값 |
|---|---|
| 발동 | 누군가 연속 체공 ≥ 0.6초 · 쿨 16 · 첫 20초 |
| 전조 | 2.5초 · 보스 위 큰 손바닥(전역) + 0.6초 넘게 뜬 사람 머리 위 작은 손바닥(찬다 · 내 것 = "착지!") |
| 대상 | 판정 순간 연속 체공 **≥ 1.2초**(1단 + 공중 1 = 1.04초 안전 · 공중 2회 1.54 · 공중 + 대시 1.46 걸림) · 무적 · 복귀 보호 · 이미 잡힘 제외 |
| 잡힘 | 보스 곁 공중(발 +7)에 3초 → 무작위 방향 던짐(높이 7.5 · 거리 30 - 기존 넉백 상한 · 맵 밖이면 기존 복귀) + **현재 체력 50%** |
| 피해 규칙(결정) | 방어 무시 · 받는 피해 감소(신규 보호 · 레벨차 · 버프 · 무적) 적용 · 쉴드 적용 · 잡힌 채로 넣는다(풀린 뒤에는 해제 유예 무적이 막는다) |
| 해제 | 동료가 손 3타(구출자당 0.5초에 1) 또는 곁 16에서 F 홀드 1.5초 → 풀림 + 보스 기절 3.5초 |
| 발버둥 | 점프 누를 때마다 −0.25초(초당 6회 인정 · 서버가 자른다) · 잡힌 뒤 0.8초 전에는 안 풀린다 · 폰 = 기본 점프 버튼(잡힘은 루트 고정만이라 버튼이 남는다) |
| 도발 연결 | `BossPatterns.onTaunt` → 즉시 풀림 + 기절(성기사는 K) |

## ③ 중력 반전 시범 → 대체

`ControllerManager`(UpDirection 아래) + 거꾸로 중력 격리 시범(수동 Play 1회): 지면 센서가 천장을 못 잡아 활성 컨트롤러 없음 · 떠오른 캐릭터를 **서버 높이 검증이 1.3 · 3.0초에 바닥으로 되돌림** · 모든 바닥 판정(발 = 루트 − 엉덩이 높이 · 층 8)이 "아래 = −Y" 전제 · 폰 조이스틱 · 카메라 뒤집힘. → **대체 = 수정 공중 정원**(설계 §9-1). 발판은 `Workspace.Ground`에 두어 서버 지면 탐지 · 높이 검증이 그대로 받는다(점프대 높이 19 < 허용 22.38).
