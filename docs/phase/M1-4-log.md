## 사용자 추가 지시(작업 중)

- 심해 군주 · 폭풍 군주 신전 = 걸어서 가는 적절한 자리 · 컨셉 = **보스 관문 해금 장소**(자세한 묘사 X · 보스맵 느낌 + 색 조합 · 날씨 영향 고려). 폭풍 군주 = 번개가 칠 것 같은 폭풍우 첨탑. 꾸미기는 성의만 - **문(관문)은 열심히 디자인**.
- 보강: 관문 문 = **공통 틀**(구조 · F 상호작용 · 등록 전/후 표현) + **보스별 장식 모듈**(신규 보스 재사용 · 카툰 교체 대비). 날씨 = 관문 주변 로컬 · 클라 전용 · 입자 수 상한. 폭풍 섬광 = 보스 낙뢰 · 피뢰침 경고와 **다른 모양 · 색**, 밝기 낮게 · 빈도 드물게(광과민 배려). 심해 신전 = **둑길 · 다리로 걸어서** 연결.
