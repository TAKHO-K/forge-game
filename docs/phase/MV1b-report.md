## 0-3 원거리 공중 정지 = 대공 잡기 체공(MV1 결정 9)

- 전: 대공 잡기 체공 = 서버가 본 Humanoid 상태(Jumping · Freefall)만. 정지는 클라 `LinearVelocity`라 상태가 Freefall로 남을 가능성이 높지만 서버가 직접 확인하는 값이 아니었다(클라 Attribute `MV1Hovering`은 복제 안 됨).
- 후: 서버가 **공중 공격을 받아들인 순간** 그 직업의 `AttackMotionData.air.hoverSeconds`만큼 체공 세션에 `hoverUntil`을 적는다(`AttackServer`) → `AirState.isHovering` → `BossHandlersBR1.trackAir`가 체공으로 센다. 클라가 보낸 값은 안 쓴다(서버가 받아들인 공격 · 데이터 길이만).
- 검증 MV1(가) 새 항목: 클라 상태 = 지상인 스탠드인도 정지 중 체공 셈 · 0.2초 뒤 0.20초 · 정지 끝나면 멈춤 O.
