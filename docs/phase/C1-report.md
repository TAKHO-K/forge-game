- **기준이 내려갈 때 이득 보는 사람이 없는 이유(한 줄)**: 떠난 높은 참여자는 자기 스테이지 > 기준이 되어 자격을 잃고(높은 기준에서 쌓은 기여를 낮은 HP로 바꿔 먹는 길 차단), 남은 사람은 "같은 스테이지 동료가 그만큼 깎아 준" 정상 파티와 같은 상황이다.
- **맞는 중 스테이지를 바꿔 몹을 초기화해 위기를 피하는 경우 = 허용(추천대로)**: 초기화되는 건 혼자 참여한 몹뿐이고 자기 기여 · 첫 타격이 전부 사라져 처치 보상 측면 이득이 없다(시뮬 d = −53%). 몹의 어그로는 그대로 남아(AI 추적은 초기화하지 않음) 다음 틱에 새 스테이지로 다시 참여한다.
- 무리 스폰(M1-4) 몹도 같은 `MonsterState` 경로라 같은 규칙. 보스(진행 보스 아레나)는 스테이지가 고정된 개인 · 파티 인스턴스라 기준 규칙 대상이 아니다(토벌 = 4번 규칙).
