## 10. 사용자가 Play에서 꼭 볼 곳

1. 마을 시작 2초 뒤 → 출석 창 1개(시즌판 32칸 한 화면 · [오늘 모두 받기]) → 닫으면 1초 뒤 선물함(있을 때).
2. 강화대로 걸어가기 → 아래 가운데 강화대 창(불씨 칸 · 가득까지 n번) → [강화] 몇 번(실패 = 칸 차오름 · 성공 = 비우기) · [i] = 큰 창.
3. 폰(ForceTouchLayout)으로 강화대 → 전투 버튼 대신 둥근 [강화].
4. 가방(G) → 정렬 · 필터 · 선택해서 정리 · 장비 고르고 [비교].
5. 도감(K) → 진행 상자 10개(PC) · 직업 탭 무기 그림 4×8.
6. 구역 선택(N) → 칸 상태 그림 · 보스 칸 금 테 + 초상 · 등록한 관문 보스 칸 [원격 입장] → 보스 관문 창.
7. 지도(M) → 판 안쪽 [+ − ◎ ?] · 관문 = 보스 초상 핀.
8. 더보기 → [HUD 편집] → 다음 목표 카드 끌어 옮기고 [저장하고 나가기] → 설정 › 조작 · HUD › [처음 위치로](2단계).
9. 더보기 › 펫 → 알 확률 막대 · 펫이 있으면 [잠그기] · [놓아주기](2단계).
10. 상점 → 큰 창 · 노랑 [구매] 1개 · 카운트다운 없음 · 파티(P) → 빠른 말 눌러 머리 위 말풍선.
