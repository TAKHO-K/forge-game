## 5. 일어난 문제 · 정정

- **데이터 줄 가운데 주석**: 환생 줄 가운데에 주석을 넣어 뒤쪽 `pillar` 키가 주석으로 사라짐 → Play 3에서 환생 연출 오류 20회(`attempt to index nil with 'height'`) → 수정 · 데이터 파일 전체 grep으로 같은 패턴 0 확인. 메모리에 있던 함정을 한 번 더 밟았다.
- **대시 감지 0**: 대시는 루트를 CFrame 트윈으로 옮겨 `AssemblyLinearVelocity`가 0 → 치장 대시 트레일이 안 켜짐(Play 4) → 위치 변화량으로 감지.
- **가산 발광 Beam**: 검은 심(초월)이 안 보이고 색 기둥이 블룸에서 흰색으로 날아감 → 심 = 비발광 · 색 띠 = 발광 0.4 ~ 0.5.
- **첫 조명 값**: 평면 재질에서 채도 +0.08 · 밝기 2.5 ~ 2.8은 잔디 · 모래가 형광처럼 뜸 · 해질녘(17.4 ~ 17.9)은 몬스터가 안 보임 → 규칙화(art-direction §5-6).
- 파이썬 히어독 한글 깨짐으로 하네스 머리 주석 편집이 한 번 실패 → Edit 도구로 재적용.

## 6. 결정 필요(3개 이내)

1. **아트 스위치 켜기**: `ArtStyleV1Data.enabled`(지금 false). 이번 Studio 에셋은 Blender 가져오기 없이도 게임 안에서 동작한다 - 구역 조명 · 도파민 · 전조 · UI 프레임만 먼저 켤지(치장은 판매 전이라 보이지 않음).
2. **몬스터 색 대비(종 데이터)**: T4 전갈 · 선인장(황토 · 녹)과 T6 얼음 골렘(옅은 청)이 바닥과 색이 붙는다 - 바닥은 최대한 조정했다. 아트 스위치 뒤에서 몬스터 색을 덮을지(예: 전갈 적갈 (140, 60, 35)).
