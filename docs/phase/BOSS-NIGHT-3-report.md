| 그림(빔 · 전조 띠) ↔ 판정 | 1.8(옆으로 비킨 줄인데 그림만 안쪽 원 반경부터) | 0.00 ~ 0.02 |

함께 고친 것(재측정 중 찾음):
- **클라 빔 시작 거리**가 서버 판정과 달랐다: 서버 = 반경 ≥ 안쪽 원 · 빔 위 거리 ≥ fwd, 클라 = max(안쪽 반경, fwd). 줄이 옆으로 8 stud 비켜 있으면 안쪽 원 6을 이미 벗어나 판정은 4.2부터인데 그림은 6부터였음 → 클라 `beamStart = max(fwd, √(inner² − lat²))`(서버와 같은 식).
- **보이는 몸 회전 지연**: 클라 몸 회전 부드럽게 하기(지수 계수 10)가 초당 150° 회전에서 약 0.1초 늦음 + 서버 0.1초 갱신 → 서버가 0.13초 앞선 빔 각을 `BossAimLockYaw`로 보냄.
- **회전 기울기**: 몸이 도는 쪽으로 최대 12° 기울어(turnLean) 보석이 옆으로 약 1 stud · 높이 2 stud 방향마다 달라짐 → 조준 고정(aimLock) 동안 회전 기울기 0(조준 고정의 목적 = 시전 중 부위 자리 고정 · 다른 조준 고정 스킬도 같음).
- 안쪽 원 14 회차(보스 곁 안전 원)는 빔이 √(14² − lat²) ≈ 11.4부터 시작 → 보석과 약 7 stud 떨어져 보이는 것은 설계(안전 원 안 판정 없음) - 사용자 확인 항목.
- Studio 측정 함정: 첫 만남 연출 뒤 카메라가 Fixed로 보스에서 6,447 stud 떨어진 곳에 남으면 거리 LOD로 모션이 멈춰 부위 자리가 그대로 고정된다(측정 전 카메라 Custom 확인).
