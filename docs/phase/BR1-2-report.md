## ⑥ 결정 필요

1. **모형 가정**(평타 노출 원거리 0.6 · 근접 0.7 · 둘째 투사체 × 0.35 · 발악 50% · 코스 45초 등)은 추정 - 실제 플레이 체감으로 확인.
2. **곡선 단계 체감**: 모형에서는 ④(인당 8발)가 평균을 거의 안 올린다(첫 발을 피하면 줄 전체를 피한다는 가정) - 8발이 실제로 어려운지 확인 필요.
3. **평타 한 방 ×0.3**: 사거리 26으로 원거리도 늘 맞게 한 대신 한 방이 초당 1.5%로 약하다 - 원거리 피격이 "느껴지는지" 확인.
4. **파티 공동 책임 45%**: 4인 전멸 30%대를 내려고 넣은 규칙(한 명 실패 → 나머지 45%) - 체감이 가혹하면 30%로(4인 전멸 약 25%).
5. 근접 솔로 받은 피해 72%(목표 80 하한 약간 아래) · 전갈 파티 전멸 0 ~ 6%(개별 피해 위주 보스) · 수정 여왕 파티 16 ~ 20% - 보스별 파티 보정 여부.
6. 기록만(K): 성기사 패링 · 반사 대결(필드 준비됨) · 튜토리얼 재설계(P4)에서 전멸기 개념 설명(30 보스 전멸기).
