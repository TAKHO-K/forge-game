지시 = 사용자 프롬프트(G1 A, COMMON.md §7). 기준선 = `f352bad`. PRD = 20.126. 저장 구조 변경 없음.

**한 줄 요약**
- 레벨차 계수: 스테이지 − (레벨 + 167) − 무료 폭 100(힘 비율 1.02^100) > 0이면 주는 피해 −1%/칸(하한 ×0.25) · 받는 피해 +2%/칸(상한 ×3). 잡몹 · 보스 · 모든 피격 경로 · 게임과 EconSim 같은 함수.
- 캐주얼 1,000 도달 **58.1시간**(목표 55 ~ 60 안) - 환생 경험치 배율 ×6 그대로(보정 불필요).
- 환생 확인창 강화 · 환생은 커뮤니티 센터 제단 한 곳(강화대 탭은 안내) · 제단 경험치 배수 직접 계산 제거 · "커뮤니티 센터 (준비 중)" 이름 정리.

## ⑤ 결정 필요

1. **1 ~ 3회차 환생 직후에도 직전 보스를 깬다** - 기준(레벨 + 167 + 무료 폭 100)이 넉넉해 벌점이 스테이지 268 이상에서만 걸린다. "레벨 1의 의미"를 1회차부터 원하면 무료 폭을 줄이거나(예: 0 ~ 50) 기준을 바꿔야 한다(1,000 도달 시간이 늘어 경험치 배율 보정이 다시 필요).
2. 보스 기여도에 주는 피해 계수가 들어간다 - 저레벨 파티원이 기여 10% 미만이면 보상에서 빠진다. 유지 / 기여도는 계수 전 피해로.

**사람이 확인할 것**: 환생 확인창 문구의 체감 · 강화대 환생 탭 안내 문구.
