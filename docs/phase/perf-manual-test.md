# 4인 로컬 서버 성능 측정 절차서 (QUEUE-ALL4 D · 사용자용)

> 왜 필요한가: Studio MCP는 클라를 1개만 띄울 수 있어 "남의 캐릭터 · 남의 연출이 4명분 실제로 오갈 때"의 프레임 · 메모리 · 네트워크를 자동으로 못 잰다. 서버 쪽은 `/gg perf world` · `/gg perf boss`(가짜 참가자)로 재고, 실제 다중 클라는 아래 절차로 사용자가 한 번 잰다. 15 ~ 20분이면 된다.

> 비교 기준(QUEUE-STUDIO 2026-10-01 · 1클라 실측): `docs/perf/queue-studio-perf.md` - 서버 12인 Heartbeat 1.12ms · 보스 4인 0.57 ~ 1.13ms · 보스전 렌더 CPU 4.4ms · 켜진 광원 7.

## 0. 준비
- Studio에서 이 장소를 연다. Rojo 플러그인이 **Connected**인지 본다(창 위 초록 표시).
- 파일 → 스튜디오 설정 → 렌더링 → **프레임 속도 제한(Framerate Manager)이 켜져 있으면 끈다**(60fps 상한이면 차이가 안 보인다 - 끌 수 없으면 그대로 두고 "상한 켜짐"이라고 적어 준다).
- 그래픽 품질: Esc → 설정 → 그래픽 모드 **수동 · 품질 5**(중간). 폰 흉내는 아래 4절.

## 1. 4명 띄우기
1. 위 메뉴 **테스트(Test)** 탭 → 가운데 **클라이언트 및 서버(Clients and Servers)** 칸.
2. **로컬 서버(Local Server)** 고르기 → 인원 **4명(4 Players)** → **시작(Start)**.
3. 창이 5개 뜬다(서버 1 + 플레이어 1 ~ 4). 모두 로딩이 끝날 때까지(약 40초) 기다린다.
4. 끝낼 때는 서버 창에서 **정리(Cleanup)** 를 누른다.

## 2. 필드 측정(허브 → 사냥터)
1. 플레이어 1 ~ 4 창을 차례로 눌러 모두 **같은 구역(석조 평원)** 으로 걸어가 서로 보이게 모인다(지도 M → 구역 → 자동 이동 써도 됨).
2. 4명 모두 몬스터를 1분 동안 계속 친다(좌클릭 꾹).
3. 그동안 **플레이어 1 창**에서:
   - **Shift + F5** → 화면 위 숫자 중 **FPS(평균)** · **프레임 시간(ms)** 을 적는다(30초 동안 가장 낮게 떨어진 값도).
   - **Shift + F2**(렌더 통계)를 켤 수 있으면 **Draw calls · Triangles**를 적는다.
4. **F9**(개발자 콘솔) → 위 탭 **Memory** → 맨 위 **Total(MB)** · **PlaceMemory** 를 적는다. 탭 **Network** → **Data Receive(KB/s)** 를 적는다.
5. **서버 창**에서 F9 → **Server** 쪽 Memory **Total** · 탭 **Stats(ServerStats)** 의 **Heartbeat(ms)** 를 적는다.

## 3. 보스전 측정
1. 플레이어 1이 파티를 만들고(P → 만들기) 2 ~ 4를 초대 · 수락한다.
2. 4명이 첫 관문(수호자) 앞에서 등록 → 도전.
3. 보스가 패턴을 2바퀴(약 1분) 쓰는 동안 2절 3 ~ 5를 같은 방법으로 적는다. 특히 **보스가 땅을 치는 순간 · 지반 붕괴 순간** 가장 낮은 FPS.

## 4. 폰 흉내(선택)
- 플레이어 1 창 → 테스트 탭 **기기(Device)** → **iPhone 14** 같은 가로 폰 → 그래픽 품질 **1**. 2절 · 3절을 한 번씩 더.

- 기준(참고): PC FPS 평균 50 이상 · 최저 30 이상 · 폰 흉내 최저 25 이상 · 클라 메모리 1,500MB 이하 · 서버 Heartbeat 평균 5ms 이하. 넘는 줄이 있으면 그 순간 화면 한 장도 같이 보내 주면 원인을 좁힐 수 있다.

## 6. 자동으로 잰 것과의 관계
- 서버 부하 표(가짜 참가자) = `docs/phase/QUEUE-ALL4-report.md` 성능 절. 이 절차의 서버 Heartbeat가 그 표의 같은 인원 값보다 2배 이상 크면 "가짜 참가자가 못 흉내 내는 비용"(실제 캐릭터 물리 · 복제)이 크다는 뜻이다.
