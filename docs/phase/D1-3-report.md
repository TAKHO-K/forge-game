# D1-3 보고 - D1-2 결정 반영: 도달 시간 목표 재설정 · 반짝이 0.1% · 흰 발자국 삭제 (2026-09-27)

지시 = "[D1-2 결정 반영 + MV1] 파트 0". 검증 = COMMON §7-1(이번 수정만 - 바뀐 EconSim 기준표 · 반짝이 공급 표). 경제 수치 변경이라 EconSim을 로컬 하네스로 돌렸다(3프로필 + 반짝이 없음 비교 2). **저장 구조 변경 없음(SAVE_VERSION 43 그대로)**.

**한 줄 요약**
- 반짝이 출현 **0.5% → 0.1%** · 골드 **25 → 125마리분**을 적용했다. 사냥 골드 중 반짝이 몫은 10.9% → **11.1%**로 거의 그대로다.

- **캐주얼 1,000 도달 = 39.2h**로, 새 목표 40 ~ 45h의 하한보다 **0.8h(2%) 아래**다(결정 1).
- 태초 흰 발자국 연출을 지웠다(MV1 태초 신발 2단 대시로 대체).
