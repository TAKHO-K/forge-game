# A2-S 보고 - 아트 디렉팅 + 스타일 샘플 1세트 (승인용 · 2026-09-30)

> 샘플은 전부 **스위치 `ArtStyleV1` 뒤**(기본 꺼짐 - `shared/data/ArtStyleV1Data.enabled = false`). 이번 커밋으로 플레이어 화면은 바뀌지 않는다. 켜기 = Studio `/gg art on`(끄기 `off` · 대검 미리보기 `/gg art look normal|legendary|transcendent|grade`). place 저장 불필요.

## 0. 아트 방향 요약 5줄

1. **"두툼한 장난감 대장간 — 덩어리는 크고 단순하게, 빛은 보상에만."**
2. 형태: 종마다 튀어나온 것 1개(슬라임 = 새싹 두 잎) · 큰 1 : 중간 2 ~ 3 : 작은 ≤ 4 · 최소 두께 0.4 · 모서리는 쐐기로 깎는다.
3. 색: 채도 층 = 배경 < 바닥 < 캐릭터·몬스터 < 드랍·이펙트. 3톤은 조명으로(스펙큘러 0), 가장 어두운 색 = `#1E1B2E`. 등급 색은 무기·드랍·강화 연출에만.
4. 재질: SmoothPlastic 기본 · Neon은 등급 발광·눈빛·불꽃에만(모델 면적 ≤ 15%) · 외곽선 = Highlight 풀(두께 고정 → 두께감은 형태로).
5. VFX: 흰 번쩍 → 색 → 흩어짐 · 위로 솟음 = 좋은 일 · 성공 ≤ 14 입자 / 대성공 ≤ 24 입자 · 보스 전조가 항상 우선.

참조 이미지 공통점(직접 본 것 - 10 · 12 · 13 · 15 · 01 · 07 · 구역 합본 · 대장간 썸네일 · 알 아이콘 · 패스 아이콘 · 툴팁): 두꺼운 어두운 외곽선 + 한쪽 광택 / 평면 3톤 · 질감 없음 / 짧은 비율 · 큰 흰 눈 / 등급 = 같은 형태에 색 · 빛 · 장식 누적 / 배경은 채도 낮고 넓게. UI 시트 16 ~ 18 · 00 · 11 · 14 · 19 · 20은 이번 샘플 범위 밖이라 목록만 확인했다.

## 7. 사용자에게 물을 것 (3개)

1. **귀여움 ↔ 날카로움**: 슬라임은 지금 "귀여움 7 : 날카로움 3"(둥근 돔 · 큰 흰 눈). 상위 티어로 갈수록 뿔 · 각을 늘리는 규칙(style-bible §5)과 맞추려면 T1은 이대로, 아니면 **눈썹 쐐기 1개로 조금 더 장난스럽게**?
2. **채도**: `artV1`은 cartoon보다 채도 +0.04 · 대비 +0.02 더 올렸다(`compare-off-on`). 잔디가 형광에 가깝게 느껴지면 +0.08로 되돌린다 - 지금이 좋은가?
3. **외곽선 두께**: Highlight는 두께 조절이 안 된다(화면 기준 가는 선). 캐릭터 · 몬스터에 **굵은 선이 꼭 필요하면 Blender 메시에 뒤집힌 헐(파트 수 × 2)** 을 붙여야 한다 - 보스만 / 잡몹까지 / 지금처럼 가는 선?
