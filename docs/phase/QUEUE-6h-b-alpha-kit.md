## 3. Studio 2인 로컬 서버 테스트
**절차**: Studio 위 메뉴 **테스트** 탭 → "클라이언트 및 서버" 칸에서 **로컬 서버** 선택 · 플레이어 **2** → **시작**. 창 3개(서버 1 · 클라 2)가 뜹니다. 두 클라에서 파티를 맺고(P 키 → 초대 · 수락) 같은 보스로 들어갑니다(`/gg boss 5`는 파티장이).
| 볼 것 | 방법 | 기대 |
|---|---|---|
| 영혼 → 구원의 기도 부활 | 한 명을 치유사로(`/gg class healer`) · 다른 한 명 `/gg soul die` → 리스폰 뒤 영혼 · 치유사가 R(기도)을 영혼 근처에서 | 영혼 풀림 · 체력 30% · 로그 `[K3] 부활 … 구원의 기도` |
| 성역 끝 부활 | 치유사 T(성역)를 켠 뒤 성역 안에서 다른 한 명 `/gg soul die` | 성역이 끝날 때 부활(리스폰 대기 중이면 리스폰 때) |
| 전멸 | 두 명 다 `/gg soul die` | 보스 리셋 · 힌트 단계 · 둘 다 살아 돌아옴 |
| 한 명 영혼 · 한 명 이탈 | 한 명 영혼 상태에서 다른 한 명이 창을 닫음 | 남은 사람(영혼)이 전멸 처리됨(보스전이 멈추지 않음) |
| 튕김 재접속 | 보스전 중 한 클라 창을 닫고 120초 안에 다시 들어오기(Studio에서 실행 중 플레이어 추가가 안 되면 퍼블리시 비공개 서버에서 계정 2개) | 다시 들어오면 영혼으로 관전 · 클리어하면 보상 |
| 파티 보상 | 둘이 함께 보스 처치 | 두 명 모두 보상 로그 · 기여 10% 미만이면 제외 |
- 사람이 해야 하는 이유: MCP로는 클라이언트를 하나만 띄울 수 있다. 서버 규칙 자체는 로컬 하네스(`roblox/tools/harness/multiplayer_test.luau` 10/10)로 확인했다 - 여기서는 실제 네트워크 · 화면을 본다.

## 6. 폰 확인 절차(S25)
순서대로 한 번에 15분:
1. 접속 직후: 오른쪽 아래 버튼 8개(공격 · 점프 · Q · E · R · T · 대시 · 고정)가 겹치지 않는가 · 왼쪽 메뉴바(가방 · 스테이지 · 퀘스트)가 **대시 버튼과 겹치지 않는가**(Studio 폰 흉내에서 40px 겹침을 고친 것 - 실제 기기 확인이 처음).
2. 왼쪽 아래 조이스틱 구역에 [직업 변경] 버튼이 **없는가**(설정 창으로 옮김).
3. 설정 창: 맨 아래 [직업 변경]까지 스크롤로 닿는가 · 섬광 · 흔들림 토글 터치 영역.
4. 퀘스트 창(J 대신 메뉴바) · 출석 칸 [받기] 터치 · 확률 창 글씨 크기.
5. 알 창 [부화] · [받기] 버튼 · 펫이 화면을 가리지 않는가.
6. 보스전: 체력바 · 경고 표시 · 영혼일 때 화면.
7. 태초 드랍 배너(위 가운데 띠)가 다른 HUD와 겹치지 않는가.
