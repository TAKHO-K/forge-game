## 2. 2차 패스

검토 서브에이전트가 contact-sheet(전 에셋)에서 약한 10을 골랐다. 그중 5개(관문 · 강화대 · 강아지 꼬리 · 석조 · 수몰 방어구)는 **검토자가 옛 렌더를 기억해 고른 것**으로 이미 반영돼 있었다(최신 렌더로 확인). 나머지를 고쳤다:

| 약한 에셋 | 수정 | 결과 |
|---|---|---|
| 소품 면 처리(스타일 불일치 ② - 소품만 잔 면이 많아 "다른 게임" 같았다) | 바위 흔들림 0.07 → 0.035 · 층 비틀림 0.35 → 0.12 · 8각 | 큰 면 · 매끈한 언어로 무기 · 몬스터와 맞춤 |
| 비석 · 수정 첨탑 · 피뢰 기둥(바늘) | 비석 = 상자 폭 채운 모따기 돌 · 첨탑 = 결정 3개 묶음 · 피뢰 막대 ×2.5 · 받침 1.5배 | 첨탑은 틀 자체가 10 × 132(13 : 1)라 여전히 가늘다 - 한계 |
| 구역마다 같은 회색 바위 | 장식 파트(틀 발자국 안 · 충돌 없음): T1 이끼 모자 · T2 결정 돌기 · T5 번개 줄기(발광) · 번개 바위 떠 있는 조각 | 구역 구별 O(새 파트 = PropData 추가 필요) |
| 모래 항아리 채도 | −20% | 드랍보다 튀지 않게 |
| 푸른 드래곤 | 몸통 · 다리 ×1.15 | 7.8(아직 8 미만) |
| 폭풍 군주 | 망토 옆으로 벌림(정면 폭 = 어깨 1.3배) | 7.4 |
| 전갈 여왕 48파트 | **안 고침** - 다리를 합치면 모션 관절이 사라진다 | 결정 2 |
| 모음 라벨 점수가 검토보다 높았다(검토자 지적) | 라벨 = "검토 → 자체" 구분 | 정직하게 표기 |

- 스타일 불일치 ①(외곽선 규칙이 보스마다 다름)은 파트 상한 문제라 결정 2로.

## 5. 결정 필요(3개 이내)

1. **보스 몸 색**: `BossData` 보스 몸 · 머리 색 = 몬스터 **티어 색**이라 서리 거인 · 심해 군주 · 폭풍 군주가 모두 초록이다(얼음 · 심해 인상이 형태로만 남음 - 5종 보류의 주원인). 추천 = 보스 몸 색을 종 테마 색(서리 = 청백 · 심해 = 짙은 청록 · 폭풍 = 남보라 …)으로 바꾸고 티어 색은 문양 · 강조로만.
2. **보스 외곽선 · 파트 상한**: 껍데기 외곽선이 파트 상한 30 안의 여유만큼만 붙어 보스마다 0 ~ 10개(수정 여왕 · 전갈 여왕 0) · 전갈 여왕은 리그부터 48파트. 선택지 = (가) 보스 상한을 40으로 올리고 큰 파트 전부 껍데기(추천 - 삼각형은 6,000 안) (나) 껍데기 없이 전 보스 Highlight 통일 (다) 전갈 여왕 다리 · 꼬리 마디 수 줄이기(모션 수정 필요).
3. **가정한 예산 · 도형 유지 확정**: 펫 · 방어구 800 · 관문 틀 3,000은 art-direction §6에 없어 가정했다 · 소품은 반복 배치라 50% 미만을 의도했다 · 슬라임 · 양은 도형 유지(Blender "비슷"). 이 넷을 §6 표에 확정할지.

## 7. 일어난 문제 · 정정

- **시험 파일 커밋**: `git add roblox/art/`로 권한 시험 파일 `roblox/art/_permtest.txt`와 `__pycache__/*.pyc`가 fe836d5에 들어갔다(지시 위반) → fbd4e7c에서 추적 해제 + `.gitignore`에 `__pycache__/`. 히스토리에는 남아 있다(강제 푸시 안 함). 이후 커밋은 경로를 파일 단위로 지정.
