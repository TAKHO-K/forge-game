## 3. C3-1 · C3-2 입력 · 템포

- **꾹 누르기**: 좌클릭 · 폰 공격 버튼을 누르고 있으면 간격마다 다음 타(조준 = 매번 지금 커서 · 폰 자동 조준). 누름 1회 = 1회 · 간격 안 누름 = 준비되면 1회(버퍼). 서버: 간격 − 흔들림 여유 0.05까지만 받고 받은 시각 = max(지금, 지난 + 간격) → 평균 빈도 ≤ 1 ÷ 간격.
  - Play 1: 누르고 있기 3초 = 9회(간격 0.333) · **초당 20회 연타 3초 = 10회**(이득 0) · Play 3 폰 버튼 훅 3초 10회 · **실제 마우스 누름 2초 = 7회**.
- **공속 환산 규칙**(`PlayerCombat.getAttackTempo` - 서버 · 클라 · BalanceSim 한 함수): 간격 = 0.45 ÷ 장비 · 보석 공속(버프 제외), 최소 0.33(초당 3회). 한 타 피해 배율 = 간격 ÷ 옛 쿨다운(버프 포함) → **초당 피해 = 옛 식과 같다**(전 직업 × 공속 0 · 0.36 · 1.5 · 3 × 버프 = 비 1.000000 - 순수 검사 32/32). 신발 · 옵션 · 보석 · 버프 모든 공속원 같은 규칙.

| 직업 | 공속 0: 간격 · 한 타 배율 | 공속 상한: 간격 · 한 타 배율 |
|---|---|---|
| 대검 | 0.45초(2.2/s) · ×1.125 | 0.33(3.0/s) · ×2.06 |
| 쌍검(두 칼 2타 묶음) | 0.45 · 타마다 ×1.286 × 2 | 0.33 · 타마다 ×2.36 × 2 |
| 활 | 0.45 · ×1.35 | 0.33 · ×2.48 |
| 치유사 | 0.45 · ×2.01 | 0.33 · ×3.68 |

- **쌍검**: 입력 1회 = 두 칼 2타(같은 순간 판정 · 타마다 치명 굴림 · 콤보 1회) - Play 2 결과 이벤트 2개 · 0.000초 차.
- **강궁**(옛 속사): 버프 동안 간격 × 1.6(평소 0.45 → 0.72 · 상한 0.33 → 0.528) · 한 발 = 옛 속사 DPS × 간격 × `damageMultiplier` 1.0(**DPS = 옛 속사와 같음** - EconSim 불변) · 관통 1(서버 경로 두 번째 몹 · 타마다 치명) · 짧은 넉백 1.5(서버 - 잡몹만 · 벽 · 낭떠러지 · 몸 반경 확인) · 큰 화살 ×1.8 · 꽂힌 화살 = 한 타 배율만큼 커짐(총량 불변) · 꾹 누르면 자동 발사. Play 3: 버프 ×1.70 · **간격 0.53 ×5 · 6발 전부 강궁 · 대상 없이도 발사**. "빨리 누르면 고점" · "화살 2발" 폐기.
- 백스텝샷 추가 피해 = 발당 고정(한 타 배율 밖 - 5발 총량 불변).

## 6. W3a 공격 모션

- 공통: 다리 · Root 키(`PlayerMotionData.body(dy, stride, yaw, lean)` - 두 무릎을 같이 굽혀 발이 땅에 남게) · 걷는 동안 다리 가중치 = 이동 속도만큼 감소(걸으며 공격 유지) · 판정 시각 불변(근접 1프레임) · 무게 = 앞 타의 회복이 다음 타의 들어 올림.
- **대검**: 보조 손 자리 −1.45 → **−1.58**(0.58 → 0.8 stud - 두 손이 겹쳐 한 손처럼 보이던 원인) · 1타 오른 어깨 위(θ 235) → 체중 싣고 왼 아래 · 2타 왼 허리 장전 → 한 발 내딛는 가로베기 · 3타 머리 위로 크게 감았다가 몸을 돌리며 내려찍기(Play 3에서 가라앉음 다듬음).
- **쌍검**: 한 동작 안 오른칼 → 왼칼 시차(동작 끝 = 앞 칼만 벤 자리 · 뒤 칼은 회복 앞부분) + 스텝 · 3타 두 칼 동시 X.
- **지팡이**: 한 손 지팡이 + 왼손 = 대상 쪽 손바닥 시전(보조 손 IK 끔 - "배 잡기" 원인).
- **활**: 기본 유지 · 강궁 = 당김 고정점 귀 쪽 뒤로(+0.25, +0.05, +0.45) · 시위 ×1.35 · 쏜 뒤 0.26초 반동(몸이 살짝 뒤로).
- 스크린샷(`Claude outputs/C3/`): 전 `before-attack1-front` · `before-attack3-front` · `before-air-front` / 후 `after-attack1-front-4classes` · `after-greatsword-attack1` · `after-greatsword-attack3-side` · `after-dualblade-attack1` · `after-staff-attack1` / 비교 `compare-code-attack3` · `compare-keyframe-attack3` / 폰 `phone-attack-button`.
- **대검 코드 vs 키프레임**: `client/KeyframeCompare`가 같은 키 포즈로 KeyframeSequence를 만들어 `KeyframeSequenceProvider:RegisterKeyframeSequence`(Studio 임시 · 업로드 없음)로 재생 - 3타 같은 순간 컷은 거의 같다(차이 = 시간 흐름: 따라 휘두름 끝 0.06초 멈춤 · 관절별 이징). 라이브에 키프레임을 쓰려면 사용자 작업: Studio Animation Editor → 캐릭터 선택 → 가져오기(`/gg anim greatsword kf`가 만든 시퀀스를 ServerStorage로 복사해 두면 됨) → 다듬기 → 게시(Publish to Roblox) → 받은 id를 데이터에.
