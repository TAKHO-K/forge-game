# D0 결정 시트 (2026-09-25)

사용자가 고를 항목만 모았다. 근거는 `D0-audit.md`(현재 상태) · `docs/design/skills-RT.md`(스킬) · `docs/art/style-bible.md`(아트) · `roadmap-v2.md`(일정). 단계 = 자율 단계 하나(코드 + Play 3회 + 보고서, 약 4 ~ 6시간 [추정]).

**이미 확정된 것(선택지 아님)**
- P3d-F 후속 4건(받는 피해 하한 0.25 · 끼이는 순간 평타 ×2 · 재생성 자리 찾기 ≤ 2ms/프레임 · 계정 무관 기대식) → G1 첫 파트.
- **이동기: 이단점프 채택**(사용자 확정 - 같은 점프 버튼 두 번 · 2단은 1단보다 낮게 · 기절 · 끼임 · 넉백 중 불가 · 서버 높이 검증). **공중대시는 보류.** 세부 수치는 아래 3번.
