기준 코드: `roblox/src/` (커밋 c4ed73b 시점 작업 트리). 줄 번호는 모두 `roblox/src/` 기준 상대 경로.
약어: BD = `shared/data/BossData.lua`, BS = `shared/BossScheduler.lua`, BR = `shared/BossRules.lua`, BSM = `shared/BossSkillMath.lua`, BP = `server/BossPatterns.lua`.

## 0. 공통 규칙과 읽는 법

| 항목 | 값 | 근거 |
|---|---|---|
| 스킬 피해 `attack` 배율의 기준 | 보스 공격력(잡몹 공격력 × attackMultiplier 1)의 감소식 거친 1타 × 배율. **보스별 평타 배율(basicAttack.damageMultiplier)은 스킬에 안 곱한다** | BP:219 `applyHit(player, data.attack, label, damage.multiplier)`, BD:250, BR:217 |
| 배율 → 최대체력 몫(앵커 7타 생존) | ×1 = 14.3% · ×1.5 = 21.4% · ×2 = 28.6% · ×3 = 42.9% | BD:190(×3 = 42.9%), BSM:252 (배율 ÷ surviveTargetHits) |
| `maxHp` 피해 상한 | 발동당 1인 합계 ≤ 55% (gimmickFailMaxHpFraction 0.55) | BD:56, BSM:241-243 |
| 우선순위 눈금 | normal 0 · signature 50 · gimmick 100, 굶주림 가산 +1000 | BD:149-150 |
| 전역 쿨(GCD) | 보스별 5/6/7초, 격노(HP ≤ 20%) 2.5초, 입장 유예 2초 | BD:260-267, BP:1790 |
| 범위 배율 | 스테이지 5 이하 1.0 → 스테이지 25 이상 1.152 고정. 대상 필드 radiusStuds · innerRadiusStuds · halfWidthStuds · pathHalfWidthStuds · scatterStuds · pulses · finisher.radiusStuds. 파동 속도·두께·전조·쿨은 불변 | BR:56-67, BSM:266-293 |
| 범위 배율 계산 | s(S) = (1 + 0.15 × itemLvMult(min(S,25))) ÷ (1 + 0.15 × itemLvMult(5)), itemLvMult(L) = 1 + 0.06(L−1) → (1+0.15×2.44)/(1+0.15×1.24) = 1.366/1.186 = **1.152** | BR:56-61, Loot:287-293, CharacterLevel:177-178 · 23 · 164-165, CharacterLevelConfig:14 · 19, EquipSlots:28 |
| 힌트 2단계 | 기믹 전조 × 1.5, 게이트 판정 스킬(폭풍 낙뢰)도 × 1.5 | BD:129-133, BP:984-989, BP:1423 |
| 구속 시간(bound) | circleBoss = 전조 × 펄스 수 · ring = 마지막 파동 마지막 겹이 최대 반경(140.6)에 닿을 때 · circleTarget = 전조(연발이면 + 반복전조 × (count−1)) · charge = (전조 + 이동) × dashCount + recover · line = 전조 × volleys · gimmick = 전조 + recover | BSM:62-88, 최대 반경 = 96 × (√2 + 0.05) = 140.56 (BossArenaMapData:41) |
| 최소 반복 간격 추정식 | 같은 스킬의 시작→다음 시작 ≥ bound + max(쿨, GCD). 내부 쿨과 GCD 모두 **스킬이 끝난 시각**부터 돈다(BS:160-166). 6종 모두 쿨 ≥ GCD라 격노(2.5초)는 **같은 스킬의 반복 간격을 줄이지 못하고** 스킬 사이 빈틈만 줄인다. 또 "연속 금지"(BS:118-125)로 다른 후보가 있으면 같은 스킬은 두 번 연달아 못 나간다 | BS:7-8 · 88-91 · 160-166 |

돌진(charge)의 이동 시간은 실제 벽까지 거리에 따라 달라진다. 아래 표는 모형 기본값 1.5초(BD:175) ~ 상한 280 ÷ 60 = 4.67초(BSM:80, 아레나 반경 140 · BossArenaMapData:25) 범위로 적었다.

## 8. BossScheduler 선택 규칙(3줄)

1. 한 번에 한 스킬만. 직전 스킬이 **끝난 뒤** GCD(격노면 2.5초)와 입장 유예가 지나야 고르고, 후보 = 내부 쿨이 찼고 조건(conditions)이 전부 참인 스킬 (BS:6-9, 88-91, 101-105).
2. 자리 비우기: 아직 안 나온 reserveFirstUse 기믹의 첫 시각을 넘겨 끝날 다른 스킬은 뺀다. 다른 후보가 있으면 직전 스킬은 뺀다(연속 금지) (BS:10-13, 93-125).
3. 우선순위(normal 0 · signature 50 · gimmick 100, starvationSeconds 넘으면 +1000) 큰 쪽 → 같으면 readyAt 이른 쪽 → skillOrder 순. 고른 스킬의 precondition이 거짓이면 otherwise 스킬로 대신 시작(서리 포효 → 낙빙) (BS:14-16, 127-149).

## 10. 스테이지 25 이후 밀도 증가(S14)

- 범위 배율은 스테이지 25에서 1.152로 멈추고, 그 뒤 난이도는 **낙하 원 개수**가 맡는다 (BD:135-139, BR:69).
- extra(S) = min(3, ⌊(S − startStage) ÷ stepStages⌋), S ≤ startStage면 0. startStage = fromLegacyStage(25, 5) = 175, stepStages = fromLegacySpan(25, 5) = 180 (k 1.02 환산, 옛 1.155 기준 25·25) → **스테이지 355부터 +1 · 535부터 +2 · 715부터 +3(상한)** (BD:137 · 144-145, BR:76-82, InfiniteStage:16-33, InfiniteStageConfig:17 · 24).
- 대상: densityScalable = true인 스킬만 - circleTarget · 동시 산개(연발 아님) · scatterStuds > 0 · 기믹 아님 · 게이트 없음. 현재 **3개: 수호자 낙석 · 서리 낙빙 · 전갈 독침** (BSM:299-302, BD:219 · 413 · 637).
- 적용: count += extra, scatterStuds × √((count + extra) ÷ count)(면적당 밀도 보존). 범위 배율을 먼저 곱한 뒤 밀도를 더한다. 낙빙의 인원 몫(countPerMember)은 그대로 따로 더해진다 (BSM:304-320, BR:262, BP:912-913).
- 쌍 스테이지(보스 2마리)면 밀도 증가를 끄지만 지금 isPairStage는 항상 false (BR:70-74). 견습은 0 (BR:209-210).
- 합격 기준: BossSim.checkDensity(72방위 × 0.5stud, 99분위 ≤ 전조, 최댓값 ≤ 전조 + 0.25초). 실패하면 maxExtra 0으로 끈다 (BD:139-145).

## 11. 참고 · 주의점

- **"범위 배율 25"의 스테이지 척도**: 범위 배율은 신발 itemLevel이 25에서 동결되는 데서 나온다(BR:52-57, CharacterLevel:177-178). 밀도 임계값은 P2.5c에서 k 1.02 척도로 환산(175 · 355…)했지만 **범위 배율의 25는 환산되지 않고 지금 스테이지 번호 25 그대로**다. 즉 지금 척도에선 1바퀴(스테이지 25) 안에 이미 최대 배율에 닿는다 - 의도 여부는 코드 주석으로 확인되지 않음.
- 돌진 계열(수호자 돌진 · 전갈 잠행 찌르기)의 반복 간격은 벽까지 실제 거리에 달려 범위로만 적었다.
- 연발(sequential)·링의 구속 시간은 BSM.boundSeconds의 **상한식**이고, 실제 onSkillEnd 시각은 BossPatterns 핸들러가 정한다 - 표의 "최소 반복"은 추정치.
- 링 스킬 3종(진동파 · 해일 · 방전 고리)이 "점프 필수"다. 범람은 "올라가기"이지만 1stud 계단이라 걷기로 오른다.
