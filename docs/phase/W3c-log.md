| 명령 | 보이는 것 |

| `/gg anim greatsword airattack [반복]` | 점프 → 정점 가까이 칼을 머리 뒤로 → 내려찍기(히트스톱) → 착지 먼지 고리 · 쿵(해금 단계 무관) |

| `/gg anim healer skille [반복]` | 검보라 소용돌이(두 손) + 지팡이 내리꽂기 → 어둠 구슬 발사 → 비행(보라 테두리 · 어둠 리본) → 터졌다 빨려 듦 |

## Play 스크린샷 계획(부모 - 밝은 맵 · 어두운 맵 둘 다)

- 어두운 맵 = 클라 `Lighting.ClockTime = 0` · `Brightness` 낮춤(끝나면 되돌림) 또는 어두운 구역.
- 정지 컷(포즈만 - `PlayerGui.W1PoseHook:Invoke("freeze", clip, tau)`):
  - 대검 `air`: tau 0(칼 머리 뒤 · 준비) · 0.0167(타격) · 0.08(내려찍는 중) · 0.217(끝 - 칼끝 발 앞 아래). 전 = 이 커밋 전 스크린샷(`Claude outputs/W3b` · 없으면 `git show HEAD~:…PlayerMotionData.lua` 비교 생략).
  - 활 `finisher`: tau 0.2(당기는 중) · 0.36(정적 - 최대 당김) · 0.47(반동).
  - 치유사 `skillE`: 기존(W3b).
- 이펙트 컷(실시간 - `/gg anim` 뒤 타이밍 캡처 · DevAnim은 0.4초 뒤 시작):
  - `airattack`: 명령 + 약 0.9초(정점 준비) · + 약 1.0초(내려찍기) · 착지 순간(+1.3 ~ 1.6초 - 먼지 고리 0.4초).
  - `bow skille`: 스킬 모션 뒤(약 +1.5초) 당김 0.43초 → 발사(공기 고리 0.25초) → 도착(20스터드 · 충격 0.14 ~ 0.35초).
  - `healer skille`: 명령 + 0.4초(소용돌이 0.7초) → 약 +1.5초 구슬 발사(0.19초) → 비행 → 적중(흡입 0.28초).
- 치유모드 구슬(대비) = 딜링모드 끈 채 평타 · 딜링모드 구슬 = E 켠 뒤 평타(몹 대상).
