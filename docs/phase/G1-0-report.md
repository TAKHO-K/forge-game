## ④ 가정 · 결정 로그

| # | 결정 | 이유 |
|---|---|---|
| 1 | 검증 필터 = Attribute(`VerifyOnly`) | 서버 시작 때 도는 블록이라 채팅 명령(`/gg verify`)으로는 이미 늦다. `VerifyArmedUntil`과 같은 자리 · 같은 켜고 끄기 |
| 2 | 하한은 곱의 결과에만(증가 배율 포함 곱이 0.25 밑이면 0.25) | 지시 "최종 하한" |
| 3 | 벽 위 복귀 기준 = 발 ≥ 벽 윗면 − 1 · 1초 | 아레나 안에서 이 높이에 1초 머무는 길이 없다(단상 + 점프 + 넉백 정점 18.2 → 13 위 약 0.46초). 회오리는 무적 출처로 뺐다 |
| 4 | 솟기 전 검사 선행 0.3초 | 전 슬롯 동시 부하에서 조각 수십 프레임 = 0.3초 안 |
| 5 | 예산 기준 = 2ms × 0.4 | 체크포인트 간격(보통 ≤ 1.1ms)을 더해도 2ms 안 |
| 6 | 1,000회 시뮬은 검증 모듈 안(게임 코드 밖)에 두고 판정 함수는 게임 것(`isOutside` · `isOffFloorHeight`)을 쓴다 | 게임 코드를 늘리지 않는다 |
