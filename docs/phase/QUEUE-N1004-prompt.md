사용자 원문 요지(10-03): 환생 뒤 태초 무기로 끝나면 아쉬우니 계승으로 초월 무기로 넘긴다. +30 달성 시 넘길 수 있고, 초월 무기를 얻으면 스테이지가 비약적으로 빨리 밀려야 한다(뚫리는 느낌 자체가 달라야). 고스테이지 몹 · 보스 공격 · 체력 · 방어를 조절하고, 몹 공격 조정이 필요하면 수련에 방어 수치를 추가 개방(골드 소모처). 무기 성능 + 직업 특성 진화(골드) + 수련 수치를 그에 맞춰 올린다. 일반 수련 50레벨 · 진화 최대 범위를 운 나쁜 유저도 +30에 닿는 지점까지 편하게 진행되게 확대(골드 → 빠른 돌파 → 골드 수급 확대의 선순환). 초월 무기를 들면 수련 51~100 = "고급 수련"(창은 같고 증가율이 다름) · 스테이지 15,000쯤이면 100레벨을 편하게 찍을 골드 배분 · 고스테이지 몹 · 보스 골드가 이와 맞는지 점 검증. 계승하면 초월 +0에서 시작 · 초월 +20까지 · 강화당 공격력 상승은 골드 소모량을 따라가 잉여 골드를 완벽히 관리. 무기 이펙트 고민. 보석 홈 광원(등급별 · 홈 위치별) 확인. 초월 보석은 반드시 계승 뒤 해금 · 계승 시 1개 제공 · 태초보다 강함 · 추출 가능. 운으로 얻은 좋은 옵션은 얻을 만하다. 모든 변수를 파악해 고스테이지 몹 체력 · 방어를 조절하고, 몹 정보 · 스탯이 즉시 정확한 수치로 반영되어야 한다.
