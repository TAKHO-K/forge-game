## ③ 낙하 [3] (사용자 결정 · 보완)

- 판정 = 착지 순간 수직 속도(클라가 재서 `FallLanded` - 공중 점프 · 활강으로 속도를 죽이면 산다) → 환산 높이 h = v² ÷ 2g.
- **피해 = 최대 체력 × clamp((h − 안전 24.38) ÷ (360 − 24.38), 0, 1)** · 고정 %최대체력 · 방어 · 피해 감소 · 방어막 무시. 안전 = 합법 정점 21.38 + 3(평소 점프 · 사다리 0). 360 = 나무 세 번째 정거장(검증이 대조).
- 100% 또는 체력이 0이 되면 **쓰러짐**: "쿵!" + 뒤로 눕기 + 그을림(어두운 채움 Highlight) 1.6초 · 루트 고정 · 무적 → 마지막 안전 지점(이번 체공을 시작한 땅)에서 체력 가득 · 아이템 손실 없음.
- **불꽃 꼬리** = 예상 피해 50%(h 192 · 속도 275) 이상으로 떨어지는 동안(Fire + Trail 꼬리 - 노랑 → 빨강).

## ④ 공중 전투 [4]

- **예산(한 체공)** = 해금된 공중 점프 × 1 + 이번 체공에 쓴 공중 대시 × 1(`MoveRules.airAttackBudget`) - 환생 0 = 0(옛 착지 버퍼) · 1 = 1(+대시 1) · 3 = 2(+대시 1 = 3). 서버 `AirState`가 체공 세션을 직접 세고 넘으면 거부(쿨다운 · 콤보 안 건드림).
- 공중 판정: 클라가 공중이라 보냈거나 서버가 1초 넘게 공중으로 본 요청 = 공중(지상 위조로 긴 활강 · 낙하 중 예산 우회 차단). 공중이면 대상 높이차 상한을 넓힌다(근접 14 · 원거리 30 - 옛 8이면 아래 몹을 못 맞힘).
- **강공격 스택**: 0.15초 넘게 뜨면(요철 제외) 0부터 · 공중 3타 = 강공격 + 무기 반짝임(별 6개 · 0.35초 - 7장 예산 ≤ 6)은 **환생 3부터**(전에는 공중 3타도 일반).
- **무기별 공중 동작 틀(임시 모션 - 최종 = W1 · A2)**: 대검 = 내려찍기(몸 앞으로 24°) · 쌍검 = 회전 베기(몸 한 바퀴) · 활 = **0.25초 공중 정지** 후 아래로 사격(몸 숙임 · 활 35° 눕힘 - 프레야식) · 지팡이 = 0.25초 공중 영창 후 아래로 발사 · 방패망치 = 머리 위 내려치기(직업 없음 - 데이터 자리만).
- **원거리 공중 정지**: 사격당 0.25초 · 공중 공격 횟수 안에서만(최대 4회 = 1.0초) · 높이를 올리지 않음(HeightGuard 무관) · S1 합법 목록 `s1Limits().rangedHover`. **대공 잡기**: 정지도 체공이라 그대로 센다(추천 - "점프하지 마"를 어기고 공중에서 쏘면 잡힌다).

|---|---|---|

- 공중 DPS ≤ 지상 유지(예산이 체공 시간보다 먼저 끝난다). **보스 약점 여지**: 보스 머리 · 등 위 약점(높이 층 8 위)을 "공중 공격만 닿는 부위"로 두면 공중 전투가 딜 손해가 아닌 선택이 된다(BR2 제안).

- **태초 신발 = 2단 대시**(`DashConfig.primordialShoes` - 지상 · 공중 · 첫 대시 뒤 1.5초 안 · 쿨다운 두 번째부터 · 창을 놓치면 첫 대시 쿨 그대로). **D1-2의 대시 18(×1.125)은 폐기**(판단): 태초 신발은 이미 이속 상한이라 이동 속도 비례로 30.8 - 따로 늘리면 최악 틈이 더 커진다.
- **태초 장갑 = 붙잡기**(사용자 수정 - 공중 공격 +1 취소): 모서리 매달림(최대 4초) → 점프 = 올라서기 · 한 체공 1회 · 딜 · 공격 횟수 · 공속 영향 0. 서버: 클라가 모서리 윗점을 보내면 그 점 위에서 광선으로 다시 찾고(±3) "마지막 지면 + 높이 허용치 + 손 높이" 안인지 본 뒤 HeightGuard 허가(`source = ledge`)를 준다.
  - 실측(지연 0.25): 공중 점프 2 정점에서 매달림(발 19.8 · 모서리 26.6 - 허용치 22.38 초과) → 올라서서 그대로 섬 · **되돌림 0 · 거절 0**. 첫 구현은 서버가 지연된 발 기준으로 광선을 쏴 `mismatch` 거절 → 클라 모서리 점 + 마지막 지면 기준으로 고침. 대각선 올라서기가 모서리를 뚫어 튕기던 것 → 두 단계(위 → 안쪽)로 고침.
  - 대공 잡기의 공중 시간 규칙은 그대로(매달림 = 공중).
- S1 속도 허용치에 반영: 2단 대시(`s1Limits().dash.chainCharges`) · 한 폴링 최대 이동 38.1 < 50.
