## 바닥층 · 토글(보정 1 · 2 · 사용자 결정)
- `server/BaseLayer`(규칙) + `BaseLayerServer.server`(연결): 갑옷 한 부위라도 입고 토글 끔 → 셔츠 · 바지 템플릿 = 바닥층(진남색/크림 누빔 + 가죽 띠 · 4장 upload.py) · 레이어드 **옷**(셔츠 · 재킷 · 바지 · 신발 등 - 머리카락 · 모자 · 얼굴 · 머리 장식은 그대로)을 서버 보관(ServerStorage.GearHiddenClothes)으로 옮김 · 켜거나 갑옷을 벗으면 원래대로(템플릿 = 캐릭터 Attribute 원본 · 레이어드 = Humanoid:AddAccessory).
  - Play에서 찾은 것: 레이어드 옷을 투명하게 하면 **몸까지 같이 사라졌다**(몸과 합쳐 그려짐) → 보관 방식으로 바꿈. 레이어드 머리카락도 WrapLayer라 옷 종류만 숨기게 고침.
