# 치장 외형 감사(QUEUE-ALL9C 1-6R · 2026-10-03)

> 사용자 10-03 지시: 치장 외형 · 이펙트 개선은 **사용자 검수 뒤에만** 구현(감사 캡처 → GPT 콘셉트 시안 → 사용자 일괄 검수 → 설계 담당 지시 → 구현). 이번 = **감사만 · 구현 변경 없음**.

## 찍은 방법

- Studio 전용 `client/CosmeticAudit.client.lua`(Player Attribute `DebugCosAudit = "all"`) + 서버 `DevTools` Studio 전용 Remote `CosAuditFire`(처치 · 강화 성공 · 하이파이브 = 실전과 같은 Remote로 내 클라에만) + 스크래치패드 PowerShell 감시(로그 `[COSAUDIT] SHOT` 줄마다 PrintWindow · 뷰포트 잘라 1280 폭 JPEG).
- 장착 = 내 Attribute `Cosmetic_<칸>`을 로컬에서만 바꿈(상점 [직접 보기]와 같은 길 · 서버 값 · 저장 그대로 · 끝나면 되돌림). 장소 = 허브 광장(대장간 앞) · HUD 숨김 · 화면 위 라벨 = `id · 칸 · 장면 · t=+초`(연출 시작 뒤 실제 시각 - 사진마다 확인 가능).
- 장면: `a1 ~ a3` = 정지 3각도(물건형) 또는 연출 한가운데 3각도(연출형 · 테마 = 대시) · `m1 ~ m3` = 시작 · 중간 · 끝(동작 길이의 8% · 45% · 90%) · 테마는 칸마다 `<칸>_m1 ~ m3`(대시 · 점프 · 활강 · 발자국). `_sheet.jpg` = 한 장 모음.
- 동작 = 대시(루트 18 stud / 0.3초) · 점프(위 속도 52) · 활강(Gliding + 16 stud / 1.6초) · 발자국(MoveTo 걷기) · 처치(앞 9 stud 감사 더미) · 무기(playSwing) · 귀환(RecallCastUntil 2초 → 끝) · 펫(개 · 희귀 로컬 펫 + 걷기).
- 구성 수 = 장면 동안 새로 생긴 인스턴스 최대값(workspace · SoundService) + 캐릭터에 미리 달린 트레일 · 입자 중 켜진 것. 소리 = 치장 코드(CosmeticFx · ArtV1Cosmetics · GlideView · PetView)에 Sound 없음(grep 0) - 강화 · 귀환의 소리 1 ~ 2는 기본 연출 소리.
