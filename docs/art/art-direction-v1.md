# 아트 방향 v1 (A2-S · 2026-09-30)

> 이 문서는 style-bible v2 · art-spec · cartoon-pipeline 위에 **"깔쌈함"의 기준**을 얹는다. 충돌하면 style-bible §0 → 이 문서 → 나머지 순. 샘플 = `ArtStyleV1` 스위치(기본 꺼짐) 뒤 · 결과 = `docs/phase/A2-S-report.md`.

## 1. 콘셉트

**"두툼한 장난감 대장간 — 덩어리는 크고 단순하게, 빛은 보상에만."**

키워드 5: **두툼함**(얇은 부위 없음) · **또렷한 덩어리**(큰 1 : 중간 2 ~ 3 : 작은 몇 개) · **깎은 모서리**(쐐기 모따기) · **따뜻한 불빛 vs 서늘한 돌** · **보상만 빛난다**(Neon · 파티클은 등급 · 강화 · 드랍에만).

참조 이미지 12종에서 뽑은 공통점: ① 두꺼운 어두운 외곽선 + 한쪽 광택 ② 평면 3톤(윗면 밝게 · 오른면 어둡게) · 질감 없음 ③ 머리 · 몸이 큰 짧은 비율, 눈이 크고 단순(흰 바탕 + 검은 점) ④ 등급 = 같은 형태 + 색 · 빛 · 장식 누적 ⑤ 배경은 채도 낮고 넓게, 캐릭터 · 보상은 채도 높고 작게.

## 2. 형태 언어

| 규칙 | 값 |
|---|---|
| 실루엣 | 30 stud · 폰 800 × 360에서 **3초 안에 종 구별** = 종마다 "튀어나온 것 1개"(슬라임 = 이끼 볏 · 멧돼지 = 엄니 · 골렘 = 주먹). 몸 윤곽 안의 디테일로 구별하지 않는다 |
| 비율(잡몹) | 몸 : 머리(또는 윗덩어리) = 1 : 0.6 ~ 0.8 · 다리 짧게(키의 ≤ 25%) · 눈은 몸 폭의 18 ~ 22% |
| 비율(무기) | 대검 = 아바타 키와 비슷(5) · 날 폭 ≥ 0.9(폰에서 선이 아니라 판) · 손잡이 : 가드 : 날 = 1 : 0.4 : 3 |
| 덩어리 비율 | 큰 1(부피 70%) · 중간 2 ~ 3(25%) · 작은 ≤ 4(5% - 눈 · 보석 · 광택). 작은 것이 5개를 넘으면 합친다 |
| 모서리 | 상자는 **쐐기(WedgePart)로 모따기 느낌** - 모서리 하나만 깎아도 "깎은 장난감"이 된다. 둥근 것은 공 · 원기둥으로 |
| 두께 | 최소 0.4 stud(art-spec 1-5) · 날 · 판은 최소 0.25 |
| 파트 수 | 아래 §6 예산 |

## 3. 색

### 3-1. 채도 층(낮음 → 높음)

**배경(먼 절벽 · 하늘) < 플레이 바닥 < 캐릭터 · 몬스터 < 드랍 · 이펙트.** 이펙트만 Neon · 순색. 몬스터는 바닥과 명도 차 30% 이상.

### 3-2. 구역 팔레트(주조 · 강조 - `CartoonStyleData.palette` 그대로, 여기서 역할만 정한다)

### 3-3. 3톤

한 물체 = 기본색 + 윗면 ×1.18 + 그늘 ×0.72. 파트는 조명(스펙큘러 0)으로, **몬스터 눈 · 광택만 색 파트**(흰 광택 점 1개 = "한쪽 하이라이트"). 순검정 금지 - 가장 어두운 색 = `#1E1B2E`(외곽선 색).

### 3-4. 등급 색 사용처

`ItemVisualData` 7등급 + 초월 흑금(`transcendent` = 검은 본체 + 금 `#D6B03E` 균열). **무기 발광 · 드랍 빛기둥 · 아이콘 테두리 · 강화 연출에만.** 환경 · 몬스터 몸 금지(고대 빨강 · 유물 금 특히). 위험색(주황빨강 330 ~ 50°)은 보스 장판 · 전조 전용.

## 4. 재질 · 외곽선 · 조명

| 항목 | 규칙 |

| 후처리 | Atmosphere 밀도 0.12 · Haze 0.6 · 색 (196,222,250) · ColorCorrection 대비 +0.08 · 채도 +0.12 · Bloom 강도 0.4 · Threshold 1.5(Neon만 번지게) |

## 5. VFX

| 도파민 순간 | 길이 | 크기 | 색 단계 | 파티클 |
|---|---|---|---|---|
| 강화 성공 | 0.9초 | 모루 위 반경 3 | 흰 섬광 → 주황 불꽃 | ≤ 14 |
| 강화 대성공 | 1.4초 | 반경 5 + 빛기둥 8 | 흰 섬광 → 금 폭발 → 금 별 | ≤ 24 |
| 드랍 | 드랍 유지 | 빛기둥(기존) | 등급 색 | 0(파트 + 투명도) |
| 레벨업 | 1.0초 | 발밑 고리 | 흰 → 노랑 | ≤ 16 |

- 단계 규칙: **흰 번쩍(0.08초) → 색 → 흩어짐.** 위로 솟는 것 = 좋은 일, 옆으로 퍼지는 것 = 타격.
- 보스 전조가 우선: 보스전 안에서는 아군 VFX 불투명도 ≤ 50% · 장판 위 층 금지(style-bible §8).
- 폰 예산: 한 화면 동시 파티클 ≤ 120 · 한 연출 이미터 ≤ 3 · 수명 ≤ 1.2초 · VFX는 전부 클라.

## 7. Blender 메시로 1:1 교체하는 흐름

1. 파트 이름 = 리그 이름(`Body` · `Head` · `Eye_L` …, 무기 `Blade` · `Guard` · `Grip` …). Blender 오브젝트 이름도 같게.
2. Blender에서 파트 하나 = 메시 하나, 원점 = 이 샘플의 관절 자리(`at` · `pivot`) · 앞 = −Z · 1 stud = 1 m.
3. 색은 버텍스 컬러 없이 **단색 머티리얼 1개**(색은 Studio에서 데이터 `ArtStyleV1Data`가 칠한다 - 형태만 가져온다).
4. `.fbx` → Studio 가져오기 → MeshPart 이름 확인 → `.rbxm`으로 `shared/ArtModels/<대상>/`에 저장(Rojo) → 조립 함수는 "같은 이름 메시가 있으면 복제, 없으면 파트".
5. 판정은 안 바뀐다(몬스터 = 투명 `Hitbox` · 무기 = `WeaponRigSpec` 길이 · 강화대 = 프롬프트 파트) → 교체 뒤 `/gg art on` 스크린샷 3각도 + 파트 · 삼각형 수만 다시 잰다.
